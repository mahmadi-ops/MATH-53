    1. A Repeated Eigenvalue with a Two-Dimensional Eigenspace.

    Find the eigenvalues and eigenvectors of \(A = \begin{bmatrix} 4 \amp 0 \amp 0 \\ -1 \amp 3 \amp 5 \\ 1 \amp 1 \amp -1 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    Expand \(\det(A - \lambda I)\) along the first row, which has only one nonzero entry:
    \begin{align*} \det(A - \lambda I) \amp = (4 - \lambda)\begin{vmatrix} 3-\lambda \amp 5 \\ 1 \amp -1-\lambda \end{vmatrix}\\ \amp = (4-\lambda)\bigl[(3-\lambda)(-1-\lambda) - 5\bigr]\\ \amp = (4-\lambda)(\lambda^2 - 2\lambda - 8)\\ \amp = (4-\lambda)(\lambda - 4)(\lambda + 2). \end{align*}
    So the eigenvalues are \(\lambda = 4\text{,}\) of multiplicity \(2\text{,}\) and \(\lambda = -2\text{.}\)
    🔗
    \(\lambda = 4\text{.}\) Solve \((A - 4I)\vec{x} = \vec{0}\text{:}\)
    \begin{equation*} A - 4I = \begin{bmatrix} 0 \amp 0 \amp 0 \\ -1 \amp -1 \amp 5 \\ 1 \amp 1 \amp -5 \end{bmatrix} \longrightarrow \begin{bmatrix} 1 \amp 1 \amp -5 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    The single equation is \(x_1 + x_2 - 5x_3 = 0\text{,}\) so \(x_2\) and \(x_3\) are free and the eigenspace is two-dimensional. Basic eigenvectors:
    \begin{equation*} \vec{v}_1 = \begin{bmatrix} -1 \\ 1 \\ 0 \end{bmatrix}, \qquad \vec{v}_2 = \begin{bmatrix} 5 \\ 0 \\ 1 \end{bmatrix}. \end{equation*}
    🔗
    \(\lambda = -2\text{.}\)
    \begin{equation*} A + 2I = \begin{bmatrix} 6 \amp 0 \amp 0 \\ -1 \amp 5 \amp 5 \\ 1 \amp 1 \amp 1 \end{bmatrix} \longrightarrow \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 0 \end{bmatrix}, \end{equation*}
    giving \(x_1 = 0\) and \(x_2 = -x_3\text{,}\) so \(\vec{v}_3 = \begin{bmatrix} 0 \\ 1 \\ -1 \end{bmatrix}\text{.}\)
    🔗
    Checking all three:
    \begin{equation*} A\vec{v}_1 = \begin{bmatrix} -4 \\ 4 \\ 0 \end{bmatrix} = 4\vec{v}_1, \qquad A\vec{v}_2 = \begin{bmatrix} 20 \\ 0 \\ 4 \end{bmatrix} = 4\vec{v}_2, \end{equation*}
    \begin{equation*} A\vec{v}_3 = \begin{bmatrix} 0 \\ -2 \\ 2 \end{bmatrix} = -2\vec{v}_3. \checkmark \end{equation*}
    🔗
    🔗
    🔗

    2. A Second \(3 \times 3\) Matrix.

    Find the eigenvalues and eigenvectors of \(A = \begin{bmatrix} 3 \amp -2 \amp -1 \\ 0 \amp 5 \amp 1 \\ 0 \amp 2 \amp 4 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    Expanding down the first column, which has a single nonzero entry,
    \begin{align*} \det(A - \lambda I) \amp = (3-\lambda)\begin{vmatrix} 5-\lambda \amp 1 \\ 2 \amp 4-\lambda \end{vmatrix}\\ \amp = (3-\lambda)\bigl[(5-\lambda)(4-\lambda) - 2\bigr]\\ \amp = (3-\lambda)(\lambda^2 - 9\lambda + 18)\\ \amp = (3-\lambda)(\lambda - 3)(\lambda - 6). \end{align*}
    The eigenvalues are \(\lambda = 3\text{,}\) of multiplicity \(2\text{,}\) and \(\lambda = 6\text{.}\)
    🔗
    \(\lambda = 3\text{.}\)
    \begin{equation*} A - 3I = \begin{bmatrix} 0 \amp -2 \amp -1 \\ 0 \amp 2 \amp 1 \\ 0 \amp 2 \amp 1 \end{bmatrix} \longrightarrow \begin{bmatrix} 0 \amp 2 \amp 1 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    The one equation is \(2x_2 + x_3 = 0\text{,}\) so \(x_1\) and \(x_2\) are free:
    \begin{equation*} \vec{v}_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}, \qquad \vec{v}_2 = \begin{bmatrix} 0 \\ 1 \\ -2 \end{bmatrix}. \end{equation*}
    🔗
    \(\lambda = 6\text{.}\)
    \begin{equation*} A - 6I = \begin{bmatrix} -3 \amp -2 \amp -1 \\ 0 \amp -1 \amp 1 \\ 0 \amp 2 \amp -2 \end{bmatrix}. \end{equation*}
    Row \(2\) gives \(x_3 = x_2\text{,}\) and row \(1\) then gives \(-3x_1 - 3x_2 = 0\text{,}\) so \(x_1 = -x_2\text{:}\) \(\vec{v}_3 = \begin{bmatrix} -1 \\ 1 \\ 1 \end{bmatrix}\text{.}\)
    🔗
    Checking the last one, \(A\vec{v}_3 = (-3 - 2 - 1,\ 0 + 5 + 1,\ 0 + 2 + 4) = (-6, 6, 6) = 6\vec{v}_3\text{.}\) \(\checkmark\)
    🔗
    (This lab came without a solution key, so every answer here has been checked by substituting back into \(A\vec{x} = \lambda \vec{x}\text{.}\))

    3. A \(2 \times 2\) Characteristic Polynomial.

    Find the characteristic polynomial, eigenvalues and eigenvectors of \(A = \begin{bmatrix} -4 \amp 2 \\ 3 \amp -5 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    By Definition 8.9,
    \begin{align*} c_A(\lambda) \amp = \begin{vmatrix} \lambda + 4 \amp -2 \\ -3 \amp \lambda + 5 \end{vmatrix}\\ \amp = (\lambda + 4)(\lambda + 5) - 6\\ \amp = \lambda^2 + 9\lambda + 14 = (\lambda + 2)(\lambda + 7), \end{align*}
    so the eigenvalues are \(\lambda = -2\) and \(\lambda = -7\text{.}\)
    🔗
    \(\lambda = -2\text{.}\) \(A + 2I = \begin{bmatrix} -2 \amp 2 \\ 3 \amp -3 \end{bmatrix}\text{,}\) so \(x_1 = x_2\) and \(\vec{v}_1 = \begin{bmatrix} 1 \\ 1 \end{bmatrix}\text{.}\)
    🔗
    \(\lambda = -7\text{.}\) \(A + 7I = \begin{bmatrix} 3 \amp 2 \\ 3 \amp 2 \end{bmatrix}\text{,}\) so \(3x_1 + 2x_2 = 0\) and \(\vec{v}_2 = \begin{bmatrix} 2 \\ -3 \end{bmatrix}\text{.}\)
    🔗
    Checking: \(A\vec{v}_1 = (-4+2,\ 3-5) = (-2,-2) = -2\vec{v}_1\) and \(A\vec{v}_2 = (-8-6,\ 6+15) = (-14,21) = -7\vec{v}_2\text{.}\) \(\checkmark\) (This lab also came without a key.)

    4. Eigenvalues of a Triangular Matrix.

    Write the characteristic polynomial and the eigenvalues of
    \begin{equation*} A = \begin{bmatrix} 6 \amp 0 \amp 0 \amp 0 \amp 0 \\ 9 \amp -4 \amp 0 \amp 0 \amp 0 \\ -2 \amp 0 \amp 11 \amp 0 \amp 0 \\ 1 \amp -1 \amp 3 \amp 0 \amp 0 \\ 0 \amp 1 \amp -7 \amp 4 \amp 8 \end{bmatrix}. \end{equation*}
    🔗
    Solution.
    Every entry above the main diagonal is zero, so \(A\) is lower triangular, and so is \(\lambda I - A\text{.}\) By Theorem 6.9 the determinant of a triangular matrix is the product of its diagonal entries, so
    \begin{equation*} c_A(\lambda) = (\lambda - 6)(\lambda + 4)(\lambda - 11)\lambda(\lambda - 8). \end{equation*}
    🔗
    The eigenvalues are therefore just the diagonal entries:
    \begin{equation*} \lambda = 6,\ -4,\ 11,\ 0,\ 8, \end{equation*}
    each of multiplicity one. Nothing below the diagonal — the \(9\text{,}\) the \(-2\text{,}\) the \(-7\text{,}\) and so on — plays any role at all.
    🔗
    Note that \(0\) is an eigenvalue, so \(A\) is not invertible; this is the content of Theorem 8.23. (No key was supplied with this lab; the factorization above is verified directly by the triangular-determinant theorem.)

    5. Why a Rotation Has No Real Eigenvalues.

    Let \(A\) be the matrix of the linear transformation that rotates every vector in \(\R^2\) counterclockwise through \(\pi/6\text{.}\) Explain, using the geometry of eigenvectors, why \(A\) can have no real eigenvalues.
    🔗
    Solution.
    Suppose \(\lambda \in \R\) were an eigenvalue with eigenvector \(\vec{v} \neq \vec{0}\text{,}\) so \(A\vec{v} = \lambda\vec{v}\text{.}\) Then \(A\vec{v}\) is a scalar multiple of \(\vec{v}\text{,}\) which means it lies on the same line through the origin as \(\vec{v}\text{.}\) That is the geometric content of being an eigenvector, as in Figure 8.8: \(A\) may stretch, shrink, or reverse \(\vec{v}\text{,}\) but it may not turn it off its own line.
    🔗
    A rotation through \(\pi/6\) turns every nonzero vector by \(30^\circ\text{.}\) Since \(\pi/6\) is not a multiple of \(\pi\text{,}\) no nonzero vector ends up on its original line. So no nonzero \(\vec{v}\) can satisfy \(A\vec{v} = \lambda\vec{v}\) for a real \(\lambda\text{,}\) and \(A\) has no real eigenvalues.
    🔗
    The two exceptional angles are worth noting: rotation through \(0\) is the identity, for which every nonzero vector is an eigenvector with \(\lambda = 1\text{,}\) and rotation through \(\pi\) reverses every vector, giving \(\lambda = -1\text{.}\)

    6. Eigenvalues with a Repeated Root.

    Find the eigenvalues of \(A = \begin{bmatrix} 1 \amp 2 \amp 0 \\ 2 \amp 1 \amp 0 \\ -2 \amp -2 \amp -1 \end{bmatrix}\) and their multiplicities.
    🔗
    Solution.
    The third column of \(A - \lambda I\) has a single nonzero entry, so expand down it:
    \begin{align*} \det(A - \lambda I) \amp = (-1-\lambda)\begin{vmatrix} 1-\lambda \amp 2 \\ 2 \amp 1-\lambda \end{vmatrix}\\ \amp = (-1-\lambda)\bigl[(1-\lambda)^2 - 4\bigr]\\ \amp = (-1-\lambda)(\lambda^2 - 2\lambda - 3)\\ \amp = (-1-\lambda)(\lambda - 3)(\lambda + 1). \end{align*}
    🔗
    So the eigenvalues are \(\lambda = 3\) and \(\lambda = -1\text{,}\) the latter of multiplicity two.
    🔗
    🔗

    7. An Eigenvalue from Two Rows.

    Let \(A = \begin{bmatrix} 1 \amp \square \amp 3 \\ \square \amp \square \amp \square \\ 1 \amp \square \amp -1 \end{bmatrix}\text{,}\) where the entries marked \(\square\) are unknown. If \(\vec{x} = \begin{bmatrix} 3 \\ 0 \\ 1 \end{bmatrix}\) is an eigenvector of \(A\text{,}\) which number must be an eigenvalue of \(A\text{?}\)
    🔗
    Solution.
    The second entry of \(\vec{x}\) is \(0\text{,}\) so the unknown middle column never contributes: in the product \(A\vec{x}\) each row is multiplied by \((3, 0, 1)\) and the middle entry is annihilated. That makes rows \(1\) and \(3\text{,}\) which are fully known in the positions that matter, enough.
    🔗
    Row \(1\) gives \(1(3) + \square \cdot 0 + 3(1) = 6\text{,}\) and row \(3\) gives \(1(3) + \square \cdot 0 + (-1)(1) = 2\text{.}\) So
    \begin{equation*} A\vec{x} = \begin{bmatrix} 6 \\ ? \\ 2 \end{bmatrix}. \end{equation*}
    🔗
    Since \(\vec{x}\) is an eigenvector, \(A\vec{x} = \lambda\vec{x}\text{,}\) that is \((6, ?, 2) = \lambda(3, 0, 1)\text{.}\) The first coordinate gives \(\lambda = 2\text{,}\) and the third confirms it. So \(\lambda = 2\) must be an eigenvalue of \(A\text{.}\) (The middle coordinate then forces the unknown \(?\) to be \(0\text{,}\) but we did not need that.)

    8. The Dominant Eigenvalue.

    Consider the linear dynamical system \(V_{k+1} = AV_k\) with \(A = \begin{bmatrix} -2 \amp 0 \\ 3 \amp 1 \end{bmatrix}\text{.}\) Which eigenvalue of \(A\) is dominant?
    🔗
    Solution.
    \(A\) is lower triangular, so its eigenvalues are the diagonal entries \(\lambda = -2\) and \(\lambda = 1\text{.}\)
    🔗
    The dominant eigenvalue is the one of largest absolute value, since it is the term that survives when \(A^k\) is applied repeatedly. Here \(|-2| = 2 \gt 1 = |1|\text{,}\) so \(\lambda = -2\) is dominant.
    🔗
    A dominant eigenvalue of absolute value greater than \(1\) means the trajectory grows without bound; contrast the Markov chains of Section 10.9, where the dominant eigenvalue is always \(1\) and the trajectory settles down instead.

    9. ★ Can We Compute \(A^{500}\) Efficiently?

    Let \(A = \begin{bmatrix} 2 \amp 1 \\ 1 \amp 2 \end{bmatrix}\) and \(P = \begin{bmatrix} 1 \amp 1 \\ 1 \amp -1 \end{bmatrix}\text{.}\) Compute \(P^{-1}AP\text{,}\) and use it to find \(A^{500}\text{.}\)
    🔗
    Solution.
    Since \(\det P = -2\text{,}\) \(P^{-1} = \tfrac{1}{2}\begin{bmatrix} 1 \amp 1 \\ 1 \amp -1 \end{bmatrix}\text{.}\) Then
    \begin{equation*} AP = \begin{bmatrix} 3 \amp 1 \\ 3 \amp -1 \end{bmatrix}, \qquad P^{-1}AP = \begin{bmatrix} 3 \amp 0 \\ 0 \amp 1 \end{bmatrix} = D, \end{equation*}
    a diagonal matrix.
    🔗
    From \(P^{-1}AP = D\) we get \(A = PDP^{-1}\text{,}\) and therefore \(A^n = PD^nP^{-1}\text{,}\) since all the interior \(P^{-1}P\) pairs cancel. With \(D^{500} = \begin{bmatrix} 3^{500} \amp 0 \\ 0 \amp 1 \end{bmatrix}\text{,}\)
    \begin{equation*} PD^{500} = \begin{bmatrix} 3^{500} \amp 1 \\ 3^{500} \amp -1 \end{bmatrix}, \end{equation*}
    \begin{equation*} A^{500} = \tfrac{1}{2}\begin{bmatrix} 3^{500} + 1 \amp 3^{500} - 1 \\ 3^{500} - 1 \amp 3^{500} + 1 \end{bmatrix}. \end{equation*}
    🔗
    Five hundred matrix multiplications have been replaced by one exponentiation of a number. The columns of \(P\) are what made this work: they are eigenvectors of \(A\text{,}\) since \(A(1,1) = 3(1,1)\) and \(A(1,-1) = 1(1,-1)\text{.}\)

    10. ★ Verifying an Eigenvector.

    Let \(A = \begin{bmatrix} 0 \amp 1 \\ 2 \amp 1 \end{bmatrix}\text{.}\) Verify that \(\begin{bmatrix} 1 \\ 2 \end{bmatrix}\) and \(\begin{bmatrix} 1 \\ -1 \end{bmatrix}\) are eigenvectors of \(A\text{,}\) and find their eigenvalues. Is \(\begin{bmatrix} 1 \\ 0 \end{bmatrix}\) an eigenvector?
    🔗
    Solution.
    A vector \(\vec{x} \neq \vec{0}\) is an eigenvector when \(A\vec{x}\) is a scalar multiple of \(\vec{x}\text{.}\) Computing,
    \begin{equation*} A \begin{bmatrix} 1 \\ 2 \end{bmatrix} = \begin{bmatrix} 2 \\ 4 \end{bmatrix} = 2 \begin{bmatrix} 1 \\ 2 \end{bmatrix}, \end{equation*}
    so it is an eigenvector with eigenvalue \(\lambda = 2\text{.}\) Next,
    \begin{equation*} A \begin{bmatrix} 1 \\ -1 \end{bmatrix} = \begin{bmatrix} -1 \\ 1 \end{bmatrix} = -1 \begin{bmatrix} 1 \\ -1 \end{bmatrix}, \end{equation*}
    an eigenvector with eigenvalue \(\lambda = -1\text{.}\)
    🔗
    But
    \begin{equation*} A \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 0 \\ 2 \end{bmatrix}, \end{equation*}
    which is not a multiple of \(\begin{bmatrix} 1 \\ 0 \end{bmatrix}\text{,}\) so \(\begin{bmatrix} 1 \\ 0 \end{bmatrix}\) is not an eigenvector.
    🔗
    Note that checking a proposed eigenvector requires no root-finding at all — only one matrix-vector product.

    11. ★ A Geometric Eigenvector.

    Let \(Q : \R^2 \to \R^2\) be reflection in the line \(y = x\text{,}\) with matrix \(\begin{bmatrix} 0 \amp 1 \\ 1 \amp 0 \end{bmatrix}\text{.}\) Find its eigenvalues and eigenvectors without computing a characteristic polynomial.
    🔗
    Solution.
    An eigenvector is a nonzero vector that the transformation keeps on its own line through the origin. For a reflection there are two obvious families.
    🔗
    Vectors along the mirror line are fixed. The vector \(\begin{bmatrix} 1 \\ 1 \end{bmatrix}\) lies on \(y = x\text{,}\) and reflecting leaves it alone:
    \begin{equation*} Q \begin{bmatrix} 1 \\ 1 \end{bmatrix} = \begin{bmatrix} 1 \\ 1 \end{bmatrix} = 1 \cdot \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \end{equation*}
    an eigenvector with \(\lambda = 1\text{.}\)
    🔗
    Vectors perpendicular to the mirror are reversed. The vector \(\begin{bmatrix} 1 \\ -1 \end{bmatrix}\) is perpendicular to \(y = x\text{,}\) and
    \begin{equation*} Q \begin{bmatrix} 1 \\ -1 \end{bmatrix} = \begin{bmatrix} -1 \\ 1 \end{bmatrix} = -1 \cdot \begin{bmatrix} 1 \\ -1 \end{bmatrix}, \end{equation*}
    an eigenvector with \(\lambda = -1\text{.}\)
    🔗
    These two directions are independent, so we have found all of them: the eigenvalues are \(1\) and \(-1\text{.}\) The characteristic polynomial would confirm it, since \(\det(\lambda I - Q) = \lambda^2 - 1 = (\lambda-1)(\lambda+1)\text{,}\) but the geometry gave the answer first. Contrast Exercise 10.8.5, where a rotation has no such directions at all.

    12. ★ Finding Eigenvalues.

    Find the eigenvalues of \(A = \begin{bmatrix} 1 \amp 2 \amp 0 \\ 0 \amp 3 \amp 0 \\ 2 \amp -4 \amp 2 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    Form \(\lambda I - A\) and expand along its third column, which has a single nonzero entry:
    \begin{align*} c_A(\lambda) \amp = \det \begin{bmatrix} \lambda - 1 \amp -2 \amp 0 \\ 0 \amp \lambda - 3 \amp 0 \\ -2 \amp 4 \amp \lambda - 2 \end{bmatrix}\\ \amp = (\lambda - 2) \begin{vmatrix} \lambda - 1 \amp -2 \\ 0 \amp \lambda - 3 \end{vmatrix}\\ \amp = (\lambda - 2)(\lambda - 1)(\lambda - 3). \end{align*}
    🔗

    15. A Fiftieth Power.

    Let \(A = \begin{bmatrix} 2 \amp 1 \amp 0 \\ 0 \amp 1 \amp 0 \\ -1 \amp -1 \amp 1 \end{bmatrix}\text{.}\) Find \(A^{50}\text{.}\)
    🔗
    Solution.
    Expanding \(\det(A - \lambda I)\) down the third column,
    \begin{equation*} \det(A - \lambda I) = (1-\lambda)\begin{vmatrix} 2-\lambda \amp 1 \\ 0 \amp 1-\lambda \end{vmatrix} = (2-\lambda)(1-\lambda)^2, \end{equation*}
    so the eigenvalues are \(\lambda = 2\) and \(\lambda = 1\) of multiplicity two.
    🔗
    \(\lambda = 2\text{.}\) \(A - 2I = \begin{bmatrix} 0 \amp 1 \amp 0 \\ 0 \amp -1 \amp 0 \\ -1 \amp -1 \amp -1 \end{bmatrix}\) gives \(x_2 = 0\) and \(x_1 = -x_3\text{,}\) so \(\vec{v}_1 = (-1, 0, 1)\text{.}\)
    🔗
    \(\lambda = 1\text{.}\) \(A - I = \begin{bmatrix} 1 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \\ -1 \amp -1 \amp 0 \end{bmatrix}\) gives the single equation \(x_1 + x_2 = 0\text{,}\) so \(\vec{v}_2 = (0,0,1)\) and \(\vec{v}_3 = (-1,1,0)\text{.}\)
    🔗
    Three independent eigenvectors, so \(A\) is diagonalizable. Put
    \begin{equation*} P = \begin{bmatrix} -1 \amp 0 \amp -1 \\ 0 \amp 0 \amp 1 \\ 1 \amp 1 \amp 0 \end{bmatrix}, \qquad D = \begin{bmatrix} 2 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    Row reducing \([\,P \mid I\,]\) gives
    \begin{equation*} P^{-1} = \begin{bmatrix} -1 \amp -1 \amp 0 \\ 1 \amp 1 \amp 1 \\ 0 \amp 1 \amp 0 \end{bmatrix}. \end{equation*}
    🔗
    By Theorem 8.2, \(A^{50} = PD^{50}P^{-1}\) with \(D^{50} = \operatorname{diag}(2^{50}, 1, 1)\text{.}\) First
    \begin{equation*} PD^{50} = \begin{bmatrix} -2^{50} \amp 0 \amp -1 \\ 0 \amp 0 \amp 1 \\ 2^{50} \amp 1 \amp 0 \end{bmatrix}, \end{equation*}
    and then multiplying by \(P^{-1}\text{,}\)
    \begin{equation*} A^{50} = \begin{bmatrix} 2^{50} \amp 2^{50} - 1 \amp 0 \\ 0 \amp 1 \amp 0 \\ 1 - 2^{50} \amp 1 - 2^{50} \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    A quick sanity check: setting the exponent to \(1\) in the same computation returns \(A\) itself, and the second row of \(A^{50}\) is \([0\ 1\ 0]\text{,}\) which is right because the second row of \(A\) is \([0\ 1\ 0]\) and so is fixed by every power.

    16. Solving a Dynamical System.

    A dynamical system has the form
    \begin{equation*} \begin{bmatrix} x(n+1) \\ y(n+1) \end{bmatrix} = \begin{bmatrix} 1.5 \amp -0.5 \\ 1 \amp 0 \end{bmatrix} \begin{bmatrix} x(n) \\ y(n) \end{bmatrix}. \end{equation*}
    Find \(x_n\) and \(y_n\) for the initial conditions \(x_0 = 20\text{,}\) \(y_0 = 10\text{.}\)
    🔗
    Solution.
    Write \(A = \begin{bmatrix} \frac{3}{2} \amp -\frac{1}{2} \\ 1 \amp 0 \end{bmatrix}\text{.}\) Then
    \begin{equation*} c_A(\lambda) = \lambda^2 - \tfrac{3}{2}\lambda + \tfrac{1}{2} = (\lambda - 1)\left(\lambda - \tfrac{1}{2}\right). \end{equation*}
    🔗
    For \(\lambda = 1\text{,}\) \(A - I = \begin{bmatrix} \frac{1}{2} \amp -\frac{1}{2} \\ 1 \amp -1 \end{bmatrix}\) gives \(x_1 = x_2\text{,}\) so \(\vec{v}_1 = (1,1)\text{.}\) For \(\lambda = \tfrac{1}{2}\text{,}\) \(A - \tfrac{1}{2}I = \begin{bmatrix} 1 \amp -\frac{1}{2} \\ 1 \amp -\frac{1}{2} \end{bmatrix}\) gives \(x_2 = 2x_1\text{,}\) so \(\vec{v}_2 = (1,2)\text{.}\) Hence
    \begin{equation*} P = \begin{bmatrix} 1 \amp 1 \\ 1 \amp 2 \end{bmatrix}, \quad D = \begin{bmatrix} 1 \amp 0 \\ 0 \amp \frac{1}{2} \end{bmatrix}, \quad P^{-1} = \begin{bmatrix} 2 \amp -1 \\ -1 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    Then \(A^n = PD^nP^{-1}\text{,}\) and
    \begin{equation*} PD^n = \begin{bmatrix} 1 \amp \frac{1}{2^n} \\ 1 \amp \frac{2}{2^n} \end{bmatrix}, \end{equation*}
    \begin{equation*} A^n = \begin{bmatrix} 2 - \frac{1}{2^n} \amp \frac{1}{2^n} - 1 \\[2pt] 2 - \frac{1}{2^{n-1}} \amp \frac{1}{2^{n-1}} - 1 \end{bmatrix}. \end{equation*}
    🔗
    Applying this to \([20\ 10]^T\text{,}\)
    \begin{align*} x_n \amp = 20\left(2 - \tfrac{1}{2^n}\right) + 10\left(\tfrac{1}{2^n} - 1\right) = 30 - \tfrac{10}{2^n}\\ y_n \amp = 30 - \tfrac{10}{2^{n-1}}. \end{align*}
    🔗
    Check \(n = 0\text{:}\) \(x_0 = 30 - 10 = 20\) and \(y_0 = 30 - 20 = 10\text{.}\) \(\checkmark\) And \(n = 1\text{:}\) the recursion gives \(x_1 = 1.5(20) - 0.5(10) = 25\text{,}\) matching \(30 - 5\text{.}\) \(\checkmark\)
    🔗
    Both sequences tend to \(30\text{,}\) because the dominant eigenvalue is \(\lambda = 1\) and the other eigenvalue \(\tfrac{1}{2}\) contributes a term that dies away.

        🔗

      3. For every integer \(n \geq 2\text{,}\) \(A^n = 3^{n-1}\begin{bmatrix} 1 \amp 1 \\ 2 \amp 2 \end{bmatrix}\text{.}\)

    2. Let \(A = \begin{bmatrix} 2 \amp 1 \\ 1 \amp 1 \end{bmatrix} \begin{bmatrix} 2 \amp 0 \\ 0 \amp 2 \end{bmatrix} \begin{bmatrix} 1 \amp -1 \\ -1 \amp 2 \end{bmatrix}\text{.}\) Which of these is false?

        🔗
        🔗
      2. \(2\) is its only eigenvalue, of multiplicity two.
        🔗
        🔗
      3. For every \(n \geq 2\text{,}\) \(A^n = 2^n I\text{.}\)
        🔗
        🔗
      4. The general solution of \((2I - A)\vec{x} = \vec{0}\) has exactly one parameter.
        🔗
        🔗
      🔗
      🔗

    19. What Guarantees Diagonalizability?

    Let \(A\) be an \(n \times n\) matrix. Which of the following is always true?
    1. \(A\) is always diagonalizable.
      🔗
      🔗
    2. If for some \(\lambda\) the system \((\lambda I - A)\vec{x} = \vec{0}\) has infinitely many solutions, then \(A\) is diagonalizable.
      🔗
      🔗
    3. If the characteristic polynomial of \(A\) has a single root of multiplicity \(n\text{,}\) then \(A\) is diagonalizable.
      🔗
      🔗
    4. If the characteristic polynomial of \(A\) has \(n\) distinct roots, then \(A\) is diagonalizable.
      🔗
      🔗
    🔗

    🔗

    🔗
    (d) True. Eigenvectors belonging to distinct eigenvalues are linearly independent, so \(n\) distinct roots produce \(n\) independent eigenvectors, which is exactly the criterion of Theorem 8.15. See also Example 8.14.

    22. Long-Run Powers.

    Let \(A = \begin{bmatrix} 0 \amp 1 \\ \frac{1}{3} \amp \frac{2}{3} \end{bmatrix}\text{.}\) It turns out that \(P^{-1}AP = D\) where
    \begin{equation*} P = \begin{bmatrix} 1 \amp -3 \\ 1 \amp 1 \end{bmatrix}, \qquad D = \begin{bmatrix} 1 \amp 0 \\ 0 \amp -\frac{1}{3} \end{bmatrix}. \end{equation*}
    For large \(n\text{,}\) what do the entries of \(A^n\) approach?
    🔗
    Solution.
    From \(P^{-1}AP = D\) we get \(A = PDP^{-1}\) and hence \(A^n = PD^nP^{-1}\text{,}\) with
    \begin{equation*} D^n = \begin{bmatrix} 1 \amp 0 \\ 0 \amp \left(-\frac{1}{3}\right)^n \end{bmatrix}. \end{equation*}
    Since \(\left|-\tfrac{1}{3}\right| \lt 1\text{,}\) the lower-right entry tends to \(0\text{,}\) so \(D^n \to \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}\text{.}\)
    🔗
    Here \(\det P = 1 - (-3) = 4\text{,}\) so \(P^{-1} = \tfrac{1}{4}\begin{bmatrix} 1 \amp 3 \\ -1 \amp 1 \end{bmatrix}\text{.}\) Therefore
    \begin{equation*} A^n \longrightarrow \begin{bmatrix} 1 \amp -3 \\ 1 \amp 1 \end{bmatrix} \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix} \cdot \tfrac{1}{4}\begin{bmatrix} 1 \amp 3 \\ -1 \amp 1 \end{bmatrix} \end{equation*}
    \begin{equation*} = \tfrac{1}{4}\begin{bmatrix} 1 \amp 0 \\ 1 \amp 0 \end{bmatrix} \begin{bmatrix} 1 \amp 3 \\ -1 \amp 1 \end{bmatrix} = \tfrac{1}{4}\begin{bmatrix} 1 \amp 3 \\ 1 \amp 3 \end{bmatrix}. \end{equation*}
    🔗
    The columns of the limit are both multiples of the first column of \(P\text{,}\) the eigenvector for the dominant eigenvalue \(\lambda = 1\text{.}\) That is the general pattern: in the long run only the dominant eigenvalue survives, which is exactly why steady-state vectors exist for the Markov chains of Section 10.9.

    23. ★ An Eigenvalue of Multiplicity Two.

    Find the eigenvalues and eigenvectors of \(A = \begin{bmatrix} 5 \amp 1 \amp 1 \\ 0 \amp 3 \amp -2 \\ 0 \amp -1 \amp 4 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    Expand \(\det(\lambda I - A)\) down the first column:
    \begin{align*} c_A(\lambda) \amp = (\lambda - 5)\begin{vmatrix} \lambda - 3 \amp 2 \\ 1 \amp \lambda - 4 \end{vmatrix}\\ \amp = (\lambda - 5)\left[ (\lambda-3)(\lambda-4) - 2 \right]\\ \amp = (\lambda - 5)\left( \lambda^2 - 7\lambda + 10 \right)\\ \amp = (\lambda - 5)^2(\lambda - 2). \end{align*}
    So \(\lambda = 5\) has multiplicity \(2\text{,}\) and \(\lambda = 2\) has multiplicity \(1\text{.}\)
    🔗
    For \(\lambda_1 = 5\text{,}\) solve \((5I - A)\vec{x} = \vec{0}\text{:}\)
    \begin{equation*} \left[ \begin{array}{ccc|c} 0 \amp -1 \amp -1 \amp 0 \\ 0 \amp 2 \amp 2 \amp 0 \\ 0 \amp 1 \amp 1 \amp 0 \end{array} \right] \longrightarrow \left[ \begin{array}{ccc|c} 0 \amp 1 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{equation*}
    The single equation is \(y + z = 0\text{,}\) with \(x\) and \(z\) free:
    \begin{equation*} \vec{x} = s \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix} + t \begin{bmatrix} 0 \\ -1 \\ 1 \end{bmatrix}. \end{equation*}
    So \(\lambda_1 = 5\) has two basic eigenvectors, and they are not multiples of each other.
    🔗
    For \(\lambda_2 = 2\text{:}\)
    \begin{equation*} 2I - A = \begin{bmatrix} -3 \amp -1 \amp -1 \\ 0 \amp -1 \amp 2 \\ 0 \amp 1 \amp -2 \end{bmatrix}. \end{equation*}
    The second row gives \(y = 2z\text{,}\) and the first then gives \(-3x - 2z - z = 0\text{,}\) so \(x = -z\text{.}\) Taking \(z = 1\text{,}\) \(\vec{x} = (-1, 2, 1)\text{.}\)
    🔗
    Checking: \(A(0,-1,1) = (0, -3-2, 1+4) = (0,-5,5) = 5(0,-1,1)\text{,}\) and \(A(-1,2,1) = (-5+2+1, 6-2, -2+4) = (-2,4,2) = 2(-1,2,1)\text{.}\) \(\checkmark\)
    🔗
    Because the eigenvalue of multiplicity \(2\) supplies two independent eigenvectors, \(A\) has three in all and is diagonalizable — unlike Exercise 10.8.17, where the count came up short.

    24. ★ Three Distinct Eigenvalues.

    Find the eigenvalues and eigenvectors of \(B = \begin{bmatrix} 2 \amp -1 \amp 1 \\ 0 \amp 3 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    \(B\) is upper triangular, so \(\lambda I - B\) is too, and by Theorem 6.9
    \begin{equation*} c_B(\lambda) = (\lambda - 2)(\lambda - 3)(\lambda - 1). \end{equation*}
    The eigenvalues are \(\lambda_1 = 1\text{,}\) \(\lambda_2 = 2\text{,}\) \(\lambda_3 = 3\text{,}\) all of multiplicity one.
    🔗
    \(\lambda = 2\text{.}\) \(2I - B = \begin{bmatrix} 0 \amp 1 \amp -1 \\ 0 \amp -1 \amp 1 \\ 0 \amp 0 \amp 1 \end{bmatrix}\) gives \(z = 0\) from the third row and then \(y = 0\text{,}\) with \(x\) free: \(\vec{x} = (1,0,0)\text{.}\)
    🔗
    \(\lambda = 3\text{.}\) \(3I - B = \begin{bmatrix} 1 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 2 \end{bmatrix}\) gives \(z = 0\) and then \(x + y = 0\text{:}\) \(\vec{x} = (-1,1,0)\text{.}\)
    🔗
    \(\lambda = 1\text{.}\) \(I - B = \begin{bmatrix} -1 \amp 1 \amp -1 \\ 0 \amp -2 \amp 1 \\ 0 \amp 0 \amp 0 \end{bmatrix}\) gives \(z = 2y\) from the second row, and then \(-x + y - 2y = 0\text{,}\) so \(x = -y\text{:}\) \(\vec{x} = (-1,1,2)\text{.}\)
    🔗
    Checking the last one: \(B(-1,1,2) = (-2 - 1 + 2,\ 3 - 2,\ 2) = (-1,1,2)\text{.}\) \(\checkmark\) Three distinct eigenvalues give three independent eigenvectors, so \(B\) is diagonalizable by Exercise 10.8.19.

    25. ★ Two Similar Matrices.

    Let \(A = \begin{bmatrix} 1 \amp 2 \\ 3 \amp 4 \end{bmatrix}\) and \(P = \begin{bmatrix} 0 \amp 1 \\ 1 \amp 0 \end{bmatrix}\text{.}\) Compute \(PAP^{-1}\) and explain what the answer says about \(P\text{.}\)
    🔗
    Solution.
    The matrix \(P\) is its own inverse, since swapping twice restores the original: \(P^{-1} = P\text{.}\) Multiplying step by step,
    \begin{equation*} PA = \begin{bmatrix} 0 \amp 1 \\ 1 \amp 0 \end{bmatrix} \begin{bmatrix} 1 \amp 2 \\ 3 \amp 4 \end{bmatrix} = \begin{bmatrix} 3 \amp 4 \\ 1 \amp 2 \end{bmatrix}, \end{equation*}
    \begin{equation*} (PA)P^{-1} = \begin{bmatrix} 3 \amp 4 \\ 1 \amp 2 \end{bmatrix} \begin{bmatrix} 0 \amp 1 \\ 1 \amp 0 \end{bmatrix} = \begin{bmatrix} 4 \amp 3 \\ 2 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    So \(A\) and \(B = \begin{bmatrix} 4 \amp 3 \\ 2 \amp 1 \end{bmatrix}\) are similar, in the sense of Definition 8.19.
    🔗
    The two multiplications did different jobs: left multiplication by \(P\) swapped the rows of \(A\text{,}\) and right multiplication by \(P^{-1}\) swapped the columns. The net effect is to reverse both index orders at once. By Theorem 8.21, \(A\) and \(B\) have the same eigenvalues; indeed both have trace \(5\) and determinant \(-2\text{.}\)

    26. ★ Using Similarity to Find Eigenvalues.

    Find the eigenvalues of
    \begin{equation*} A = \begin{bmatrix} 5 \amp 12 \amp 6 \\ 2 \amp 5 \amp 3 \\ -4 \amp -12 \amp -7 \end{bmatrix} \end{equation*}
    by first replacing \(A\) with a similar but simpler matrix.
    🔗
    Solution.
    A row operation followed by the matching column operation produces a similar matrix. Apply \(2r_2 + r_3\text{,}\) which is left multiplication by
    \begin{equation*} E = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 2 \amp 1 \end{bmatrix}, \qquad E^{-1} = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp -2 \amp 1 \end{bmatrix}. \end{equation*}
    This gives
    \begin{equation*} EA = \begin{bmatrix} 5 \amp 12 \amp 6 \\ 2 \amp 5 \amp 3 \\ 0 \amp -2 \amp -1 \end{bmatrix}. \end{equation*}
    🔗
    Now right multiply by \(E^{-1}\text{,}\) which replaces column \(2\) by \(c_2 - 2c_3\text{:}\)
    \begin{equation*} B = (EA)E^{-1} = \begin{bmatrix} 5 \amp 0 \amp 6 \\ 2 \amp -1 \amp 3 \\ 0 \amp 0 \amp -1 \end{bmatrix}. \end{equation*}
    Since \(B = EAE^{-1}\text{,}\) the matrices \(A\) and \(B\) are similar and share their eigenvalues.
    🔗
    \(B\) has a bottom row \([\,0\ 0\ {-1}\,]\text{,}\) so expanding \(\det(\lambda I - B)\) along that row,
    \begin{align*} c_B(\lambda) \amp = (\lambda + 1)\begin{vmatrix} \lambda - 5 \amp 0 \\ -2 \amp \lambda + 1 \end{vmatrix}\\ \amp = (\lambda + 1)^2(\lambda - 5). \end{align*}
    🔗
    So the eigenvalues of \(A\) are \(\lambda = -1\text{,}\) of multiplicity \(2\text{,}\) and \(\lambda = 5\text{.}\) Two checks on \(A\) itself: the trace is \(5 + 5 - 7 = 3 = (-1) + (-1) + 5\text{,}\) and \(\det A = 5 = (-1)(-1)(5)\text{.}\) \(\checkmark\)
