    Section 5.3 Column Space, Null Space, and Rank

    Every matrix carries two subspaces with it: the span of its columns, and the set of vectors it sends to zero. Their dimensions are linked by a single identity, and together they let us restate the Invertible Matrix Theorem in geometric language.
    🔗

    Subsection 5.3.1 Column Space and Rank

    Definition 5.20. Column Space and Rank.

    Let \(A\) be an \(m \times n\) matrix.
    🔗
    • The column space of \(A\) is the span of the columns of \(A\) and is denoted by \(\operatorname{Col} A\text{.}\)
      🔗
      🔗
    • The rank of \(A\) is the dimension of the column space of \(A\) and is denoted by \(\operatorname{rank} A\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 5.21. Finding the Rank and Column Space.

    Find the rank of the matrix \(A\) and describe the column space efficiently:
    \begin{equation*} A = \begin{bmatrix} 1 \amp 2 \amp 1 \amp 3 \amp 2 \\ 1 \amp 3 \amp 6 \amp 0 \amp 2 \\ 3 \amp 7 \amp 8 \amp 6 \amp 6 \end{bmatrix}. \end{equation*}
    🔗
    Solution.
    Let us find the reduced row-echelon form of \(A\text{:}\)
    \begin{align*} \begin{bmatrix} 1 \amp 2 \amp 1 \amp 3 \amp 2 \\ 1 \amp 3 \amp 6 \amp 0 \amp 2 \\ 3 \amp 7 \amp 8 \amp 6 \amp 6 \end{bmatrix} \amp \xrightarrow[-3r_1 + r_3]{-r_1 + r_2} \begin{bmatrix} 1 \amp 2 \amp 1 \amp 3 \amp 2 \\ 0 \amp 1 \amp 5 \amp -3 \amp 0 \\ 0 \amp 1 \amp 5 \amp -3 \amp 0 \end{bmatrix}\\ \amp \xrightarrow{-r_2 + r_3} \begin{bmatrix} 1 \amp 2 \amp 1 \amp 3 \amp 2 \\ 0 \amp 1 \amp 5 \amp -3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix} \xrightarrow{-2r_2 + r_1} \begin{bmatrix} 1 \amp 0 \amp -9 \amp 9 \amp 2 \\ 0 \amp 1 \amp 5 \amp -3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}. \end{align*}
    🔗
    The pivots sit in columns \(1\) and \(2\text{.}\) Note that
    \begin{equation*} \operatorname{Col} A = \operatorname{Span}\left\{ \begin{bmatrix} 1 \\ 1 \\ 3 \end{bmatrix}, \begin{bmatrix} 2 \\ 3 \\ 7 \end{bmatrix} \right\}, \qquad \text{and hence} \qquad \operatorname{rank} A = 2. \end{equation*}
    🔗
    Why does this work? Writing \(\vec{R}_1, \ldots, \vec{R}_5\) for the columns of the reduced row-echelon matrix, note that \(\{ \vec{R}_1, \vec{R}_2 \}\) is a linearly independent set and \(\operatorname{Span}\{ \vec{R}_1, \ldots, \vec{R}_5 \} = \operatorname{Span}\{ \vec{R}_1, \vec{R}_2 \}\text{.}\) Also \(x_1\vec{R}_1 + x_2\vec{R}_2 = \vec{0}\) only has the trivial solution. Row operations do not change which linear relations hold among the columns, so similar statements hold for the columns of \(A\text{:}\)
    \begin{equation*} \operatorname{Span}\{ \vec{A}_1, \ldots, \vec{A}_5 \} = \operatorname{Span}\{ \vec{A}_1, \vec{A}_2 \}, \end{equation*}
    and \(x_1\vec{A}_1 + x_2\vec{A}_2 = \vec{0}\) only has the trivial solution.
    🔗
    🔗
    🔗

    Observation 5.23.

    The rank of \(A\) is equal to the number of pivots in \(A\text{.}\) A basis for \(\operatorname{Col} A\) is given by the columns of the original matrix \(A\) in the pivot positions.
    🔗
    🔗
    🔗

    Subsection 5.3.2 Null Space

    Definition 5.24. Null Space.

    Let \(A\) be an \(m \times n\) matrix. The null space of \(A\text{,}\) or kernel of \(A\text{,}\) is defined as
    \begin{equation*} \operatorname{Ker} A = \operatorname{Nul} A = \left\{ \vec{x} \in \R^n \; : \; A\vec{x} = \vec{0} \right\}. \end{equation*}
    🔗
    🔗

    Example 5.25. Finding a Null Space.

    Find \(\operatorname{Nul} A\) for \(A = \begin{bmatrix} 1 \amp 2 \amp 1 \\ 0 \amp -1 \amp 1 \\ 2 \amp 3 \amp 3 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    We solve \(A\vec{x} = \vec{0}\text{:}\)
    \begin{align*} \left[ \begin{array}{ccc|c} 1 \amp 2 \amp 1 \amp 0 \\ 0 \amp -1 \amp 1 \amp 0 \\ 2 \amp 3 \amp 3 \amp 0 \end{array} \right] \amp \xrightarrow{-2r_1 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 2 \amp 1 \amp 0 \\ 0 \amp -1 \amp 1 \amp 0 \\ 0 \amp -1 \amp 1 \amp 0 \end{array} \right] \xrightarrow{-r_2 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 2 \amp 1 \amp 0 \\ 0 \amp -1 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]\\ \amp \xrightarrow[-r_2]{-r_2 + r_1} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{align*}
    🔗
    With \(z = t\) free, the rows give \(y = t\) and \(x = -3t\text{,}\) so
    \begin{equation*} \vec{x} = \begin{bmatrix} x \\ y \\ z \end{bmatrix} = t \begin{bmatrix} -3 \\ 1 \\ 1 \end{bmatrix}, \qquad \text{i.e.} \qquad \operatorname{Nul} A = \operatorname{Span}\left\{ \begin{bmatrix} -3 \\ 1 \\ 1 \end{bmatrix} \right\}, \end{equation*}
    which is a line through the origin.
    🔗
    Also, since the spanning set of \(\operatorname{Nul} A\) consists of a single vector, we have \(\dim \operatorname{Nul} A = 1\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 5.3.3 The Rank–Nullity Relation

    Theorem 5.27. Rank and Nullity.

    Let \(A\) be an \(m \times n\) matrix. Then
    \begin{equation*} \operatorname{rank}(A) + \dim \operatorname{Nul} A = n. \end{equation*}
    🔗
    🔗

    Example 5.28. Checking the Rank–Nullity Relation.

    Consider \(A = \begin{bmatrix} 1 \amp 2 \amp 1 \\ 0 \amp -1 \amp 1 \\ 2 \amp 3 \amp 3 \end{bmatrix}\) from Example 5.25.
    🔗
    Solution.
    After row reduction, we saw that
    \begin{equation*} A \; \longrightarrow \; \begin{bmatrix} 1 \amp 3 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 0 \end{bmatrix}, \end{equation*}
    which has two leading \(1\)s, hence \(\operatorname{rank} A = 2\text{.}\)
    🔗
    Also, we saw that \(\dim \operatorname{Nul} A = 1\text{.}\) Furthermore \(A\) is \(3 \times 3\text{,}\) which means \(n = 3\text{.}\) Then
    \begin{equation*} \underbrace{\operatorname{rank}(A)}_{2} + \underbrace{\dim \operatorname{Nul} A}_{1} = \underbrace{n}_{3}. \checkmark \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Subsection 5.3.4 The Invertible Matrix Theorem (Continued)

    Theorem 5.30. The Invertible Matrix Theorem, Continued.

    Let \(A\) be an \(n \times n\) matrix. The following conditions are equivalent.
    🔗
    • \(A\) is an invertible matrix.
      🔗
      🔗
    • \(\operatorname{Col} A = \R^n\text{.}\)
      🔗
      🔗
    • \(\operatorname{rank} A = n\text{.}\)
      🔗
      🔗
    • \(\operatorname{Nul} A = \{ \vec{0} \}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.
    In Theorem 4.57 we discussed the following equivalences, which we can now express in terms of rank, null space, and column space of \(A\text{:}\)
    🔗
    • \(A\) is an invertible matrix \(\iff\) the columns of \(A\) are linearly independent \(\iff\) \(\operatorname{rank} A = n\text{.}\)
      🔗
      🔗
    • \(A\) is an invertible matrix \(\iff\) the columns of \(A\) span \(\R^n\) \(\iff\) \(\operatorname{Col} A = \R^n\text{.}\)
      🔗
      🔗
    • \(A\) is an invertible matrix \(\iff\) \(A\vec{X} = \vec{0}\) has only the trivial solution \(\iff\) \(\operatorname{Nul} A = \{ \vec{0} \}\text{.}\)
      🔗
      🔗
