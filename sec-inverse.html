    Section 4.4 The Inverse of a Matrix

    For a nonzero real number \(a\) there is a reciprocal \(a^{-1}\) with \(a a^{-1} = 1\text{.}\) We now ask the analogous question for matrices: given a square matrix \(A\text{,}\) is there a matrix that undoes it? Unlike the situation for real numbers, the answer can be no even when \(A\) is not the zero matrix.
    🔗

    Subsection 4.4.1 Definition and Uniqueness

    Definition 4.31. Inverse of a Matrix.

    Let \(A\) be an \(n \times n\) matrix. Then \(B\) is an inverse of \(A\) if and only if \(AB = I_n\) and \(BA = I_n\text{.}\)
    🔗
    🔗

    Remark 4.32. Question: What does this imply about the size of \(B\text{?}\)

    Let us assume \(B\) is a \(p \times k\) matrix. Then for \(AB\) to be defined we have \(p = n\text{.}\) Also, for \(BA\) to be defined we have \(k = n\text{,}\) which means \(B\) is an \(n \times n\) matrix.
    🔗
    So only square matrices can have inverses, and an inverse of an \(n \times n\) matrix is again \(n \times n\text{.}\)
    🔗
    🔗

    Theorem 4.33. Uniqueness of an Inverse.

    If \(A\) is a square matrix and \(B\) and \(C\) are inverses of \(A\text{,}\) then \(B = C\text{.}\)
    🔗
    🔗

    Proof.
    Since \(B\) and \(C\) are both inverses of \(A\text{,}\) we have
    \begin{equation*} BA = AB = I \qquad \text{and} \qquad CA = AC = I. \end{equation*}
    Therefore
    \begin{equation*} B = BI = B(AC) = (BA)C = IC = C, \end{equation*}
    where the middle equality uses the associativity of matrix multiplication.
    🔗
    🔗

    Definition 4.34. Invertible Matrix.

    Let \(A\) be a square matrix.
    🔗
    • The inverse of \(A\text{,}\) if it exists, is denoted by \(A^{-1}\text{,}\) and
      \begin{equation*} A A^{-1} = I = A^{-1} A. \end{equation*}
      🔗
      🔗
    • If \(A\) has an inverse, then we say that \(A\) is invertible.
      🔗
      🔗
    🔗
    🔗

    Remark 4.35.

    Theorem 4.33 is what entitles us to say the inverse rather than an inverse, and to give it the name \(A^{-1}\text{.}\)
    🔗
    🔗
    🔗

    Subsection 4.4.2 The Inverse of a \(2 \times 2\) Matrix

    Theorem 4.36. The Inverse of a \(2 \times 2\) Matrix.

    Suppose \(A = \begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix}\) and \(ad - bc \neq 0\text{.}\) Then
    \begin{equation*} A^{-1} = \frac{1}{ad - bc} \begin{bmatrix} d \amp -b \\ -c \amp a \end{bmatrix}. \end{equation*}
    🔗
    🔗

    Sketch.
    Finding \(A^{-1}\) amounts to solving the two systems \(A \vec{x} = \vec{e}_1\) and \(A \vec{x} = \vec{e}_2\) at once, so we row reduce the augmented matrix
    \begin{equation*} \left[ \begin{array}{cc|cc} a \amp b \amp 1 \amp 0 \\ c \amp d \amp 0 \amp 1 \end{array} \right]. \end{equation*}
    🔗
    Replacing the first row by \(d R_1 - b R_2\) and the second by \(a R_2 - c R_1\) gives
    \begin{equation*} \left[ \begin{array}{cc|cc} ad - bc \amp 0 \amp d \amp -b \\ 0 \amp ad - bc \amp -c \amp a \end{array} \right]. \end{equation*}
    If \(ad - bc \neq 0\text{,}\) we may divide each row by \(ad - bc\) to obtain \(\left[ I_2 \mid A^{-1} \right]\) with \(A^{-1}\) as claimed. If instead \(ad - bc = 0\text{,}\) the reduction produces a row of zeros on the left, the systems are inconsistent, and no inverse exists.
    🔗
    🔗

    Remark 4.37.

    In HW5, students will prove that the inverse of a \(2 \times 2\) matrix is in the form above.
    🔗
    🔗

    Example 4.38. A Matrix with No Inverse.

    Show that \(A = \begin{bmatrix} 0 \amp k \\ 0 \amp k \end{bmatrix}\text{,}\) where \(k \in \R\text{,}\) does not have an inverse.
    🔗
    Solution.
    If \(A^{-1}\) exists, write \(A^{-1} = \begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix}\text{.}\) Then
    \begin{equation*} A A^{-1} = \begin{bmatrix} 0 \amp k \\ 0 \amp k \end{bmatrix} \begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix} = \begin{bmatrix} kc \amp kd \\ kc \amp kd \end{bmatrix} = k \begin{bmatrix} c \amp d \\ c \amp d \end{bmatrix}, \end{equation*}
    which cannot be \(I_2 = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 1 \end{bmatrix}\text{,}\) since the two rows of the product are identical while the rows of \(I_2\) are not.
    🔗
    This is consistent with Theorem 4.36: here \(ad - bc = (0)(k) - (k)(0) = 0\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 4.4.3 The Matrix Inversion Algorithm

    Remark 4.39. Questions.

    Suppose that \(A\) is any \(n \times n\) matrix.
    • How do we know whether or not \(A^{-1}\) exists?
      🔗
      🔗
    • If \(A^{-1}\) exists, how do we find it?
      🔗
      🔗
    🔗
    For both questions, we use the matrix inversion algorithm.
    🔗
    🔗

    Algorithm 4.40. The Matrix Inversion Algorithm.

    Let \(A\) be an \(n \times n\) matrix. To find \(A^{-1}\text{,}\) if it exists:
    🔗
    • Take the \(n \times 2n\) matrix
      \begin{equation*} \left[ \, A \mid I_n \, \right] \end{equation*}
      obtained by augmenting \(A\) with the \(n \times n\) identity matrix, \(I_n\text{.}\)
      🔗
      🔗
    • Perform elementary row operations to transform \(\left[ \, A \mid I_n \, \right]\) into a reduced row-echelon matrix.
      🔗
      🔗
    🔗
    If the result has the form \(\left[ \, I_n \mid B \, \right]\text{,}\) then \(A\) is invertible and \(A^{-1} = B\text{.}\) If the left half cannot be reduced to \(I_n\text{,}\) then \(A\) is not invertible.
    🔗
    🔗

    Example 4.41. The Algorithm on a \(2 \times 2\) Matrix.

    Let \(A = \begin{bmatrix} 2 \amp -7 \\ 5 \amp -18 \end{bmatrix}\text{.}\) Find \(A^{-1}\text{.}\)
    🔗
    Solution.
    Augment \(A\) with \(I_2\) and row reduce:
    \begin{align*} \left[ \, A \mid I_2 \, \right] \amp = \left[ \begin{array}{cc|cc} 2 \amp -7 \amp 1 \amp 0 \\ 5 \amp -18 \amp 0 \amp 1 \end{array} \right] \xrightarrow{R_2 - 2R_1} \left[ \begin{array}{cc|cc} 2 \amp -7 \amp 1 \amp 0 \\ 1 \amp -4 \amp -2 \amp 1 \end{array} \right]\\ \amp \xrightarrow{R_1 \leftrightarrow R_2} \left[ \begin{array}{cc|cc} 1 \amp -4 \amp -2 \amp 1 \\ 2 \amp -7 \amp 1 \amp 0 \end{array} \right] \xrightarrow{R_2 - 2R_1} \left[ \begin{array}{cc|cc} 1 \amp -4 \amp -2 \amp 1 \\ 0 \amp 1 \amp 5 \amp -2 \end{array} \right]\\ \amp \xrightarrow{R_1 + 4R_2} \left[ \begin{array}{cc|cc} 1 \amp 0 \amp 18 \amp -7 \\ 0 \amp 1 \amp 5 \amp -2 \end{array} \right] = \left[ \, I_2 \mid A^{-1} \, \right]. \end{align*}
    🔗
    Therefore
    \begin{equation*} A^{-1} = \begin{bmatrix} 18 \amp -7 \\ 5 \amp -2 \end{bmatrix}. \end{equation*}
    🔗
    Note that for a \(2 \times 2\) matrix we can instead use Theorem 4.36. Here \(ad - bc = (2)(-18) - (-7)(5) = -36 + 35 = -1\text{,}\) so
    \begin{equation*} A^{-1} = \frac{1}{ad-bc} \begin{bmatrix} d \amp -b \\ -c \amp a \end{bmatrix} = \frac{1}{-1} \begin{bmatrix} -18 \amp 7 \\ -5 \amp 2 \end{bmatrix} = \begin{bmatrix} 18 \amp -7 \\ 5 \amp -2 \end{bmatrix}, \end{equation*}
    in agreement with the algorithm.
    🔗
    🔗
    🔗

    Remark 4.42.

    Although the above formula for \(A^{-1}\) is much quicker for \(2 \times 2\) matrices, as we will see later, the general formula for \(n \times n\) matrices (\(n \geq 3\)) is less efficient and more complicated to use when compared to the matrix inversion algorithm.
    🔗
    🔗

    Theorem 4.43. Matrix Inverses.

    Let \(A\) be an \(n \times n\) matrix. Then the following conditions are equivalent.
    🔗
    1. \(A\) is invertible.
      🔗
      🔗
    2. The reduced row-echelon form of \(A\) is \(I\text{.}\)
      🔗
      🔗
    3. \(\left[ \, A \mid I_n \, \right]\) can be transformed into \(\left[ \, I_n \mid A^{-1} \, \right]\) using the Matrix Inversion Algorithm.
      🔗
      🔗
    🔗
    🔗

    Proof.
    Assume that \(\left[ \, A \mid I_n \, \right]\) can be transformed into \(\left[ \, I_n \mid B \, \right]\) using elementary row operations. This means the reduced row-echelon matrix of \(A\) is \(I\text{.}\)
    🔗
    Writing the columns of \(I_n\) as \(\vec{e}_1, \ldots, \vec{e}_n\) and the columns of \(B\) as \(\vec{B}_1, \ldots, \vec{B}_n\text{,}\) the reduction is
    \begin{equation*} \left[ \, A \mid \vec{e}_1 \; \vec{e}_2 \; \cdots \; \vec{e}_n \, \right] \longrightarrow \left[ \, I_n \mid \vec{B}_1 \; \vec{B}_2 \; \cdots \; \vec{B}_n \, \right]. \end{equation*}
    🔗
    Then, for each \(i\text{,}\) the reduction \(\left[ \, A \mid \vec{e}_i \, \right] \longrightarrow \left[ \, I_n \mid \vec{B}_i \, \right]\) is possible, which means \(A \vec{x}_i = \vec{e}_i\) has the solution \(\vec{x}_i = \vec{B}_i\text{,}\) or \(A \vec{B}_i = \vec{e}_i\text{.}\) Hence
    \begin{equation*} AB = \left[ A\vec{B}_1 \; A\vec{B}_2 \; \cdots \; A\vec{B}_n \right] = \left[ \vec{e}_1 \; \vec{e}_2 \; \cdots \; \vec{e}_n \right] = I. \end{equation*}
    🔗
    Later we will show that if \(AB = I\text{,}\) then \(BA = I\) and hence \(B = A^{-1}\text{.}\) This will be shown when we study Theorem 4.57.
    🔗
    🔗

    Example 4.44. Seeing \(AB = I\) Column by Column.

    Let \(A = \begin{bmatrix} 1 \amp 2 \\ 0 \amp -1 \end{bmatrix}\text{.}\) Run the Matrix Inversion Algorithm and verify directly that \(A \vec{B}_i = \vec{e}_i\) for each column.
    🔗
    Solution.
    \begin{equation*} \left[ \, A \mid I_2 \, \right] = \left[ \begin{array}{cc|cc} 1 \amp 2 \amp 1 \amp 0 \\ 0 \amp -1 \amp 0 \amp 1 \end{array} \right] \xrightarrow{R_1 + 2R_2} \left[ \begin{array}{cc|cc} 1 \amp 0 \amp 1 \amp 2 \\ 0 \amp -1 \amp 0 \amp 1 \end{array} \right] \xrightarrow{R_2 \to -R_2} \left[ \begin{array}{cc|cc} 1 \amp 0 \amp 1 \amp 2 \\ 0 \amp 1 \amp 0 \amp -1 \end{array} \right]. \end{equation*}
    🔗
    So \(B = \begin{bmatrix} 1 \amp 2 \\ 0 \amp -1 \end{bmatrix}\text{,}\) with columns \(\vec{B}_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\) and \(\vec{B}_2 = \begin{bmatrix} 2 \\ -1 \end{bmatrix}\text{.}\) Checking directly,
    \begin{equation*} A\vec{B}_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix} = \vec{e}_1, \qquad A\vec{B}_2 = \begin{bmatrix} 0 \\ 1 \end{bmatrix} = \vec{e}_2, \end{equation*}
    and therefore
    \begin{equation*} AB = \left[ A\vec{B}_1 \; A\vec{B}_2 \right] = \left[ \vec{e}_1 \; \vec{e}_2 \right] = I. \end{equation*}
    In this example \(A\) happens to be its own inverse.
    🔗
    🔗
    🔗

    Example 4.45. The Algorithm on a \(3 \times 3\) Matrix.

    Let \(A = \begin{bmatrix} 3 \amp 1 \amp 2 \\ 1 \amp -1 \amp 3 \\ 1 \amp 2 \amp 4 \end{bmatrix}\text{.}\) Find the inverse of \(A\text{,}\) if it exists.
    🔗
    Solution.
    Augment with \(I_3\) and row reduce:
    \begin{align*} \left[ \begin{array}{ccc|ccc} 3 \amp 1 \amp 2 \amp 1 \amp 0 \amp 0 \\ 1 \amp -1 \amp 3 \amp 0 \amp 1 \amp 0 \\ 1 \amp 2 \amp 4 \amp 0 \amp 0 \amp 1 \end{array} \right] \amp \xrightarrow{R_1 \leftrightarrow R_2} \left[ \begin{array}{ccc|ccc} 1 \amp -1 \amp 3 \amp 0 \amp 1 \amp 0 \\ 3 \amp 1 \amp 2 \amp 1 \amp 0 \amp 0 \\ 1 \amp 2 \amp 4 \amp 0 \amp 0 \amp 1 \end{array} \right]\\ \amp \xrightarrow[R_3 - R_1]{R_2 - 3R_1} \left[ \begin{array}{ccc|ccc} 1 \amp -1 \amp 3 \amp 0 \amp 1 \amp 0 \\ 0 \amp 4 \amp -7 \amp 1 \amp -3 \amp 0 \\ 0 \amp 3 \amp 1 \amp 0 \amp -1 \amp 1 \end{array} \right]\\ \amp \xrightarrow{R_2 - R_3} \left[ \begin{array}{ccc|ccc} 1 \amp -1 \amp 3 \amp 0 \amp 1 \amp 0 \\ 0 \amp 1 \amp -8 \amp 1 \amp -2 \amp -1 \\ 0 \amp 3 \amp 1 \amp 0 \amp -1 \amp 1 \end{array} \right]\\ \amp \xrightarrow{R_3 - 3R_2} \left[ \begin{array}{ccc|ccc} 1 \amp -1 \amp 3 \amp 0 \amp 1 \amp 0 \\ 0 \amp 1 \amp -8 \amp 1 \amp -2 \amp -1 \\ 0 \amp 0 \amp 25 \amp -3 \amp 5 \amp 4 \end{array} \right]\\ \amp \xrightarrow{R_1 + R_2} \left[ \begin{array}{ccc|ccc} 1 \amp 0 \amp -5 \amp 1 \amp -1 \amp -1 \\ 0 \amp 1 \amp -8 \amp 1 \amp -2 \amp -1 \\ 0 \amp 0 \amp 25 \amp -3 \amp 5 \amp 4 \end{array} \right]\\ \amp \xrightarrow{\frac{1}{25} R_3} \left[ \begin{array}{ccc|ccc} 1 \amp 0 \amp -5 \amp 1 \amp -1 \amp -1 \\ 0 \amp 1 \amp -8 \amp 1 \amp -2 \amp -1 \\ 0 \amp 0 \amp 1 \amp \frac{-3}{25} \amp \frac{5}{25} \amp \frac{4}{25} \end{array} \right]\\ \amp \xrightarrow[R_1 + 5R_3]{R_2 + 8R_3} \left[ \begin{array}{ccc|ccc} 1 \amp 0 \amp 0 \amp \frac{10}{25} \amp 0 \amp \frac{-5}{25} \\ 0 \amp 1 \amp 0 \amp \frac{1}{25} \amp \frac{-10}{25} \amp \frac{7}{25} \\ 0 \amp 0 \amp 1 \amp \frac{-3}{25} \amp \frac{5}{25} \amp \frac{4}{25} \end{array} \right] = \left[ \, I_3 \mid A^{-1} \, \right]. \end{align*}
    🔗
    Therefore
    \begin{equation*} A^{-1} = \begin{bmatrix} \frac{10}{25} \amp 0 \amp \frac{-5}{25} \\[2pt] \frac{1}{25} \amp \frac{-10}{25} \amp \frac{7}{25} \\[2pt] \frac{-3}{25} \amp \frac{5}{25} \amp \frac{4}{25} \end{bmatrix} = \frac{1}{25} \begin{bmatrix} 10 \amp 0 \amp -5 \\ 1 \amp -10 \amp 7 \\ -3 \amp 5 \amp 4 \end{bmatrix}. \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Subsection 4.4.4 The Inverse and the Matrix Equation \(A\vec{x} = \vec{b}\)

    If \(A\) is invertible, the matrix equation \(A\vec{x} = \vec{b}\) can be solved in one stroke by multiplying both sides on the left by \(A^{-1}\text{:}\)
    \begin{align*} A^{-1} \left( A \vec{x} \right) \amp = A^{-1} \vec{b}\\ \left( A^{-1} A \right) \vec{x} \amp = A^{-1} \vec{b}\\ I \vec{x} \amp = A^{-1} \vec{b}\\ \vec{x} \amp = A^{-1} \vec{b}. \end{align*}
    🔗

    Example 4.46. Solving a System Using the Inverse.

    Consider the system of linear equations
    \begin{align*} 2x - 7y \amp = 3\\ 5x - 18y \amp = 8 \end{align*}
    and use the concept of the inverse of a matrix to solve the system.
    🔗
    Solution.
    We can write the matrix equation \(A\vec{x} = \vec{b}\) as follows:
    \begin{equation*} A \vec{x} = \begin{bmatrix} 2 \amp -7 \\ 5 \amp -18 \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \underbrace{\begin{bmatrix} 3 \\ 8 \end{bmatrix}}_{\vec{b}}. \end{equation*}
    🔗
    We computed \(A^{-1}\) in Example 4.41, so
    \begin{equation*} \vec{x} = A^{-1} \vec{b} = \begin{bmatrix} 18 \amp -7 \\ 5 \amp -2 \end{bmatrix} \begin{bmatrix} 3 \\ 8 \end{bmatrix} = \begin{bmatrix} -2 \\ -1 \end{bmatrix}. \end{equation*}
    That is, \(x = -2\) and \(y = -1\) is a unique solution for this system.
    🔗
    How do we know \(\vec{x}\) is a unique solution? Let us assume that there exists more than one solution. For example, if \(\vec{w}\) is another solution, then we can repeat the above process to show that \(\vec{w} = A^{-1}\vec{b}\text{.}\) Also, since \(\vec{x} = A^{-1}\vec{b}\text{,}\) we get \(\vec{x} = \vec{w}\text{,}\) which means \(\vec{x}\) and \(\vec{w}\) are the same.
    🔗
    🔗
    🔗

    Subsection 4.4.5 Inverses of Transposes and Products

    Theorem 4.47. Inverses of Transposes and Products.

    1. If \(A\) is an invertible matrix, then \(\left( A^T \right)^{-1} = \left( A^{-1} \right)^T\text{.}\)
      🔗
      🔗
    2. If \(A\) and \(B\) are invertible matrices, then \(AB\) is invertible and \((AB)^{-1} = B^{-1}A^{-1}\text{.}\)
      🔗
      🔗
    3. If \(A_1, A_2, \ldots, A_k\) are invertible, then \(A_1 A_2 \cdots A_k\) is invertible and
      \begin{equation*} \left( A_1 A_2 \cdots A_k \right)^{-1} = A_k^{-1} A_{k-1}^{-1} \cdots A_2^{-1} A_1^{-1}. \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof of (1).
    If \(A\) is an invertible matrix, then \(A A^{-1} = I\text{,}\) which means
    \begin{equation*} \left( A A^{-1} \right)^T = I^T \qquad \Longrightarrow \qquad \left( A^{-1} \right)^T A^T = I. \end{equation*}
    Also, since \(A^{-1} A = I\text{,}\)
    \begin{equation*} \left( A^{-1} A \right)^T = I^T \qquad \Longrightarrow \qquad A^T \left( A^{-1} \right)^T = I. \end{equation*}
    🔗
    Both equations together say that \(\left( A^{-1} \right)^T\) is an inverse of \(A^T\text{,}\) and so
    \begin{equation*} \left( A^{-1} \right)^T = \left( A^T \right)^{-1}. \end{equation*}
    🔗
    🔗

    Remark 4.48.

    The proofs of (2) and (3) are left to the reader. For (2), it suffices to verify that \(\left( B^{-1}A^{-1} \right)(AB) = I\) and \((AB)\left( B^{-1}A^{-1} \right) = I\text{;}\) part (3) then follows by induction on \(k\text{.}\) Note that, as with the transpose of a product, taking inverses reverses the order of the factors.
