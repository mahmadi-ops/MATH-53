    Section 6.3 Determinants of Inverses, Products, and Transposes

    Subsection 6.3.1 The Determinant Detects Invertibility

    Theorem 6.16. Invertibility and the Determinant.

    An \(n \times n\) matrix \(A\) is invertible (Statement 1) if and only if \(\det A \neq 0\) (Statement 2). In this case,
    \begin{equation*} \det(A^{-1}) = \frac{1}{\det A}. \end{equation*}
    🔗
    🔗

    Proof.
    Statement 1 \(\Longrightarrow\) Statement 2. If \(A_{n \times n}\) is invertible, then we know that \(\left[ A \mid I \right]\) can be carried to \(\left[ I \mid A^{-1} \right]\) by elementary operations. We also know that elementary operations are reversible. Hence \(A\) can be obtained from \(I\) by performing a sequence of elementary operations. By Theorem 6.11, each such operation multiplies the determinant by a nonzero factor, so we conclude that \(\det A = \alpha \det I = \alpha\text{,}\) where \(\alpha \in \R\) and \(\alpha \neq 0\text{.}\)
    🔗
    Statement 2 \(\Longrightarrow\) Statement 1. We show that if Statement 1 is NOT true, then Statement 2 is NOT true. If \(A\) is not invertible, then \(A\) must have fewer than \(n\) pivot positions. This means the reduced row-echelon matrix will have at least one zero on its main diagonal, and since that matrix is upper triangular, its determinant is the product of the entries on the main diagonal, and hence \(\det A = 0\text{.}\)
    🔗
    The fact that \(\det A^{-1} = \dfrac{1}{\det A}\) is shown in Corollary 6.20, after we discuss \(\det(AB) = \det A \det B\text{.}\)
    🔗
    🔗

    Example 6.17. True or False?

    If \(A\) and \(B\) are two square matrices and \(A\) is not invertible, then \(AB\) is not invertible.
    🔗
    Solution.
    True. We show the contrapositive: if \(AB\) is invertible, then \(A\) is invertible. Note that if \(AB\) is invertible, then there exists a matrix \(C\) such that \((AB)C = I\text{,}\) which means \(A(BC) = I\text{.}\) By condition (8) of Theorem 4.57, \(A\) is invertible with \(A^{-1} = BC\text{.}\)
    🔗
    🔗
    🔗
    🔗

    Subsection 6.3.2 The Determinant of a Product

    Example 6.18. True or False?

    For any elementary matrix \(E\) and square matrix \(M\text{,}\) we have
    \begin{equation*} \det(EM) = \det(E) \det(M). \end{equation*}
    🔗
    Solution.
    True. We check the three types of elementary matrix in turn, using Observation 4.53 (left multiplication by \(E\) performs the corresponding row operation) together with Theorem 6.11.
    🔗
    (I) If \(E\) represents exchange of two rows, then \(\det E = -1\text{.}\) Also, \(\det(EM) = -\det M\text{,}\) since the product \(EM\) is equivalent to exchange of two rows. Hence \(\det(EM) = \det E \det M\text{.}\)
    🔗
    (II) If \(E\) represents the multiplication of the \(i\)th row by a constant \(k\text{,}\) then \(\det E = k\) and \(\det(EM) = k \det M = \det E \det M\text{.}\)
    🔗
    (III) If \(E\) represents adding \(k\) times row \(i\) to row \(j\text{,}\) then \(\det E = 1\) and \(\det(EM) = \det M = \det E \det M\text{.}\)
    🔗
    🔗
    🔗

    Theorem 6.19. Determinant of a Product.

    Let \(A\) and \(B\) be \(n \times n\) matrices. Then
    \begin{equation*} \det(AB) = \det A \times \det B. \end{equation*}
    🔗
    🔗

    Proof.
    Case (I): \(A\) is not invertible. If \(A\) is not invertible, then \(\det A = 0\text{.}\) Also, if \(A\) is not invertible, then \(AB\) is not invertible by Example 6.17, and so \(\det(AB) = 0\text{.}\) Hence, in this case, \(\det(AB) = 0 = \det A \det B\text{.}\)
    🔗
    Case (II): \(A\) is invertible. Hence \(A\) can be written as a product of elementary matrices,
    \begin{equation*} A = E_1 E_2 \cdots E_p, \end{equation*}
    and \(\det(AB) = \det \left( E_1 E_2 \cdots E_p B \right)\text{.}\) Next, we can use Example 6.18 repeatedly to write
    \begin{align*} \det(AB) \amp = \det E_1 \, \det \left( E_2 \cdots E_p B \right)\\ \amp = \det E_1 \, \det E_2 \, \det \left( E_3 \cdots E_p B \right)\\ \amp \;\; \vdots\\ \amp = \det E_1 \, \det E_2 \, \cdots \, \det E_p \, \det B. \end{align*}
    🔗
    Now run the same identity backwards to reassemble \(A\text{:}\)
    \begin{align*} \det(AB) \amp = \det \left( E_1 E_2 \right) \det E_3 \cdots \det E_p \, \det B\\ \amp \;\; \vdots\\ \amp = \det \left( E_1 E_2 \cdots E_p \right) \det B = \det A \, \det B. \end{align*}
    🔗
    🔗

    Corollary 6.20. Determinant of an Inverse.

    If \(A\) is invertible, then \(\det A^{-1} = \dfrac{1}{\det A}\text{.}\)
    🔗
    🔗

    Proof.
    Since \(A A^{-1} = I\text{,}\) then
    \begin{equation*} \det \left( A A^{-1} \right) = \det A \, \det A^{-1} = \det I = 1, \end{equation*}
    hence
    \begin{equation*} \det A^{-1} = \frac{1}{\det A}. \end{equation*}
    🔗
    🔗

    Theorem 6.21. Determinant of a Transpose.

    If \(A\) is an \(n \times n\) matrix, then the determinant of its transpose is given by
    \begin{equation*} \det(A^T) = \det A. \end{equation*}
    🔗
    🔗
    🔗

    Subsection 6.3.3 Putting the Rules Together

    Example 6.22. A Determinant of a Complicated Product.

    Suppose \(A\text{,}\) \(B\) and \(C\) are \(4 \times 4\) matrices with \(\det A = -1\text{,}\) \(\det B = 2\text{,}\) and \(\det C = 1\text{.}\) Find \(\det \left( 2A^2 (B^{-1}) (C^T)^3 B (A^{-1}) \right)\text{.}\)
    🔗
    Solution.
    \begin{align*} \det \left( 2A^2 (B^{-1}) (C^T)^3 B (A^{-1}) \right) \amp = \left( 2^4 \right) \det(A^2) \, \det(B^{-1}) \, \det \left( (C^T)^3 \right) \det(B) \, \det(A^{-1})\\ \amp = \left( 2^4 \right) \left( \det A \right)^2 \frac{1}{\det B} \left( \det C \right)^3 \det B \frac{1}{\det A}\\ \amp = \left( 2^4 \right) (1) \left( \frac{1}{2} \right) (1) (2) (-1)\\ \amp = -16. \end{align*}
    🔗
    Note where each rule was used: the factor \(2^4\) comes from Theorem 6.14 with \(n = 4\text{;}\) the product splits by Theorem 6.19; the reciprocals come from Corollary 6.20; and \(\det(C^T) = \det C\) by Theorem 6.21.
