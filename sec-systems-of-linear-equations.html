    Section 1.1 Systems of Linear Equations

    Linear algebra begins with a very concrete question: given several linear equations in several unknowns, which assignments of values to the unknowns satisfy all of them at once? This section fixes the vocabulary and looks at what the answer can look like.
    🔗

    Subsection 1.1.1 Systems, Solutions, and Consistency

    Example 1.1. The Parts of a System.

    The following is a system of linear equations:
    \begin{align*} x_1 - 2x_2 - 7x_3 \amp = -1\\ -x_1 + 3x_2 + 6x_3 \amp = 0 \end{align*}
    🔗
    • The variables are \(x_1\text{,}\) \(x_2\text{,}\) \(x_3\text{.}\)
      🔗
      🔗
    • The coefficients are the numbers multiplying the variables: \(1, -2, -7\) in the first equation and \(-1, 3, 6\) in the second.
      🔗
      🔗
    • The constant terms are the numbers on the right-hand sides: \(-1\) and \(0\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Definition 1.2. Solution of a System.

    A solution to a system of linear equations is an assignment of values to the variables that is a solution to every equation in the system.
    🔗
    🔗

    Example 1.3. Checking Candidate Solutions.

    For the system of Example 1.1, decide which of the following are solutions:
    \begin{align*} \text{(a) } \amp x_1 = -3, \; x_2 = -1, \; x_3 = 0,\\ \text{(b) } \amp x_1 = 6, \; x_2 = 0, \; x_3 = 1,\\ \text{(c) } \amp x_1 = 0, \; x_2 = 0, \; x_3 = 0. \end{align*}
    🔗
    Solution.
    (a) is a solution. Substituting,
    \begin{align*} (-3) - 2(-1) - 7(0) \amp = -3 + 2 = -1, \checkmark\\ -(-3) + 3(-1) + 6(0) \amp = 3 - 3 = 0. \checkmark \end{align*}
    🔗
    (b) is also a solution. Substituting,
    \begin{align*} 6 - 2(0) - 7(1) \amp = 6 - 7 = -1, \checkmark\\ -6 + 3(0) + 6(1) \amp = -6 + 6 = 0. \checkmark \end{align*}
    🔗
    (c) is not a solution. The first equation gives \(0 - 0 - 0 = 0 \neq -1\text{.}\) It fails the first equation, and a solution must satisfy every equation in the system.
    🔗
    🔗
    🔗

    Definition 1.4. Consistent and Inconsistent Systems.

    A system of linear equations is consistent if it has at least one solution, and inconsistent if it has no solutions.
    🔗
    🔗

    Example 1.5. An Inconsistent System.

    The system of Example 1.1 is consistent, since we exhibited two solutions above. By contrast, consider
    \begin{align*} x_1 + x_2 + x_3 \amp = 0\\ x_1 + x_2 + x_3 \amp = -8 \end{align*}
    Why is the above system inconsistent?
    🔗
    Solution.
    The two equations have identical left-hand sides. Any assignment of values to \(x_1, x_2, x_3\) produces one and the same number \(x_1 + x_2 + x_3\text{,}\) and that single number cannot equal both \(0\) and \(-8\text{.}\) Hence no assignment satisfies both equations, and the system has no solutions.
    🔗
    🔗
    🔗
    🔗

    Subsection 1.1.2 Graphical Solutions

    Example 1.6. Two Equations in Two Variables.

    Consider the system of linear equations in two variables
    \begin{align*} x + y \amp = 1\\ y - x \amp = 1 \end{align*}
    🔗
    A solution to this system is a pair of real numbers \((x,y)\) satisfying these two equations. Graphically, a solution to this system is the point of intersection of these two lines.
    🔗
    Solution.
    Add the equations:
    \begin{equation*} 2y = 2, \qquad \text{so} \qquad y = 1. \end{equation*}
    Substitute \(y = 1\) into one of the equations:
    \begin{equation*} x + 1 = 1, \qquad \text{so} \qquad x = 0. \end{equation*}
    The unique solution is \((x,y) = (0,1)\text{,}\) which is exactly the point where the two lines cross.
    🔗
    🔗
    🔗
    Given a system of two equations in two variables, graphed on the \(xy\)-coordinate plane, there are three possibilities.
    🔗

    Example 1.9. A System with Infinitely Many Solutions.

    The system
    \begin{align*} x - y \amp = 0\\ 2x - 2y \amp = 0 \end{align*}
    illustrates the third case. The second equation is just twice the first, so both equations describe the same line \(y = x\text{.}\) Every point on that line is a solution, and there are infinitely many of them.
    🔗
    🔗
    🔗

    Subsection 1.1.3 Parametric Form of a Solution Set

    Example 1.10. Describing Infinitely Many Solutions.

    The system of linear equations in three variables that we saw earlier,
    \begin{align*} x_1 - 2x_2 - 7x_3 \amp = -1\\ -x_1 + 3x_2 + 6x_3 \amp = 0, \end{align*}
    has solutions \(x_1 = -3 + 9s\text{,}\) \(x_2 = -1 + s\text{,}\) \(x_3 = s\text{,}\) where \(s\) is any real number (\(s \in \R\)).
    🔗
    Solution.
    The number \(s\) is called a parameter, and
    \begin{equation*} x_1 = -3 + 9s, \quad x_2 = -1 + s, \quad x_3 = s, \quad \text{where } s \in \R \end{equation*}
    is called the solution set in parametric form.
    🔗
    Notice that the two solutions we found in Example 1.3 are recovered by taking \(s = 0\) and \(s = 1\text{:}\)
    \begin{align*} s = 0 \amp \;\longrightarrow\; (x_1, x_2, x_3) = (-3, -1, 0),\\ s = 1 \amp \;\longrightarrow\; (x_1, x_2, x_3) = (6, 0, 1). \end{align*}
    🔗
    🔗
    🔗

    Remark 1.11. Question: What is the graphical interpretation of the solution set in this example?

    Each of the two equations describes a plane in \(\R^3\text{.}\) The intersection of two planes is a line, whose parametric equations are the solution set for the above system of linear equations.
    🔗
    🔗
    This raises the central computational problem of the chapter.
    🔗

    Remark 1.12. Problem.

    Find all solutions to a system of \(m\) linear equations in \(n\) variables, i.e., solve a system of linear equations.
