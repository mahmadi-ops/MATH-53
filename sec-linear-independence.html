    Section 2.5 Linear Independence

    Subsection 2.5.1 Definition and First Examples

    Definition 2.35. Linearly Independent Set of Vectors.

    Let \(\{ \vec{u}_1, \vec{u}_2, \ldots, \vec{u}_k \}\) be a set of vectors in \(\R^n\text{.}\) This set is linearly independent if no vector in the set is in the span of the other vectors of that set.
    🔗
    🔗

    Example 2.36. Testing Independence from the Definition.

    Consider the vectors
    \begin{equation*} \vec{u} = \begin{bmatrix} 0 \\ 1 \\ 2 \end{bmatrix}, \qquad \vec{v} = \begin{bmatrix} 0 \\ 2 \\ 3 \end{bmatrix}, \qquad \vec{w} = \begin{bmatrix} 1 \\ 0 \\ 2 \end{bmatrix}. \end{equation*}
    Is the set \(\{ \vec{u}, \vec{v}, \vec{w} \}\) linearly independent?
    🔗
    Solution.
    (I) We can easily see that \(\vec{w}\) is not in \(\operatorname{Span}\{ \vec{u}, \vec{v} \}\text{,}\) since that span is the \(yz\)-plane by Example 2.26, while the first entry of \(\vec{w}\) is \(1 \neq 0\text{.}\)
    🔗
    (II) Solving \(x_1 \vec{v} + x_2 \vec{w} = \vec{u}\) leads to
    \begin{equation*} \left[ \begin{array}{cc|c} 0 \amp 1 \amp 0 \\ 2 \amp 0 \amp 1 \\ 3 \amp 2 \amp 2 \end{array} \right] \longrightarrow \left[ \begin{array}{cc|c} 1 \amp 0 \amp \frac{1}{2} \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp -\frac{1}{4} \end{array} \right], \end{equation*}
    which has no solution. Hence \(\vec{u}\) is not in \(\operatorname{Span}\{ \vec{v}, \vec{w} \}\text{.}\)
    🔗
    (III) Similarly, one can show that \(x_1 \vec{u} + x_2 \vec{w} = \vec{v}\) has no solution, which means \(\vec{v}\) is not in \(\operatorname{Span}\{ \vec{u}, \vec{w} \}\text{.}\)
    🔗
    From (I), (II), and (III), we can conclude that \(\{ \vec{u}, \vec{v}, \vec{w} \}\) is a linearly independent set.
    🔗
    🔗
    🔗
    🔗

    Subsection 2.5.2 Linear Independence as a Linear Combination

    Checking every vector against the span of all the others, as we just did, is laborious. The following theorem provides a familiar way to check if a set of vectors is linearly independent.
    🔗

    Theorem 2.37. Independence and the Trivial Solution.

    The collection of vectors \(\{ \vec{u}_1, \ldots, \vec{u}_k \}\) in \(\R^n\) is linearly independent if and only if whenever
    \begin{equation*} \sum_{i=1}^{k} a_i \vec{u}_i = \vec{0} \end{equation*}
    it follows that each \(a_i = 0\text{.}\)
    🔗
    Thus \(\{ \vec{u}_1, \ldots, \vec{u}_k \}\) in \(\R^n\) is linearly independent exactly when the system of linear equations \(AX = 0\) has only the trivial solution, where \(A\) is the \(n \times k\) matrix having these vectors as columns.
    🔗
    🔗

    Proof.
    If some \(a_i \neq 0\text{,}\) we may solve for \(\vec{u}_i\) in terms of the other vectors, exhibiting \(\vec{u}_i\) as a member of the span of the others. Conversely, if some \(\vec{u}_i\) lies in the span of the others, say \(\vec{u}_i = \sum_{j \neq i} c_j \vec{u}_j\text{,}\) then \(\sum_{j \neq i} c_j \vec{u}_j - \vec{u}_i = \vec{0}\) is a nontrivial relation, since the coefficient of \(\vec{u}_i\) is \(-1 \neq 0\text{.}\)
    🔗
    🔗

    Example 2.38. Expressing a Vector as a Linear Combination.

    Let
    \begin{equation*} A = \begin{bmatrix} 1 \amp 0 \amp 2 \amp -1 \\ 2 \amp -1 \amp 0 \amp 1 \\ 3 \amp 1 \amp 3 \amp 1 \end{bmatrix} \qquad \text{and} \qquad B = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}. \end{equation*}
    Express \(B\) as a linear combination of the columns \(A_1, A_2, A_3, A_4\) of \(A\text{,}\) or show that this is impossible.
    🔗
    Solution.
    Consider \(C = \begin{bmatrix} A \amp \vec{B} \end{bmatrix}\text{.}\) As stated in Theorem 2.37, if \(C\vec{X} = \vec{0}\) has only the trivial solution, then \(\{ \vec{A}_1, \vec{A}_2, \vec{A}_3, \vec{A}_4, \vec{B} \}\) is a linearly independent set. If this is the case, we will not be able to write \(\vec{B}\) as a linear combination of the columns of \(A\text{.}\)
    🔗
    Also, if \(C\vec{X} = \vec{0}\) has a nontrivial solution, then we have
    \begin{equation*} a_1 \vec{A}_1 + a_2 \vec{A}_2 + a_3 \vec{A}_3 + a_4 \vec{A}_4 + a_5 \vec{B} = \vec{0}, \end{equation*}
    and if \(a_5 \neq 0\text{,}\) then
    \begin{equation*} \vec{B} = -\frac{1}{a_5} \left( a_1 \vec{A}_1 + a_2 \vec{A}_2 + a_3 \vec{A}_3 + a_4 \vec{A}_4 \right). \end{equation*}
    🔗
    Row reducing,
    \begin{align*} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 2 \amp -1 \amp 0 \amp 1 \amp 1 \amp 0 \\ 3 \amp 1 \amp 3 \amp 1 \amp 1 \amp 0 \end{array} \right] \amp \xrightarrow[-3r_1 + r_3]{-2r_1 + r_2} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp -1 \amp -4 \amp 3 \amp -1 \amp 0 \\ 0 \amp 1 \amp -3 \amp 4 \amp -2 \amp 0 \end{array} \right]\\ \amp \xrightarrow{r_2 + r_3} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp -1 \amp -4 \amp 3 \amp -1 \amp 0 \\ 0 \amp 0 \amp -7 \amp 7 \amp -3 \amp 0 \end{array} \right]\\ \amp \xrightarrow[-\frac{1}{7} r_3]{-r_2} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 4 \amp -3 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \amp -1 \amp \frac{3}{7} \amp 0 \end{array} \right]. \end{align*}
    🔗
    With \(x_4 = s\) and \(x_5 = t\) free, back-substitution gives
    \begin{align*} x_1 \amp = -s - \tfrac{1}{7}t\\ x_2 \amp = -s + \tfrac{5}{7}t\\ x_3 \amp = s - \tfrac{3}{7}t\\ x_4 \amp = s\\ x_5 \amp = t, \qquad \text{where } s, t \in \R. \end{align*}
    🔗
    For \(s = 1\) and \(t = -1\) we get \(x_1 = -\frac{6}{7}\text{,}\) \(x_2 = -\frac{12}{7}\text{,}\) \(x_3 = \frac{10}{7}\text{,}\) \(x_4 = 1\text{,}\) \(x_5 = -1\text{,}\) so
    \begin{equation*} -\tfrac{6}{7}\vec{A}_1 - \tfrac{12}{7}\vec{A}_2 + \tfrac{10}{7}\vec{A}_3 + \vec{A}_4 - \vec{B} = \vec{0}. \end{equation*}
    Since \(a_5 = -1 \neq 0\text{,}\) we may solve for \(\vec{B}\text{.}\) As an example, \(\vec{B}\) can be written as the following linear combination of the columns of \(A\text{:}\)
    \begin{equation*} \vec{B} = -\tfrac{6}{7}\vec{A}_1 - \tfrac{12}{7}\vec{A}_2 + \tfrac{10}{7}\vec{A}_3 + \vec{A}_4. \end{equation*}
    🔗
    🔗
    🔗

    Theorem 2.39. Too Many Vectors.

    Any set \(\{ \vec{A}_1, \vec{A}_2, \ldots, \vec{A}_k \}\) in \(\R^n\) is linearly dependent if \(k \gt n\text{.}\)
    🔗
    🔗

    Remark 2.40.

    In Example 2.38 above, the set \(\{ \vec{A}_1, \vec{A}_2, \vec{A}_3, \vec{A}_4, \vec{B} \}\) in \(\R^3\) was shown to be a linearly dependent set. Note that the number of vectors in the set is more than the number of entries in each vector.
    🔗
    The reason is that the associated homogeneous system has \(n\) equations in \(k\) unknowns; with \(k \gt n\) there are at most \(n\) pivots and hence at least one free variable, so a nontrivial solution exists.
    🔗
    🔗
    🔗

    Subsection 2.5.3 Seeing Dependence

    Geometrically, dependence is a collapse. Two vectors in \(\R^3\) normally span a plane; if one is a multiple of the other, the span drops to a line. Three vectors normally span all of \(\R^3\text{;}\) if they happen to lie on a common plane through the origin, the span drops to that plane. In each case the set is dependent exactly when the span is smaller than it ought to be.
    🔗

    Remark 2.44.

    This is Definition 2.35 made visible. In the second figure \(\vec{v}_2\) lies in \(\operatorname{Span}\{\vec{v}_1\}\text{;}\) in the third, \(\vec{v}_3\) lies in \(\operatorname{Span}\{\vec{v}_1, \vec{v}_2\}\text{.}\) Each redundant vector is one the span was already reaching, which is why adding it buys no new dimension.
    🔗
    🔗
    🔗

    Subsection 2.5.4 A Harder Example

    Example 2.45. Independence of the Pairwise Sums.

    Let \(\vec{u}\text{,}\) \(\vec{v}\text{,}\) \(\vec{w}\) be vectors in \(\R^n\text{.}\) Show that
    \begin{align*} \{ \vec{u}, \vec{v}, \vec{w} \} \amp \text{ is linearly independent}\\ \Longleftrightarrow \quad \{ \vec{u} + \vec{v}, \; \vec{v} + \vec{w}, \; \vec{w} + \vec{u} \} \amp \text{ is linearly independent}. \end{align*}
    🔗
    Solution.
    Both directions rest on one computation. For scalars \(a, b, c\text{,}\) regrouping gives
    \begin{align*} a(\vec{u} + \vec{v}) + b(\vec{v} + \vec{w}) + c(\vec{w} + \vec{u})\\ \amp = (a + c)\vec{u} + (a + b)\vec{v} + (b + c)\vec{w}. \end{align*}
    🔗
    (\(\Rightarrow\)) Suppose \(\{\vec{u}, \vec{v}, \vec{w}\}\) is linearly independent, and suppose the left-hand side above is \(\vec{0}\text{.}\) Then all three coefficients on the right must vanish:
    \begin{equation*} a + c = 0, \qquad a + b = 0, \qquad b + c = 0. \end{equation*}
    The first two give \(c = -a\) and \(b = -a\text{;}\) substituting into the third gives \(-2a = 0\text{,}\) so \(a = 0\) and then \(b = c = 0\text{.}\) Only the trivial combination gives \(\vec{0}\text{,}\) so the pairwise sums are linearly independent by Theorem 2.37.
    🔗
    (\(\Leftarrow\)) We prove the contrapositive. Suppose \(\{\vec{u}, \vec{v}, \vec{w}\}\) is linearly dependent, so there are scalars \(x, y, z\text{,}\) not all zero, with \(x\vec{u} + y\vec{v} + z\vec{w} = \vec{0}\text{.}\) We want \(a, b, c\text{,}\) not all zero, with \(a + c = x\text{,}\) \(a + b = y\text{,}\) \(b + c = z\text{.}\) That is the system
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 1 \\ 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 1 \end{bmatrix} \begin{bmatrix} a \\ b \\ c \end{bmatrix} = \begin{bmatrix} x \\ y \\ z \end{bmatrix}, \end{equation*}
    and the coefficient matrix has determinant \(1(1) - 0 + 1(1) = 2 \neq 0\text{.}\) By Theorem 4.57 it is invertible, so the system has a unique solution \((a,b,c)\text{;}\) and since \((x,y,z) \neq \vec{0}\text{,}\) that solution is not \(\vec{0}\) either.
    🔗
    For this choice of \(a, b, c\) the displayed identity gives
    \begin{equation*} a(\vec{u} + \vec{v}) + b(\vec{v} + \vec{w}) + c(\vec{w} + \vec{u}) = x\vec{u} + y\vec{v} + z\vec{w} = \vec{0}, \end{equation*}
    a nontrivial dependence among the pairwise sums. So dependence of \(\{\vec{u}, \vec{v}, \vec{w}\}\) forces dependence of the sums, which is the contrapositive of the direction we wanted.
    🔗
    A warning. The \(2\) in that determinant is doing real work. The same argument with four vectors and the cyclic sums \(\vec{u}_1 + \vec{u}_2, \; \vec{u}_2 + \vec{u}_3, \; \vec{u}_3 + \vec{u}_4, \; \vec{u}_4 + \vec{u}_1\) fails: those four sums always satisfy
    \begin{equation*} (\vec{u}_1 + \vec{u}_2) - (\vec{u}_2 + \vec{u}_3) + (\vec{u}_3 + \vec{u}_4) - (\vec{u}_4 + \vec{u}_1) = \vec{0}, \end{equation*}
    so they are dependent no matter how independent the \(\vec{u}_i\) are.
