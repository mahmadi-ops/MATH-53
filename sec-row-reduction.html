    Section 1.4 The Row Reduction Algorithm

    We now have all the pieces: elementary row operations preserve the solution set, and echelon forms make the solution set easy to read off. The row reduction algorithm ties them together into a procedure that solves any system of linear equations.
    🔗

    Subsection 1.4.1 The Algorithm

    Algorithm 1.32 The Row Reduction Algorithm.

    1. Starting with the whole matrix, choose the leftmost column containing a nonzero entry among the remaining rows. If all remaining rows are zero, the forward phase is finished.
      🔗
      🔗
    2. Interchange rows if necessary to put a nonzero entry of that column in the top remaining row. This entry is the next pivot.
      🔗
      🔗
    3. Use row replacements to create zeros below the pivot.
      🔗
      🔗
    4. Continue with the rows strictly below the pivot row and the columns strictly to the right of the pivot column. Repeat steps 1–3 until no rows or columns remain, or the remaining rows are zero. The matrix is now in row-echelon form.
      🔗
      🔗
    5. Beginning with the rightmost pivot and working left, divide each pivot row by its pivot to make it \(1\text{,}\) then use row replacements to create zeros above it. The result is reduced row-echelon form.
      🔗
      🔗
    🔗
    🔗

    Remark 1.33.

    Note that steps 1–4 will produce a row-echelon matrix, and step 5 will convert it to a reduced row-echelon matrix:
    • Steps 1–4: the forward phase, to obtain a row-echelon form (REF).
      🔗
      🔗
    • Step 5: the backward phase, to obtain the reduced row-echelon form (RREF).
      🔗
      🔗
    The forward phase involves choices — which nonzero entry to swap into the pivot row, for instance — and different choices produce different row-echelon matrices. The backward phase removes all such differences: by Theorem 1.30, everyone who row reduces the same matrix arrives at the same reduced row-echelon form.
    🔗
    🔗
    🔗

    Subsection 1.4.2 The Three Possible Outcomes

    The three graphical possibilities of Figure 1.10 correspond to three outcomes of the algorithm. The next three examples illustrate each in turn. Each system has three equations in three unknowns, so each equation is a plane in space and the solution set is whatever the three planes have in common; the interactive figures let you rotate the planes and see it.
    🔗

    Example 1.34 A System with a Unique Solution.

    Solve the system
    \begin{align*} x_1 + x_2 + 2x_3 \amp = -1\\ x_2 + 2x_1 + 3x_3 \amp = 0\\ x_3 - 2x_2 \amp = 2 \end{align*}
    🔗
    Solution.
    First rewrite each equation with the variables in the order \(x_1, x_2, x_3\) and form the augmented matrix. The forward phase gives
    \begin{align*} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 2 \amp -1 \\ 2 \amp 1 \amp 3 \amp 0 \\ 0 \amp -2 \amp 1 \amp 2 \end{array} \right] \amp \xrightarrow{-2r_1 + r_2} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 2 \amp -1 \\ 0 \amp -1 \amp -1 \amp 2 \\ 0 \amp -2 \amp 1 \amp 2 \end{array} \right]\\ \amp \xrightarrow{-2r_2 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 2 \amp -1 \\ 0 \amp -1 \amp -1 \amp 2 \\ 0 \amp 0 \amp 3 \amp -2 \end{array} \right], \end{align*}
    which is a row-echelon matrix.
    🔗
    Now the backward phase:
    \begin{align*} \amp \xrightarrow{\frac{1}{3} r_3} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 2 \amp -1 \\ 0 \amp -1 \amp -1 \amp 2 \\ 0 \amp 0 \amp 1 \amp -\frac{2}{3} \end{array} \right]\\ \amp \xrightarrow[-2r_3 + r_1]{r_3 + r_2} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 0 \amp \frac{1}{3} \\ 0 \amp -1 \amp 0 \amp \frac{4}{3} \\ 0 \amp 0 \amp 1 \amp -\frac{2}{3} \end{array} \right]\\ \amp \xrightarrow{-r_2} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 0 \amp \frac{1}{3} \\ 0 \amp 1 \amp 0 \amp -\frac{4}{3} \\ 0 \amp 0 \amp 1 \amp -\frac{2}{3} \end{array} \right]\\ \amp \xrightarrow{-r_2 + r_1} \left[ \begin{array}{ccc|c} 1 \amp 0 \amp 0 \amp \frac{5}{3} \\ 0 \amp 1 \amp 0 \amp -\frac{4}{3} \\ 0 \amp 0 \amp 1 \amp -\frac{2}{3} \end{array} \right], \end{align*}
    a reduced row-echelon matrix.
    🔗
    Reading off the rows,
    \begin{equation*} x_1 = \frac{5}{3}, \qquad x_2 = -\frac{4}{3}, \qquad x_3 = -\frac{2}{3}, \end{equation*}
    a unique solution. Every column of the coefficient matrix is a pivot column, so there are no free variables.
    🔗
    🔗
    🔗

    Example 1.36 An Inconsistent System.

    Solve the system
    \begin{align*} -3x_1 - 9x_2 + x_3 \amp = -9\\ 2x_1 + 6x_2 - x_3 \amp = 6\\ x_1 + 3x_2 - x_3 \amp = 2 \end{align*}
    🔗
    Solution.
    \begin{align*} \left[ \begin{array}{ccc|c} -3 \amp -9 \amp 1 \amp -9 \\ 2 \amp 6 \amp -1 \amp 6 \\ 1 \amp 3 \amp -1 \amp 2 \end{array} \right] \amp \xrightarrow{r_3 \leftrightarrow r_1} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -1 \amp 2 \\ 2 \amp 6 \amp -1 \amp 6 \\ -3 \amp -9 \amp 1 \amp -9 \end{array} \right]\\ \amp \xrightarrow[3r_1 + r_3]{-2r_1 + r_2} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -1 \amp 2 \\ 0 \amp 0 \amp 1 \amp 2 \\ 0 \amp 0 \amp -2 \amp -3 \end{array} \right]\\ \amp \xrightarrow{2r_2 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -1 \amp 2 \\ 0 \amp 0 \amp 1 \amp 2 \\ 0 \amp 0 \amp 0 \amp 1 \end{array} \right]. \end{align*}
    🔗
    The last row says
    \begin{equation*} 0x_1 + 0x_2 + 0x_3 = 1, \qquad \text{or} \qquad 0 = 1, \end{equation*}
    which is impossible, and hence the system is inconsistent (no solution).
    🔗
    🔗
    🔗

    Remark 1.38.

    In general, a system is inconsistent exactly when the row-echelon form of its augmented matrix has a row of the form \(\left[ \begin{array}{cccc|c} 0 \amp 0 \amp \cdots \amp 0 \amp d \end{array} \right]\) with \(d \neq 0\text{.}\)
    🔗
    🔗

    Example 1.39 A System with Infinitely Many Solutions.

    Solve the system
    \begin{align*} 2x_1 + x_2 + 3x_3 \amp = 1\\ 2x_2 - x_3 + x_1 \amp = 0\\ 10x_3 - 6x_2 \amp = 2 \end{align*}
    🔗
    Solution.
    After ordering the variables as \(x_1, x_2, x_3\) in each equation,
    \begin{align*} \amp \left[ \begin{array}{ccc|c} 2 \amp 1 \amp 3 \amp 1 \\ 1 \amp 2 \amp -1 \amp 0 \\ 0 \amp -6 \amp 10 \amp 2 \end{array} \right]\\ \amp \xrightarrow{r_1 \leftrightarrow r_2} \left[ \begin{array}{ccc|c} 1 \amp 2 \amp -1 \amp 0 \\ 2 \amp 1 \amp 3 \amp 1 \\ 0 \amp -6 \amp 10 \amp 2 \end{array} \right]\\ \amp \xrightarrow{-2r_1 + r_2} \left[ \begin{array}{ccc|c} 1 \amp 2 \amp -1 \amp 0 \\ 0 \amp -3 \amp 5 \amp 1 \\ 0 \amp -6 \amp 10 \amp 2 \end{array} \right]\\ \amp \xrightarrow{-2r_2 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 2 \amp -1 \amp 0 \\ 0 \amp -3 \amp 5 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-\frac{1}{3} r_2} \left[ \begin{array}{ccc|c} 1 \amp 2 \amp -1 \amp 0 \\ 0 \amp 1 \amp -\frac{5}{3} \amp -\frac{1}{3} \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-2r_2 + r_1} \left[ \begin{array}{ccc|c} 1 \amp 0 \amp \frac{7}{3} \amp \frac{2}{3} \\ 0 \amp 1 \amp -\frac{5}{3} \amp -\frac{1}{3} \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{align*}
    🔗
    Columns \(1\) and \(2\) are pivot columns, so \(x_1\) and \(x_2\) are basic variables, whereas \(x_3\) is a free variable. Setting \(x_3 = s\text{,}\) the two nonzero rows read
    \begin{align*} x_1 + \tfrac{7}{3}s \amp = \tfrac{2}{3}\\ x_2 - \tfrac{5}{3}s \amp = -\tfrac{1}{3} \end{align*}
    and therefore the solution set in parametric form is
    \begin{align*} x_1 \amp = \tfrac{2}{3} - \tfrac{7}{3}s\\ x_2 \amp = -\tfrac{1}{3} + \tfrac{5}{3}s\\ x_3 \amp = s, \qquad \text{where } s \in \R. \end{align*}
    🔗
    🔗
    🔗
    The pattern is now clear, and it is worth recording as a theorem, since it is the main result of the chapter.
    🔗

    Theorem 1.41 Existence and Uniqueness of Solutions.

    Let a system of linear equations have augmented matrix \(A\text{,}\) and let \(R\) be a row-echelon form of \(A\text{.}\)
    1. Existence. The system is consistent if and only if \(R\) has no row of the form \(\left[ \begin{array}{cccc|c} 0 \amp 0 \amp \cdots \amp 0 \amp d \end{array} \right]\) with \(d \neq 0\text{;}\) equivalently, if and only if the augmented column is not a pivot column.
      🔗
      🔗
    2. Uniqueness. If the system is consistent, then it has a unique solution when there are no free variables, and infinitely many solutions when there is at least one free variable — one parameter for each free variable.
      🔗
      🔗
    🔗
    🔗

    Proof.
    A row \([\,0 \; \cdots \; 0 \mid d\,]\) with \(d \neq 0\) stands for the equation \(0 = d\text{,}\) which no values of the variables can satisfy, so a system whose echelon form contains such a row is inconsistent. Conversely, suppose there is no such row. Then every nonzero row of \(R\) has its leading entry in a variable column, and the backward phase of the algorithm carries \(R\) to a reduced row-echelon matrix in which each basic variable appears, with coefficient \(1\text{,}\) in exactly one equation, and in no other. Assign arbitrary values to the free variables; each equation then determines the value of its basic variable. This produces a solution, so the system is consistent. That proves existence.
    🔗
    For uniqueness, the same description shows that the solutions are in one-to-one correspondence with the choices of values for the free variables. If there are no free variables there is exactly one choice, hence one solution. If there is at least one free variable, it can take infinitely many values, each giving a different solution.
    🔗
    🔗
    The theorem explains, from the point of view of the algorithm, the trichotomy of Theorem 1.12: a system has no solution, one solution, or infinitely many, and nothing in between. It also has a useful consequence that can be read off before any computation: a consistent system with more unknowns than equations has infinitely many solutions. For there is at most one pivot per row, hence at most \(m\) basic variables in a system of \(m\) equations, and when \(n > m\) at least \(n - m\) of the \(n\) variables must be free. We will meet this consequence again in Section 2.3.
    🔗
    🔗

    Subsection 1.4.3 Systems Depending on Parameters

    A parameter can play two different roles. In a solution formula such as \(x_3=s\text{,}\) it describes the different solutions of one fixed system. Here, \(a,b,c\) instead specify the equations themselves: choosing their values selects a particular system. Treat them as fixed constants while solving, and check when an expression is zero before dividing by it.
    🔗

    Example 1.42 Conditions on the Coefficients.

    Find all values of \(a\text{,}\) \(b\) and \(c\) (or conditions on \(a\text{,}\) \(b\) and \(c\)) so that the system
    \begin{align*} 2x_1 + 3x_2 + ax_3 \amp = b\\ \phantom{2x_1 + {}} -x_2 + 2x_3 \amp = c\\ x_1 + 3x_2 - 2x_3 \amp = 1 \end{align*}
    has (i) a unique solution, (ii) no solutions, and (iii) infinitely many solutions. In (i) and (iii), find the solution(s).
    🔗
    Solution.
    Row reduce the augmented matrix, treating \(a\text{,}\) \(b\text{,}\) \(c\) as constants:
    \begin{align*} \left[ \begin{array}{ccc|c} 2 \amp 3 \amp a \amp b \\ 0 \amp -1 \amp 2 \amp c \\ 1 \amp 3 \amp -2 \amp 1 \end{array} \right] \amp \xrightarrow{r_1 \leftrightarrow r_3} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -2 \amp 1 \\ 0 \amp -1 \amp 2 \amp c \\ 2 \amp 3 \amp a \amp b \end{array} \right]\\ \amp \xrightarrow{-2r_1 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -2 \amp 1 \\ 0 \amp -1 \amp 2 \amp c \\ 0 \amp -3 \amp a+4 \amp b-2 \end{array} \right]\\ \amp \xrightarrow{-3r_2 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -2 \amp 1 \\ 0 \amp -1 \amp 2 \amp c \\ 0 \amp 0 \amp a-2 \amp b-2-3c \end{array} \right]. \end{align*}
    Everything now hinges on the entry \(a - 2\text{.}\)
    🔗
    Case (I): \(a - 2 \neq 0\text{,}\) i.e., \(a \neq 2\text{.}\) We may divide the third row by \(a-2\) and continue. Writing \(K = \dfrac{b-2-3c}{a-2}\) for brevity,
    \begin{align*} \amp \xrightarrow{\left( \frac{1}{a-2} \right) r_3} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -2 \amp 1 \\ 0 \amp -1 \amp 2 \amp c \\ 0 \amp 0 \amp 1 \amp K \end{array} \right]\\ \amp \xrightarrow{-r_2} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -2 \amp 1 \\ 0 \amp 1 \amp -2 \amp -c \\ 0 \amp 0 \amp 1 \amp K \end{array} \right]\\ \amp \xrightarrow{2r_3+r_2} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -2 \amp 1 \\ 0 \amp 1 \amp 0 \amp -c + 2K \\ 0 \amp 0 \amp 1 \amp K \end{array} \right]\\ \amp \xrightarrow{2r_3 + r_1} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp 0 \amp 1 + 2K \\ 0 \amp 1 \amp 0 \amp -c + 2K \\ 0 \amp 0 \amp 1 \amp K \end{array} \right]\\ \amp \xrightarrow{-3r_2 + r_1} \left[ \begin{array}{ccc|c} 1 \amp 0 \amp 0 \amp 1 + 3c - 4K \\ 0 \amp 1 \amp 0 \amp -c + 2K \\ 0 \amp 0 \amp 1 \amp K \end{array} \right]. \end{align*}
    Hence when \(a \neq 2\text{,}\) there is a unique solution:
    \begin{align*} x_1 \amp = 1 + 3c - 4\left( \frac{b-2-3c}{a-2} \right)\\ x_2 \amp = -c + 2 \left( \frac{b-2-3c}{a-2} \right)\\ x_3 \amp = \frac{b-2-3c}{a-2}. \end{align*}
    🔗
    Case (II): \(a - 2 = 0\) and \(b - 2 - 3c \neq 0\text{.}\) The row-echelon matrix is
    \begin{equation*} \left[ \begin{array}{ccc|c} 1 \amp 3 \amp -2 \amp 1 \\ 0 \amp -1 \amp 2 \amp c \\ 0 \amp 0 \amp 0 \amp b-2-3c \end{array} \right], \end{equation*}
    whose last row asserts \(0 = b-2-3c \neq 0\text{.}\) Then the system has no solution.
    🔗
    Case (III): \(a - 2 = 0\) and \(b - 2 - 3c = 0\text{.}\) Now the last row is entirely zero, and \(x_3\) is a free variable, so the system has infinitely many solutions. Setting \(x_3 = s\text{,}\) the second row gives \(-x_2 + 2s = c\text{,}\) so \(x_2 = -c + 2s\text{,}\) and the first row gives
    \begin{equation*} x_1 = 1 - 3x_2 + 2x_3 = 1 - 3(-c + 2s) + 2s = 1 + 3c - 4s. \end{equation*}
    The solution set in parametric form is
    \begin{align*} x_1 \amp = 1 + 3c - 4s\\ x_2 \amp = -c + 2s\\ x_3 \amp = s, \qquad \text{where } s \in \R. \end{align*}
    🔗
    In summary: the system has a unique solution when \(a \neq 2\text{,}\) no solution when \(a = 2\) and \(b \neq 2 + 3c\text{,}\) and infinitely many solutions when \(a = 2\) and \(b = 2 + 3c\text{.}\)

    Translate the augmented rows \([\,0\;0\;0\mid0\,]\) and \([\,0\;0\;0\mid5\,]\) into equations. Which row proves inconsistency, and why?

    A student says, “A zero row means infinitely many solutions.” Explain the error using these echelon augmented matrices:
    \begin{equation*} \left[\begin{array}{cc|c}1\amp0\amp2\\0\amp1\amp3\\0\amp0\amp0\end{array}\right], \qquad \left[\begin{array}{cc|c}1\amp1\amp2\\0\amp0\amp0\end{array}\right], \qquad \left[\begin{array}{cc|c}1\amp1\amp2\\0\amp0\amp1\\0\amp0\amp0\end{array}\right]. \end{equation*}

    If \(a\ne2\text{,}\) division is allowed and the system has a unique solution. If \(a=2,b\ne0\text{,}\) it is inconsistent. If \(a=2,b=0\text{,}\) the second variable is free and there are infinitely many solutions.

    5.

    Three planes in space are given by three linear equations in \(x_1, x_2, x_3\text{.}\) Using Theorem 1.41, describe every possible shape of the set of points common to all three planes. Which shapes occur in the three examples of this section, and which do not? Can three planes meet in exactly two points?
    🔗
    Answer.
    The common set is empty (inconsistent), a single point (no free variables), a line (one free variable), or a plane (two free variables, when all three equations describe the same plane). Only the empty set, a point, and a line occur in the examples. Exactly two points is impossible: by Theorem 1.12, two common points force the whole line through them to be common.

    6.

    When propane burns, the reaction is \(x_1\,\mathrm{C_3H_8} + x_2\,\mathrm{O_2} \to x_3\,\mathrm{CO_2} + x_4\,\mathrm{H_2O}\text{,}\) and the numbers of carbon, hydrogen, and oxygen atoms must each balance. Write one linear equation per element (all constant terms will be \(0\)), row reduce the resulting system, and find all solutions. Then choose the solution with the smallest positive whole-number coefficients.
    🔗
    Answer.
    Carbon: \(3x_1 = x_3\text{;}\) hydrogen: \(8x_1 = 2x_4\text{;}\) oxygen: \(2x_2 = 2x_3 + x_4\text{.}\) The reduced row-echelon form of the augmented matrix is \(\left[\begin{array}{cccc|c}1\amp0\amp0\amp-\frac14\amp0\\0\amp1\amp0\amp-\frac54\amp0\\0\amp0\amp1\amp-\frac34\amp0\end{array}\right]\text{,}\) so \(x_4 = s\) is free and \(x_1 = \tfrac14 s\text{,}\) \(x_2 = \tfrac54 s\text{,}\) \(x_3 = \tfrac34 s\text{.}\) Taking \(s = 4\) gives \(\mathrm{C_3H_8} + 5\,\mathrm{O_2} \to 3\,\mathrm{CO_2} + 4\,\mathrm{H_2O}\text{.}\)
