    Section 1.3 The Augmented Matrix and Echelon Forms

    When we apply elementary operations, the variable names never change — only the coefficients and constants do. So we may as well drop the variables and record just the numbers. This bookkeeping device is the augmented matrix.
    🔗

    Subsection 1.3.1 The Augmented Matrix

    Example 1.18. Forming the Augmented Matrix.

    The system of linear equations
    \begin{align*} x_1 - 2x_2 - 7x_3 \amp = -1\\ -x_1 + 3x_2 + 6x_3 \amp = 0 \end{align*}
    is represented by the augmented matrix
    \begin{equation*} \left[ \begin{array}{ccc|c} 1 \amp -2 \amp -7 \amp -1 \\ -1 \amp 3 \amp 6 \amp 0 \end{array} \right]. \end{equation*}
    🔗
    Two other matrices associated with a system of linear equations are the coefficient matrix and the constant matrix:
    \begin{equation*} \begin{bmatrix} 1 \amp -2 \amp -7 \\ -1 \amp 3 \amp 6 \end{bmatrix}, \qquad \begin{bmatrix} -1 \\ 0 \end{bmatrix}. \end{equation*}
    🔗
    🔗
    The three elementary operations of Definition 1.15 become elementary row operations on the augmented matrix. We use the following notation, where \(r_i\) denotes row \(i\text{:}\)
    \begin{align*} r_i \leftrightarrow r_j \amp \qquad \text{interchange rows } i \text{ and } j,\\ k \, r_i \amp \qquad \text{multiply row } i \text{ by } k \neq 0,\\ k \, r_j + r_i \amp \qquad \text{add } k \text{ times row } j \text{ to row } i. \end{align*}
    🔗

    Example 1.19. Row Operations on an Augmented Matrix.

    Consider the system of linear equations
    \begin{align*} 3x_1 - 2x_2 - 7x_3 \amp = -1\\ -x_1 + 3x_2 + 6x_3 \amp = 1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
    with augmented matrix \(\left[ \begin{array}{ccc|c} 3 \amp -2 \amp -7 \amp -1 \\ -1 \amp 3 \amp 6 \amp 1 \\ 2 \amp 0 \amp -1 \amp 3 \end{array} \right]\text{.}\) Carry out the operations of Example 1.17 in matrix form.
    🔗
    Solution.
    Interchange the first two equations (two rows), \(r_1 \leftrightarrow r_2\text{:}\)
    \begin{equation*} \left[ \begin{array}{ccc|c} -1 \amp 3 \amp 6 \amp 1 \\ 3 \amp -2 \amp -7 \amp -1 \\ 2 \amp 0 \amp -1 \amp 3 \end{array} \right]. \end{equation*}
    🔗
    Add \(3\) times the second equation to the first equation, \(3r_2 + r_1\text{:}\)
    \begin{equation*} \left[ \begin{array}{ccc|c} 0 \amp 7 \amp 11 \amp 2 \\ -1 \amp 3 \amp 6 \amp 1 \\ 2 \amp 0 \amp -1 \amp 3 \end{array} \right]. \end{equation*}
    🔗
    🔗
    🔗
    🔗

    Subsection 1.3.2 Row-Echelon and Reduced Row-Echelon Matrices

    Definition 1.20. Row-Echelon Matrix.

    A matrix is a row-echelon matrix (REM) if
    1. All rows consisting entirely of zeros are at the bottom.
      🔗
      🔗
    2. The first nonzero entry in each nonzero row is called a leading entry.
      🔗
      🔗
    3. Each leading entry is to the right of all leading entries in rows above it.
      🔗
      🔗
    🔗
    🔗

    Example 1.21. The Shape of a Row-Echelon Matrix.

    \begin{equation*} \begin{bmatrix} 0 \amp \square \amp * \amp * \amp * \amp * \amp * \amp * \\ 0 \amp 0 \amp 0 \amp \square \amp * \amp * \amp * \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp \square \amp * \amp * \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp \square \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix} \end{equation*}
    Here \(\square\) can be any nonzero real number, and \(*\) can be any real number.
    🔗
    🔗

    Definition 1.22. Reduced Row-Echelon Matrix.

    A matrix is a reduced row-echelon matrix (RREM) if
    1. It is a row-echelon matrix.
      🔗
      🔗
    2. The leading entry in each nonzero row is \(1\text{.}\)
      🔗
      🔗
    3. Each leading \(1\) is the only nonzero entry in its column.
      🔗
      🔗
    🔗
    🔗

    Example 1.23. The Shape of a Reduced Row-Echelon Matrix.

    \begin{equation*} \begin{bmatrix} 0 \amp 1 \amp * \amp 0 \amp 0 \amp * \amp 0 \amp * \\ 0 \amp 0 \amp 0 \amp 1 \amp 0 \amp * \amp 0 \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp * \amp 0 \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp * \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix} \end{equation*}
    Here \(*\) can be any real number.
    🔗
    🔗
    🔗

    Subsection 1.3.3 Pivots, Basic Variables, and Free Variables

    Definition 1.24. Pivots and Variables.

    • A pivot position is a location corresponding to a leading \(1\text{,}\) and a pivot column is the column containing the pivot position.
      🔗
      🔗
    • The basic variables are the variables that correspond to columns containing leading ones.
      🔗
      🔗
    • The remaining variables are called free variables.
      🔗
      🔗
    🔗
    🔗

    Example 1.25. Identifying Pivots and Free Variables.

    Suppose that the following matrix is the augmented matrix of a system of linear equations:
    \begin{equation*} \left[ \begin{array}{ccccccc|c} 1 \amp -3 \amp 4 \amp -2 \amp 5 \amp -7 \amp 0 \amp 4 \\ 0 \amp 0 \amp 1 \amp 8 \amp 0 \amp 3 \amp -7 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \amp 1 \amp -1 \amp 0 \amp -1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 1 \amp 2 \end{array} \right]. \end{equation*}
    Identify the pivot columns, the basic variables, and the free variables.
    🔗
    Solution.
    Note that the matrix is a row-echelon matrix. The leading ones sit in positions \((1,1)\text{,}\) \((2,3)\text{,}\) \((3,4)\text{,}\) and \((4,7)\text{,}\) so the pivot columns are columns \(1\text{,}\) \(3\text{,}\) \(4\text{,}\) and \(7\text{.}\)
    🔗
    Accordingly, \(x_1\text{,}\) \(x_3\text{,}\) \(x_4\text{,}\) and \(x_7\) are the basic variables, and the remaining variables (columns \(2\text{,}\) \(5\text{,}\) and \(6\)) — that is, \(x_2\text{,}\) \(x_5\text{,}\) and \(x_6\) — are the free variables.
    🔗
    🔗
    🔗
    We will use elementary row operations to transform a matrix to row-echelon or reduced row-echelon form. The next section gives the algorithm that does it.
