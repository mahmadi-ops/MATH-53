    Section 3.2 One-to-One and Onto Transformations

    Two questions can be asked of any transformation: does it ever send two different inputs to the same output, and does it reach every possible output? For matrix transformations both questions reduce to facts about the matrix that we already know how to check.
    🔗

Click and drag the head of the input vector \(\vec{x}\) or the output vector \(\vec{b}\) to explore the transformation; drag inside a three-dimensional pane to rotate it. The \(\vec{x}\) handle can also be moved with the keyboard (press Tab to reach it, then the arrow keys), and the “animate” button plays a short demonstration. The violet objects always show the solution set of \(T(\vec{x}) = \vec{b}\text{,}\) and the teal objects show the range of \(T\text{.}\)
    🔗

    Subsection 3.2.1 One-to-One Transformations

    Definition 3.14. Injective (One-to-One) Linear Transformation.

    Let \(T : \R^n \to \R^m\) be a linear transformation, and let \(\vec{x}_1\) and \(\vec{x}_2\) be in \(\R^n\text{.}\) We say that \(T\) is an injection or is one-to-one if \(\vec{x}_1 \neq \vec{x}_2\) implies \(T(\vec{x}_1) \neq T(\vec{x}_2)\text{.}\) Equivalently, if \(T(\vec{x}_1) = T(\vec{x}_2)\text{,}\) then \(\vec{x}_1 = \vec{x}_2\text{.}\)
    🔗
    🔗

    Theorem 3.16. One-to-One and the Trivial Solution.

    Let \(A\) be an \(m \times n\) matrix and let \(\vec{x}\) be a vector of length \(n\text{.}\) Then the transformation induced by \(A\text{,}\) \(T_A\text{,}\) is one-to-one (1) if and only if \(A\vec{x} = \vec{0}\) implies \(\vec{x} = \vec{0}\) (2).
    🔗
    🔗

    Proof.
    (1) \(\Longrightarrow\) (2). Let \(\vec{u}\) be an element of \(\R^n\) such that \(T_A(\vec{u}) = \vec{0}\text{.}\) Then, since \(T_A\) is a one-to-one linear transformation, we have \(T_A(\vec{0}) = \vec{0}\) and hence \(\vec{0} = \vec{u}\text{.}\)
    🔗
    (2) \(\Longrightarrow\) (1). Let \(\vec{u}\) and \(\vec{v}\) be elements in \(\R^n\) such that \(A\vec{u} = A\vec{v}\text{.}\) Then \(A(\vec{u} - \vec{v}) = \vec{0}\text{,}\) which implies \(\vec{u} - \vec{v} = \vec{0}\text{,}\) or \(\vec{u} = \vec{v}\text{.}\) Hence we have shown that if \(T_A(\vec{u}) = T_A(\vec{v})\) then \(\vec{u} = \vec{v}\text{,}\) which means \(T_A\) is one-to-one.
    🔗
    🔗

    Example 3.17. True or False?

    Let \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A\) is an \(m \times n\) matrix. If we also assume that \(T\) is injective, then which statement is true and which one is false?
    🔗
    1. For every \(\vec{b} \in \R^m\text{,}\) there exists one solution for the equation \(T(\vec{x}) = \vec{b}\text{.}\)
      🔗
      🔗
    2. \(A\vec{x} = \vec{0}\) has only the trivial solution.
      🔗
      🔗
    3. The columns of \(A\) are linearly independent.
      🔗
      🔗
    🔗
    Solution.
    (I) False. For example, let \(A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 1 \amp 0 \end{bmatrix}\) and \(T : \R^2 \to \R^3\text{,}\) which is a one-to-one transformation. Now, for \(\vec{b} = \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix}\text{,}\) the system \(A\vec{x} = \vec{b}\) has no solution, since the augmented matrix is
    \begin{equation*} \left[ \begin{array}{cc|c} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 2 \\ 1 \amp 0 \amp 3 \end{array} \right] \xrightarrow{r_3 - r_1} \left[ \begin{array}{cc|c} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 2 \\ 0 \amp 0 \amp 2 \end{array} \right], \end{equation*}
    and therefore the system is inconsistent.
    🔗
    (II) True. See Theorem 3.16.
    🔗
    (III) True. Note that
    \begin{equation*} A\vec{x} = \vec{0} \iff x_1\vec{A}_1 + x_2\vec{A}_2 + \cdots + x_n\vec{A}_n = \vec{0}. \end{equation*}
    If \(A\vec{x} = \vec{0}\) has only the trivial solution, it means that none of the columns of \(A\) can be written as a linear combination of the rest of them, since if for example \(\vec{A}_1\) could be written as a linear combination
    \begin{equation*} \vec{A}_1 = a_2\vec{A}_2 + a_3\vec{A}_3 + \cdots + a_n\vec{A}_n, \end{equation*}
    this gives \(\vec{A}_1 - a_2\vec{A}_2 - a_3\vec{A}_3 - \cdots - a_n\vec{A}_n = \vec{0}\text{,}\) which contradicts the fact that \(A\vec{x} = \vec{0}\) has only the trivial solution.
    🔗
    🔗
    🔗

    Example 3.18. Which Transformation Is an Injection?

    1. Reflection in the \(x\)-axis in \(\R^2\text{.}\)
      🔗
      🔗
    2. Projection into the \(x\)-axis in \(\R^2\text{.}\)
      🔗
      🔗
    3. \(T \begin{bmatrix} x \\ y \\ z \end{bmatrix} = \begin{bmatrix} x \\ y \end{bmatrix}\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    (A) The corresponding matrix is \(A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix}\) and the system \(A\vec{x} = \vec{0}\) has only the trivial solution, hence this is an injection.
    🔗
    (B) Similarly, \(A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}\text{,}\) whereas \(A\vec{x} = \vec{0}\) has non-trivial solutions, hence this is NOT an injection.
    🔗
    (C) Again \(\begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \end{bmatrix} \begin{bmatrix} x \\ y \\ z \end{bmatrix} = \begin{bmatrix} x \\ y \end{bmatrix}\text{;}\) however, \(A\vec{x} = \vec{0}\) has a free parameter and therefore (C) is not an injection. For example,
    \begin{equation*} T \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix} = T \begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix} = \begin{bmatrix} 1 \\ 0 \end{bmatrix}. \end{equation*}
    🔗
    🔗
    🔗

    Example 3.19. A One-to-One Transformation, Seen Geometrically.

    Let \(T : \R^2 \to \R^3\) be the matrix transformation \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A = \begin{bmatrix} 1 \amp 0 \\ 1 \amp 1 \\ 0 \amp 1 \end{bmatrix}\text{.}\) Is \(T\) one-to-one?
    🔗
    Solution.
    Row reducing \(A\) gives
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \\ 1 \amp 1 \\ 0 \amp 1 \end{bmatrix} \xrightarrow{r_2 - r_1} \begin{bmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 1 \end{bmatrix} \xrightarrow{r_3 - r_2} \begin{bmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{bmatrix}, \end{equation*}
    so there is a pivot in every column. Hence \(A\vec{x} = \vec{0}\) has only the trivial solution, and \(T\) is one-to-one by Theorem 3.16.
    🔗
    🔗
    🔗

    Example 3.22. A Transformation That Is Not One-to-One, Seen Geometrically.

    Let \(T : \R^3 \to \R^2\) be the matrix transformation \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A = \begin{bmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \end{bmatrix}\text{.}\) Is \(T\) one-to-one?
    🔗
    Solution.
    The matrix \(A\) is already in reduced row echelon form, and the third column has no pivot. Solving \(A\vec{x} = \vec{0}\) with free variable \(z\) gives \(x = -z\) and \(y = -z\text{,}\) so the solution set is
    \begin{equation*} \vec{x} = z \begin{bmatrix} -1 \\ -1 \\ 1 \end{bmatrix}, \qquad z \text{ arbitrary}. \end{equation*}
    Taking \(z = 1\) produces the nontrivial solution
    \begin{equation*} T \begin{bmatrix} -1 \\ -1 \\ 1 \end{bmatrix} = \begin{bmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \end{bmatrix} \begin{bmatrix} -1 \\ -1 \\ 1 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} = T \begin{bmatrix} 0 \\ 0 \\ 0 \end{bmatrix}, \end{equation*}
    so two different inputs share the output \(\vec{0}\text{,}\) and \(T\) is not one-to-one.
    🔗
    🔗
    🔗

    Remark 3.24. Wide Matrices Are Never One-to-One.

    If \(A\) is an \(m \times n\) matrix with more columns than rows (\(n \gt m\)), then \(A\) cannot have a pivot in every column: there is at most one pivot per row, and there are fewer rows than columns. Hence \(A\vec{x} = \vec{0}\) has a free variable, and the transformation \(T(\vec{x}) = A\vec{x}\) is never one-to-one. This is why the transformation \(T : \R^3 \to \R^2\) in the previous example had no chance: a transformation from a bigger space to a smaller space must collapse different inputs together.
    🔗
    🔗
    🔗

    Subsection 3.2.2 Onto Transformations

    Definition 3.25. Surjection (Onto).

    Let \(T : \R^n \to \R^m\) be a linear transformation. We say that \(T\) is a surjection or onto if, for every \(\vec{b} \in \R^m\text{,}\) there exists an \(\vec{x} \in \R^n\) such that \(T(\vec{x}) = \vec{b}\text{.}\)
    🔗
    🔗

    Example 3.27. A Transformation That Is Not Onto.

    Let \(T : \R^2 \to \R^2\) be the linear transformation defined by \(T \begin{bmatrix} a \\ b \end{bmatrix} = \begin{bmatrix} a + b \\ 0 \end{bmatrix}\) for all \(\begin{bmatrix} a \\ b \end{bmatrix} \in \R^2\text{.}\) Determine whether \(T\) is a surjective transformation or not.
    🔗
    Solution.
    Every image has second entry \(0\text{,}\) so no vector with a nonzero second entry is in the range. For instance, \(\begin{bmatrix} 0 \\ 1 \end{bmatrix}\) is never an image. Hence \(T\) is not a surjection.
    🔗
    🔗
    🔗

    Example 3.28. Which Transformation Is a Surjection?

    1. \(T : \R^3 \to \R^2\) with \(T(\vec{x}) = \begin{bmatrix} x - z \\ y + z \end{bmatrix}\text{.}\)
      🔗
      🔗
    2. \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 1 \\ 0 \amp 0 \end{bmatrix}\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    (I) The matrix is
    \begin{equation*} A = \begin{bmatrix} T(\vec{e}_1) \amp T(\vec{e}_2) \amp T(\vec{e}_3) \end{bmatrix} = \begin{bmatrix} 1 \amp 0 \amp -1 \\ 0 \amp 1 \amp 1 \end{bmatrix}. \end{equation*}
    The system \(A\vec{x} = \vec{b}\text{,}\) or
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp -1 \\ 0 \amp 1 \amp 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ z \end{bmatrix} = \begin{bmatrix} b_1 \\ b_2 \end{bmatrix}, \end{equation*}
    will always have a solution, since \(\left[ \begin{array}{ccc|c} 1 \amp 0 \amp -1 \amp b_1 \\ 0 \amp 1 \amp 1 \amp b_2 \end{array} \right]\) has two leading ones and three variables, one of which is a free variable. Hence \(T\) is a surjection.
    🔗
    (II) The system \(A\vec{x} = \vec{b}\text{,}\) or
    \begin{equation*} \left[ \begin{array}{cc|c} 1 \amp 0 \amp b_1 \\ 0 \amp 1 \amp b_2 \\ 0 \amp 0 \amp b_3 \end{array} \right], \end{equation*}
    has no solution for \(b_3 \neq 0\text{,}\) which means \(T\) is not a surjection.
    🔗
    🔗
    🔗

    Example 3.29. An Onto Transformation, Seen Geometrically.

    Let \(T : \R^3 \to \R^2\) be the matrix transformation \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A = \begin{bmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \end{bmatrix}\text{.}\) Is \(T\) onto?
    🔗
    Solution.
    The matrix \(A\) is already in reduced row echelon form and has a pivot in every row. Therefore the augmented matrix of \(A\vec{x} = \vec{b}\) can never have a pivot in its last column, and the system is consistent for every \(\vec{b} \in \R^2\text{.}\) Concretely, for any \(\vec{b} = \begin{bmatrix} b_1 \\ b_2 \end{bmatrix}\text{,}\) the input \(\vec{x} = \begin{bmatrix} b_1 \\ b_2 \\ 0 \end{bmatrix}\) satisfies \(T(\vec{x}) = \vec{b}\text{.}\) Hence \(T\) is onto.
    🔗
    🔗
    🔗

    Example 3.31. A Transformation That Is Not Onto, Seen Geometrically.

    Let \(T : \R^2 \to \R^3\) be the matrix transformation \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A = \begin{bmatrix} 1 \amp 0 \\ 1 \amp 1 \\ 0 \amp 1 \end{bmatrix}\text{.}\) Is \(T\) onto?
    🔗
    Solution.
    Every output of \(T\) is a linear combination of the two columns of \(A\text{:}\)
    \begin{equation*} T \begin{bmatrix} x \\ y \end{bmatrix} = x \begin{bmatrix} 1 \\ 1 \\ 0 \end{bmatrix} + y \begin{bmatrix} 0 \\ 1 \\ 1 \end{bmatrix} = \begin{bmatrix} x \\ x + y \\ y \end{bmatrix}. \end{equation*}
    The middle entry of every output is the sum of the other two, so the range of \(T\) is the plane \(b_2 = b_1 + b_3\) in \(\R^3\) — a two-dimensional slice of the three-dimensional codomain. For instance, \(\vec{b} = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}\) has \(1 \neq 1 + 1\text{,}\) so it is not an output of \(T\text{,}\) and \(T\) is not onto. Alternatively: \(A\) has only two pivots, so it cannot have a pivot in every one of its three rows.
    🔗
    🔗
    🔗

    Remark 3.33. Tall Matrices Are Never Onto.

    If \(A\) is an \(m \times n\) matrix with more rows than columns (\(m \gt n\)), then \(A\) cannot have a pivot in every row: there is at most one pivot per column, and there are fewer columns than rows. Hence the transformation \(T(\vec{x}) = A\vec{x}\) is never onto. This is the mirror image of Remark 3.24: a transformation from a smaller space into a bigger space cannot fill up its codomain.
    🔗
    🔗
    🔗

    Subsection 3.2.3 One-to-One and Onto Together

    Both properties are read off from the pivots of \(A\text{:}\)
    🔗
    • \(T\) is one-to-one if and only if \(A\) has a pivot in every column, that is, if and only if the columns of \(A\) are linearly independent.
      🔗
      🔗
    • \(T\) is onto if and only if \(A\) has a pivot in every row, that is, if and only if the columns of \(A\) span \(\R^m\text{.}\)
      🔗
      🔗
    🔗
    A transformation can have either property without the other, both, or neither. The two examples below complete the picture.
    🔗

    Example 3.34. A Transformation That Is Neither One-to-One Nor Onto.

    Let \(T : \R^3 \to \R^2\) be the matrix transformation \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A = \begin{bmatrix} 1 \amp 2 \amp -1 \\ 2 \amp 4 \amp -2 \end{bmatrix}\text{.}\) Show that \(T\) is neither one-to-one nor onto.
    🔗
    Solution.
    Row reducing,
    \begin{equation*} \begin{bmatrix} 1 \amp 2 \amp -1 \\ 2 \amp 4 \amp -2 \end{bmatrix} \xrightarrow{r_2 - 2r_1} \begin{bmatrix} 1 \amp 2 \amp -1 \\ 0 \amp 0 \amp 0 \end{bmatrix}, \end{equation*}
    so \(A\) has a single pivot. There is no pivot in the second or third column, so \(A\vec{x} = \vec{0}\) has two free variables and \(T\) is not one-to-one: the solution set of \(T(\vec{x}) = \vec{0}\) is the entire plane \(x + 2y - z = 0\text{.}\) There is also no pivot in the second row, so \(T\) is not onto: the range is \(\Span\left\{ \begin{bmatrix} 1 \\ 2 \end{bmatrix} \right\}\text{,}\) a line in \(\R^2\text{,}\) since every column of \(A\) is a multiple of \(\begin{bmatrix} 1 \\ 2 \end{bmatrix}\text{.}\) For example, \(\vec{b} = \begin{bmatrix} 1 \\ 1 \end{bmatrix}\) is not on this line, so \(T(\vec{x}) = \vec{b}\) has no solution.
    🔗
    🔗
    🔗

    Example 3.36. Projection into the \(xy\)-Plane Is Neither.

    Let \(P : \R^3 \to \R^3\) be projection into the \(xy\)-plane, that is,
    \begin{equation*} P \begin{bmatrix} x \\ y \\ z \end{bmatrix} = \begin{bmatrix} x \\ y \\ 0 \end{bmatrix}. \end{equation*}
    Show that \(P\) is neither one-to-one nor onto.
    🔗
    Solution.
    First find the matrix. Since \(P(\vec{e}_1) = \vec{e}_1\text{,}\) \(P(\vec{e}_2) = \vec{e}_2\) and \(P(\vec{e}_3) = \vec{0}\text{,}\)
    \begin{equation*} A = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    🔗
    Not one-to-one. The system \(A\vec{x} = \vec{0}\) reads \(x = 0\text{,}\) \(y = 0\text{,}\) and \(0 = 0\text{,}\) so \(z\) is a free variable and the solutions are
    \begin{equation*} \vec{x} = t \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}, \qquad t \in \R, \end{equation*}
    the whole \(z\)-axis. There are nontrivial solutions, so by Theorem 3.16 \(P\) is not one-to-one. Concretely,
    \begin{equation*} P \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix} = P \begin{bmatrix} 0 \\ 0 \\ 2 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \\ 0 \end{bmatrix}, \end{equation*}
    two different inputs with the same image. This is exactly what projection does: it forgets the height \(z\text{.}\)
    🔗
    Not onto. Every output has third entry \(0\text{,}\) so the range of \(P\) is the \(xy\)-plane \(\operatorname{Span}\{ \vec{e}_1, \vec{e}_2 \}\text{,}\) which is smaller than the codomain \(\R^3\text{.}\) For instance \(\vec{b} = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}\) has no preimage: the third equation of \(A\vec{x} = \vec{b}\) reads \(0 = 1\text{,}\) so the system is inconsistent.
    🔗
    Both failures are visible in \(\det A = 0\text{:}\) by Theorem 4.57, a square matrix that is not invertible is neither one-to-one nor onto, consistent with Remark 3.42.
    🔗
    🔗
    🔗

    Example 3.38. A Transformation That Is Both One-to-One and Onto.

    Let \(T : \R^2 \to \R^2\) be the matrix transformation \(T(\vec{x}) = A\vec{x}\text{,}\) where \(A = \begin{bmatrix} 2 \amp 1 \\ 1 \amp 1 \end{bmatrix}\text{.}\) Show that \(T\) is both one-to-one and onto.
    🔗
    Solution.
    Row reducing,
    \begin{equation*} \begin{bmatrix} 2 \amp 1 \\ 1 \amp 1 \end{bmatrix} \xrightarrow{r_1 \leftrightarrow r_2} \begin{bmatrix} 1 \amp 1 \\ 2 \amp 1 \end{bmatrix} \xrightarrow{r_2 - 2r_1} \begin{bmatrix} 1 \amp 1 \\ 0 \amp -1 \end{bmatrix} \xrightarrow[r_1 + r_2]{-r_2} \begin{bmatrix} 1 \amp 0 \\ 0 \amp 1 \end{bmatrix}, \end{equation*}
    so \(A\) has a pivot in every column (\(T\) is one-to-one) and in every row (\(T\) is onto). In fact, for every \(\vec{b} \in \R^2\) the equation \(T(\vec{x}) = \vec{b}\) has exactly one solution,
    \begin{equation*} \vec{x} = \begin{bmatrix} 1 \amp -1 \\ -1 \amp 2 \end{bmatrix} \vec{b}, \end{equation*}
    as can be checked by multiplying the two matrices. (We will study such invertible matrices in detail later.)
    🔗
    🔗
    🔗

    Example 3.40. Rotation Is Both One-to-One and Onto.

    Let \(R_\theta : \R^2 \to \R^2\) denote counterclockwise rotation about the origin through an angle \(\theta\text{.}\) Show that \(R_\theta\) is both one-to-one and onto, for every \(\theta\text{.}\)
    🔗
    Solution.
    Rotating \(\vec{e}_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\) counterclockwise through \(\theta\) lands on the point of the unit circle at angle \(\theta\text{,}\) and rotating \(\vec{e}_2\) lands a further quarter turn along:
    \begin{equation*} R_\theta(\vec{e}_1) = \begin{bmatrix} \cos\theta \\ \sin\theta \end{bmatrix}, \qquad R_\theta(\vec{e}_2) = \begin{bmatrix} -\sin\theta \\ \cos\theta \end{bmatrix}, \qquad \text{so} \qquad A = \begin{bmatrix} \cos\theta \amp -\sin\theta \\ \sin\theta \amp \cos\theta \end{bmatrix}. \end{equation*}
    (This matrix is studied further in Subsection 3.3.1.)
    🔗
    Now
    \begin{equation*} \det A = \cos^2\theta + \sin^2\theta = 1 \neq 0, \end{equation*}
    so \(A\) is invertible for every angle \(\theta\text{.}\) By Theorem 4.57, \(A\vec{x} = \vec{0}\) has only the trivial solution, so \(R_\theta\) is one-to-one by Theorem 3.16; and the columns of \(A\) span \(\R^2\text{,}\) so \(R_\theta\) is onto.
    🔗
    The geometry says the same thing more directly: rotating back through \(-\theta\) undoes the rotation. Indeed
    \begin{equation*} A^{-1} = \frac{1}{1} \begin{bmatrix} \cos\theta \amp \sin\theta \\ -\sin\theta \amp \cos\theta \end{bmatrix} = \begin{bmatrix} \cos(-\theta) \amp -\sin(-\theta) \\ \sin(-\theta) \amp \cos(-\theta) \end{bmatrix}, \end{equation*}
    which is the matrix of \(R_{-\theta}\text{.}\) So every \(\vec{b} \in \R^2\) has exactly one preimage, namely \(\vec{x} = R_{-\theta}(\vec{b})\) — which is precisely the statement that \(R_\theta\) is one-to-one and onto.
    🔗
    🔗
    🔗

    Remark 3.42. Square Matrices: One-to-One Equals Onto.

    For an \(n \times n\) matrix \(A\text{,}\) having a pivot in every column is the same as having \(n\) pivots, which is the same as having a pivot in every row. So for a square matrix, the transformation \(T(\vec{x}) = A\vec{x}\) is one-to-one if and only if it is onto. For non-square matrices the two properties are independent — except that, by Remark 3.24 and Remark 3.33, a wide matrix is never one-to-one and a tall matrix is never onto.
