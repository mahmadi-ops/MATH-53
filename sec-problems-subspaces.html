    Problems for Subspaces (Section 5.1).
    🔗

    1. ★ Which of These Is a Subspace?

    Which of the following is a subspace?
    1. A line through the origin in \(\R^3\text{.}\)
      🔗
      🔗
    2. A plane not containing the origin in \(\R^3\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    (A) Yes, this is a subspace.
    1. The line passes through the origin, so it contains \(\vec{0}\text{.}\)
      🔗
      🔗
    2. Any two vectors on the line are multiples of a single direction vector, and so is any linear combination of them. The line is therefore closed under addition and scalar multiplication.
      🔗
      🔗
    🔗
    (B) No, this is not a subspace. A subspace must contain \(\vec{0}\text{,}\) by Example 5.5, and this plane does not. Closure fails too: if \(\vec{u}\) lies on the plane, then \(0\vec{u} = \vec{0}\) does not.
    🔗
    🔗
    🔗

    2. ★ True or False?

    If \(H\) is a subspace of \(\R^n\) and \(\vec{u} \in H\text{,}\) then \(-\vec{u} \in H\text{.}\)
    🔗
    Solution.
    True. A subspace is closed under scalar multiplication, so multiplying the element \(\vec{u} \in H\) by the scalar \(-1\) keeps us inside \(H\text{:}\)
    \begin{equation*} (-1)\vec{u} = -\vec{u} \in H. \end{equation*}
    🔗
    The same one-line argument with the scalar \(0\) shows \(\vec{0} \in H\text{,}\) which is Example 5.5. Both facts are really the observation that a subspace inherits every algebraic operation it is closed under.
    🔗
    🔗
    🔗

    3. ★ A Set That Misses the Origin.

    Is \(T = \left\{ \begin{bmatrix} x + 2 \\ x - 3 \end{bmatrix}, \; x \in \R \right\}\) a subspace of \(\R^2\text{?}\)
    🔗
    Solution.
    No. The zero vector is not in \(T\text{:}\) setting
    \begin{equation*} \begin{bmatrix} x + 2 \\ x - 3 \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} \end{equation*}
    would require \(x = -2\) from the first entry and \(x = 3\) from the second, which is impossible. Since every subspace contains \(\vec{0}\text{,}\) \(T\) is not one.
    🔗
    Geometrically \(T\) is a line of slope \(1\) shifted off the origin — it is the line \(y = x - 5\text{,}\) which misses \((0,0)\text{.}\)
    🔗
    🔗
    🔗

    4. ★ A Line through the Origin Is a Subspace.

    Is \(T = \left\{ \begin{bmatrix} 2 \\ -1 \\ 3 \end{bmatrix} t \; : \; t \in \R \right\}\) a subspace of \(\R^3\text{?}\)
    🔗
    Solution.
    Yes.
    🔗
    (I) Taking \(t = 0\) gives \(\vec{0} \in T\text{.}\)
    🔗
    (II) Let \(\vec{u} = \begin{bmatrix} 2 \\ -1 \\ 3 \end{bmatrix}t_1\) and \(\vec{v} = \begin{bmatrix} 2 \\ -1 \\ 3 \end{bmatrix}t_2\) be in \(T\text{,}\) and let \(a, b \in \R\text{.}\) Then
    \begin{align*} a\vec{u} + b\vec{v} \amp = \begin{bmatrix} 2 \\ -1 \\ 3 \end{bmatrix} at_1 + \begin{bmatrix} 2 \\ -1 \\ 3 \end{bmatrix} bt_2\\ \amp = \begin{bmatrix} 2 \\ -1 \\ 3 \end{bmatrix}\left( at_1 + bt_2 \right)\\ \amp = \begin{bmatrix} 2 \\ -1 \\ 3 \end{bmatrix} t_3, \end{align*}
    where \(t_3 = at_1 + bt_2 \in \R\text{.}\) So \(a\vec{u} + b\vec{v} \in T\text{.}\)
    🔗
    Equivalently, \(T = \operatorname{Span}\{(2,-1,3)\}\text{,}\) and every span is a subspace by Theorem 7.8.
    🔗
    🔗
    🔗

    5. ★ Examples of Subspaces of \(\R^3\).

    Write each of the following subspaces of \(\R^3\) as a span, and say whether it is a line, a plane, or all of \(\R^3\text{.}\)
    \begin{equation*} H_1 = \left\{ \begin{bmatrix} x \\ y \\ z \end{bmatrix} \in \R^3 : y = z = 0 \right\}, \quad H_2 = \left\{ \begin{bmatrix} x \\ y \\ z \end{bmatrix} \in \R^3 : x + z = 0 \right\}. \end{equation*}
    Then verify that \(\left\{ \begin{bmatrix} 1 \\ 1 \\ 0 \end{bmatrix}, \begin{bmatrix} 0 \\ 1 \\ 1 \end{bmatrix}, \begin{bmatrix} 1 \\ 0 \\ 1 \end{bmatrix} \right\}\) spans \(H_3 = \R^3\text{.}\)
    🔗
    Solution.
    \(H_1\text{.}\) Only \(x\) is free, so \(H_1 = \operatorname{Span}\left\{ \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix} \right\}\) — the \(x\)-axis, a line through the origin.
    🔗
    \(H_2\text{.}\) The condition \(x = -z\) leaves \(y\) and \(z\) free, so with \(y = s\) and \(z = t\text{,}\)
    \begin{equation*} \begin{bmatrix} -t \\ s \\ t \end{bmatrix} = s \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix} + t \begin{bmatrix} -1 \\ 0 \\ 1 \end{bmatrix}, \end{equation*}
    so \(H_2\) is the plane \(\operatorname{Span}\left\{ \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}, \begin{bmatrix} -1 \\ 0 \\ 1 \end{bmatrix} \right\}\text{.}\)
    🔗
    \(H_3 = \R^3\text{.}\) We must write an arbitrary \((x,y,z)\) in terms of the three given vectors. Solving \(a(1,1,0) + b(0,1,1) + c(1,0,1) = (x,y,z)\) gives
    \begin{equation*} a + c = x, \qquad a + b = y, \qquad b + c = z. \end{equation*}
    Adding all three equations gives \(2(a+b+c) = x+y+z\text{,}\) so \(a + b + c = \tfrac{1}{2}(x+y+z)\text{,}\) and subtracting each equation in turn,
    \begin{equation*} a = \tfrac{1}{2}(x + y - z), \quad b = \tfrac{1}{2}(-x + y + z), \quad c = \tfrac{1}{2}(x - y + z). \end{equation*}
    🔗
    Since a solution exists for every \((x,y,z)\text{,}\) the three vectors span all of \(\R^3\text{.}\) As a check with \((x,y,z) = (1,0,0)\) we get \(a = \tfrac{1}{2}\text{,}\) \(b = -\tfrac{1}{2}\text{,}\) \(c = \tfrac{1}{2}\text{,}\) and \(\tfrac{1}{2}(1,1,0) - \tfrac{1}{2}(0,1,1) + \tfrac{1}{2}(1,0,1) = (1,0,0)\text{.}\) \(\checkmark\)
    🔗
    🔗
    🔗

    6. ★ Recognizing a Subspace from a Parametrization.

    Is \(V = \left\{ \begin{bmatrix} 2a + b \\ a - b \\ 3a \end{bmatrix}, \; a, b \in \R \right\}\) a subspace of \(\R^3\text{?}\)
    🔗
    Solution.
    Yes. Split the vector according to the two parameters:
    \begin{equation*} \begin{bmatrix} 2a + b \\ a - b \\ 3a \end{bmatrix} = a \begin{bmatrix} 2 \\ 1 \\ 3 \end{bmatrix} + b \begin{bmatrix} 1 \\ -1 \\ 0 \end{bmatrix}, \end{equation*}
    so \(V = \operatorname{Span}\left\{ \begin{bmatrix} 2 \\ 1 \\ 3 \end{bmatrix}, \begin{bmatrix} 1 \\ -1 \\ 0 \end{bmatrix} \right\}\text{.}\) By Theorem 5.9, every span is a subspace, so \(V\) is one. Since the two spanning vectors are not multiples of one another, they are independent and \(V\) is a plane through the origin.
    🔗
    The spanning set is not unique. Because
    \begin{equation*} \begin{bmatrix} 3 \\ 0 \\ 3 \end{bmatrix} = \begin{bmatrix} 2 \\ 1 \\ 3 \end{bmatrix} + \begin{bmatrix} 1 \\ -1 \\ 0 \end{bmatrix}, \end{equation*}
    we also have \(V = \operatorname{Span}\left\{ \begin{bmatrix} 2 \\ 1 \\ 3 \end{bmatrix}, \begin{bmatrix} 1 \\ -1 \\ 0 \end{bmatrix}, \begin{bmatrix} 3 \\ 0 \\ 3 \end{bmatrix} \right\}\text{,}\) but that spanning set is linearly dependent: the third vector adds nothing.
    🔗
    🔗
    🔗

    7. ★ Two Different Bases for the Same Subspace.

    Give two different bases for the \(xz\)-plane \(H = \left\{ \begin{bmatrix} x \\ y \\ z \end{bmatrix} \in \R^3 \; \middle| \; y = 0 \right\}\text{,}\) and in each case express a general element of \(H\) in that basis.
    🔗
    Solution.
    The obvious basis. Take \(\mathcal{B}_1 = \{\vec{e}_1, \vec{e}_3\}\text{.}\) Then \(H = \operatorname{Span}\{\vec{e}_1, \vec{e}_3\}\) and
    \begin{equation*} \begin{bmatrix} x \\ 0 \\ z \end{bmatrix} = x\vec{e}_1 + z\vec{e}_3. \end{equation*}
    🔗
    Another basis. Take \(\mathcal{B}_2 = \{\vec{e}_1, \vec{e}_1 + \vec{e}_3\}\text{.}\) These two are independent, and
    \begin{equation*} \begin{bmatrix} x \\ 0 \\ z \end{bmatrix} = (x - z)\vec{e}_1 + z\left( \vec{e}_1 + \vec{e}_3 \right). \end{equation*}
    Checking: \((x-z)(1,0,0) + z(1,0,1) = (x - z + z,\ 0,\ z) = (x,0,z)\text{.}\) \(\checkmark\)
    🔗
    The two bases are different, but both have two elements. That is no accident: by Theorem 5.16, all bases of a given subspace have the same size.
    🔗
    🔗
    🔗

    8. ★ Computing Dimensions.

    Find the dimension of each subspace of \(\R^3\text{:}\)
    \begin{equation*} H_1 = \left\{ \begin{bmatrix} x \\ y \\ z \end{bmatrix} \in \R^3 \; \middle| \; x = 2y, \; z = 0 \right\}, \end{equation*}
    \begin{equation*} H_2 = \left\{ \begin{bmatrix} x \\ y \\ z \end{bmatrix} \in \R^3 \; \middle| \; x + y + z = 0 \right\}. \end{equation*}
    🔗
    Solution.
    \(H_1\text{.}\) Only \(y\) is free. Writing \(y = t\) gives \(x = 2t\) and \(z = 0\text{,}\) so
    \begin{equation*} H_1 = \operatorname{Span}\left\{ \begin{bmatrix} 2 \\ 1 \\ 0 \end{bmatrix} \right\}. \end{equation*}
    A single nonzero vector is a basis, so \(\dim H_1 = 1\text{:}\) a line through the origin.
    🔗
    \(H_2\text{.}\) The condition \(x = -y - z\) leaves \(y\) and \(z\) free. With \(y = s\text{,}\) \(z = t\text{,}\)
    \begin{equation*} \begin{bmatrix} -s - t \\ s \\ t \end{bmatrix} = s \begin{bmatrix} -1 \\ 1 \\ 0 \end{bmatrix} + t \begin{bmatrix} -1 \\ 0 \\ 1 \end{bmatrix}. \end{equation*}
    These two vectors are not multiples of one another, so they form a basis and \(\dim H_2 = 2\text{:}\) a plane through the origin.
    🔗
    The pattern is worth remembering: one linear equation on \(\R^3\) cuts the dimension down by one, giving a plane; two independent equations give a line.
    🔗
    🔗

    9. What Rank Tells You.

    Let \(C\) be the coefficient matrix and \(A\) the augmented matrix of a system of \(m\) linear equations in \(n\) variables. Decide whether each statement is always true, and justify your answer.
    1. If \(\operatorname{rank} C \lt n\text{,}\) the system has infinitely many solutions.
      🔗
      🔗
    2. If \(\operatorname{rank} C = m\text{,}\) the system is consistent.
      🔗
      🔗
    3. If \(\operatorname{rank} C = n\text{,}\) the system has a unique solution.
      🔗
      🔗
    4. If \(\operatorname{rank} A = \operatorname{rank} C = n\text{,}\) the system has a unique solution.
      🔗
      🔗
    5. If the system is inconsistent, then \(\operatorname{rank} A \geq 1\text{.}\)
      🔗
      🔗
    6. A system of five equations in four variables with \(\operatorname{rank} C = 4\) has either no solution or a unique solution.
      🔗
      🔗
    🔗
    Solution.
    Throughout, recall from Observation 5.22 that the rank counts the leading \(1\)s in the reduced row-echelon form.
    🔗
    (a) False. Rank less than \(n\) only says there is at least one non-pivot column; the system could still be inconsistent. Take \(0x = 1\text{:}\) here \(n = 1\text{,}\) \(\operatorname{rank} C = 0 \lt 1\text{,}\) and there is no solution.
    🔗
    (b) True. If \(C\) has \(m\) leading \(1\)s then every one of its \(m\) rows carries a leading \(1\text{.}\) Row reducing \(A\) performs the same operations, so no row of the reduced \(A\) can be of the form \([\,0\ \cdots\ 0 \mid d\,]\) with \(d \neq 0\text{.}\) By Remark 1.32 the system is consistent.
    🔗
    (c) False. Rank \(n\) rules out free variables but not inconsistency. The system \(x = 1\text{,}\) \(0 = 1\) has \(n = 1\) and \(\operatorname{rank} C = 1\text{,}\) and no solution.
    🔗
    (d) True. Now the extra hypothesis \(\operatorname{rank} A = \operatorname{rank} C\) says the augmented column adds no new leading \(1\text{,}\) so the system is consistent; and rank \(n\) means every variable is basic, so there are no parameters. The solution is unique.
    🔗
    (e) True. Inconsistency means the reduced \(A\) contains a row \([\,0\ \cdots\ 0 \mid 1\,]\text{.}\) That row itself has a leading \(1\text{,}\) so \(\operatorname{rank} A \geq 1\text{.}\)
    🔗
    (f) True. This is (b) and (d) combined: \(C\) is \(5 \times 4\) with \(\operatorname{rank} C = 4 = n\text{,}\) so there are never any free variables. Either \(\operatorname{rank} A = 5\text{,}\) in which case the fifth row is \([\,0\ 0\ 0\ 0 \mid 1\,]\) and there is no solution, or \(\operatorname{rank} A = 4\) and the solution is unique.
    🔗
    🔗
    🔗

    10. Computing a Rank.

    Find the rank of \(A = \begin{bmatrix} 1 \amp -3 \amp 2 \\ 1 \amp 0 \amp -1 \\ 1 \amp -4 \amp 3 \\ 1 \amp 1 \amp -2 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    Clear the first column using row \(1\text{:}\)
    \begin{equation*} \begin{bmatrix} 1 \amp -3 \amp 2 \\ 1 \amp 0 \amp -1 \\ 1 \amp -4 \amp 3 \\ 1 \amp 1 \amp -2 \end{bmatrix} \longrightarrow \begin{bmatrix} 1 \amp -3 \amp 2 \\ 0 \amp 3 \amp -3 \\ 0 \amp -1 \amp 1 \\ 0 \amp 4 \amp -4 \end{bmatrix}. \end{equation*}
    Rows \(2\text{,}\) \(3\) and \(4\) are all multiples of \([0\ 1\ {-1}]\text{,}\) so two more rounds of row operations give
    \begin{equation*} \begin{bmatrix} 1 \amp 0 \amp -1 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    There are two leading \(1\)s, so \(\operatorname{rank} A = 2\text{.}\)
    🔗
    🔗
    🔗

    11. Designing the Right-Hand Side.

    Let
    \begin{equation*} A = \begin{bmatrix} 1 \amp 0 \amp -3 \amp -2 \amp 0 \\ 0 \amp 1 \amp 2 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    1. What is the rank of \(A\text{?}\)
      🔗
      🔗
    2. How many parameters are there in the general solution of \(A\vec{x} = \vec{0}\text{?}\)
      🔗
      🔗
    3. If possible, find a nonzero \(\vec{b}\) with \(A\vec{x} = \vec{b}\) having no solution; otherwise explain why none exists.
      🔗
      🔗
    4. Same question, with \(A\vec{x} = \vec{b}\) having a unique solution.
      🔗
      🔗
    5. Same question, with \(A\vec{x} = \vec{b}\) having infinitely many solutions.
      🔗
      🔗
    🔗
    Solution.
    (a) \(A\) is already in reduced row-echelon form with leading \(1\)s in columns \(1\text{,}\) \(2\) and \(5\text{,}\) so \(\operatorname{rank} A = 3\text{.}\)
    🔗
    (b) There are five variables and three of them are basic, so \(x_3\) and \(x_4\) are free: two parameters. (Equivalently, \(5 - 3 = 2\) by Theorem 5.26.)
    🔗
    (c) Write \(\vec{b} = [b_1\ b_2\ b_3\ b_4]^T\text{.}\) Since the fourth row of \(A\) is zero, the augmented matrix \([A \mid \vec{b}]\) has last row \([\,0\ 0\ 0\ 0\ 0 \mid b_4\,]\text{.}\) So any \(\vec{b}\) with \(b_4 \neq 0\) works, for instance \(\vec{b} = [0\ 0\ 0\ 1]^T\text{.}\)
    🔗
    (d) No such vector exists. Whenever the system is consistent, \(x_3\) and \(x_4\) are still free, so there are always infinitely many solutions.
    🔗
    (e) Any nonzero \(\vec{b}\) with \(b_4 = 0\text{,}\) for instance \(\vec{b} = [1\ 0\ 0\ 0]^T\text{.}\) Then the system is consistent and, by (d), has infinitely many solutions.
    🔗
    🔗
    🔗

    12. ★ Finding the Rank and Column Space.

    Find the rank of
    \begin{equation*} A = \begin{bmatrix} 1 \amp 1 \amp 2 \amp 0 \amp 1 \\ 2 \amp 3 \amp 7 \amp 1 \amp 3 \\ 1 \amp 2 \amp 5 \amp 1 \amp 2 \end{bmatrix} \end{equation*}
    and describe \(\operatorname{Col} A\) efficiently.
    🔗
    Solution.
    Row reduce:
    \begin{align*} A \amp \xrightarrow[-r_1 + r_3]{-2r_1 + r_2} \begin{bmatrix} 1 \amp 1 \amp 2 \amp 0 \amp 1 \\ 0 \amp 1 \amp 3 \amp 1 \amp 1 \\ 0 \amp 1 \amp 3 \amp 1 \amp 1 \end{bmatrix}\\ \amp \xrightarrow{-r_2 + r_3} \begin{bmatrix} 1 \amp 1 \amp 2 \amp 0 \amp 1 \\ 0 \amp 1 \amp 3 \amp 1 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}\\ \amp \xrightarrow{-r_2 + r_1} \begin{bmatrix} 1 \amp 0 \amp -1 \amp -1 \amp 0 \\ 0 \amp 1 \amp 3 \amp 1 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}. \end{align*}
    🔗
    There are two leading \(1\)s, in columns \(1\) and \(2\text{,}\) so \(\operatorname{rank} A = 2\text{.}\) By Observation 5.22, a basis for the column space is given by the columns of the original \(A\) in the pivot positions:
    \begin{equation*} \operatorname{Col} A = \operatorname{Span}\left\{ \begin{bmatrix} 1 \\ 2 \\ 1 \end{bmatrix}, \begin{bmatrix} 1 \\ 3 \\ 2 \end{bmatrix} \right\}. \end{equation*}
    🔗
    It is essential to take the columns of \(A\text{,}\) not of the reduced matrix: row operations preserve the linear relations among columns but change the columns themselves.

    13. ★ Finding a Null Space.

    Find \(\operatorname{Nul} A\) for \(A = \begin{bmatrix} 1 \amp 1 \amp 2 \\ 2 \amp 1 \amp 3 \\ 1 \amp 0 \amp 1 \end{bmatrix}\text{.}\)
    🔗
    Solution.
    Solve \(A\vec{x} = \vec{0}\text{:}\)
    \begin{align*} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 2 \amp 0 \\ 2 \amp 1 \amp 3 \amp 0 \\ 1 \amp 0 \amp 1 \amp 0 \end{array} \right] \amp \xrightarrow[-r_1 + r_3]{-2r_1 + r_2} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 2 \amp 0 \\ 0 \amp -1 \amp -1 \amp 0 \\ 0 \amp -1 \amp -1 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-r_2 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 2 \amp 0 \\ 0 \amp -1 \amp -1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]\\ \amp \xrightarrow[r_2 + r_1]{-r_2} \left[ \begin{array}{ccc|c} 1 \amp 0 \amp 1 \amp 0 \\ 0 \amp 1 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{align*}
    🔗
    With \(z = t\) free, the rows give \(x = -t\) and \(y = -t\text{,}\) so
    \begin{equation*} \vec{x} = t \begin{bmatrix} -1 \\ -1 \\ 1 \end{bmatrix}, \qquad \operatorname{Nul} A = \operatorname{Span}\left\{ \begin{bmatrix} -1 \\ -1 \\ 1 \end{bmatrix} \right\}, \end{equation*}
    a line through the origin. Since the spanning set has one vector, \(\dim \operatorname{Nul} A = 1\text{.}\)
    🔗
    Checking: \(A(-1,-1,1) = (-1 - 1 + 2,\ -2 - 1 + 3,\ -1 - 0 + 1) = \vec{0}\text{.}\) \(\checkmark\)
    🔗

    14. ★ Checking the Rank–Nullity Relation.

    Verify Theorem 5.26 for the matrix \(A = \begin{bmatrix} 1 \amp 1 \amp 2 \\ 2 \amp 1 \amp 3 \\ 1 \amp 0 \amp 1 \end{bmatrix}\) of Exercise 10.5.13.
    🔗
    Solution.
    The row reduction there ended at
    \begin{equation*} A \; \longrightarrow \; \begin{bmatrix} 1 \amp 0 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 0 \end{bmatrix}, \end{equation*}
    which has two leading \(1\)s, so \(\operatorname{rank} A = 2\text{.}\)
    🔗
    We also found \(\dim \operatorname{Nul} A = 1\text{,}\) and \(A\) is \(3 \times 3\text{,}\) so \(n = 3\text{.}\) Then
    \begin{equation*} \underbrace{\operatorname{rank} A}_{2} + \underbrace{\dim \operatorname{Nul} A}_{1} = \underbrace{n}_{3}. \checkmark \end{equation*}
    🔗
    The relation is really a statement about pivots: each of the \(n\) columns either carries a pivot (contributing to the rank) or corresponds to a free variable (contributing a basic solution to the null space), and never both.
