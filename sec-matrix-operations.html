    Section 4.1 Matrix Operations

    We begin by fixing notation for matrices and defining the two most basic operations on them: addition and multiplication by a scalar.
    🔗

    Subsection 4.1.1 Matrices and Terminology

    Definition 4.1. Matrix.

    Let \(m\) and \(n\) be positive integers.
    🔗
    An \(m \times n\) matrix is a rectangular array of numbers having \(m\) rows and \(n\) columns. Such a matrix is said to have size \(m \times n\text{.}\)
    🔗
    The number \(a_{ij}\) is the \((i,j)\)-entry of a matrix, which is the entry in row \(i\) and column \(j\text{:}\)
    \begin{equation*} A = \begin{bmatrix} a_{11} \amp a_{12} \amp a_{13} \amp \cdots \amp a_{1n} \\ a_{21} \amp a_{22} \amp a_{23} \amp \cdots \amp a_{2n} \\ a_{31} \amp a_{32} \amp a_{33} \amp \cdots \amp a_{3n} \\ \vdots \amp \vdots \amp \vdots \amp \amp \vdots \\ a_{m1} \amp a_{m2} \amp a_{m3} \amp \cdots \amp a_{mn} \end{bmatrix} = \begin{bmatrix} a_{ij} \end{bmatrix} \end{equation*}
    🔗
    🔗

    Definition 4.2. Diagonal, Identity, and Zero Matrices.

    Let \(A = \begin{bmatrix} a_{ij} \end{bmatrix}\) be an \(m \times n\) matrix.
    🔗
    • The entries \(a_{11}, a_{22}, a_{33}, \ldots\) are the diagonal entries of \(A\text{,}\) and together they form the main diagonal of \(A\text{.}\)
      🔗
    • A matrix is square if \(m = n\text{.}\)
      🔗
    • The identity matrix \(I_n = I_{n \times n}\) is the square \(n \times n\) matrix whose diagonal entries are all \(1\) and whose other entries are all \(0\text{.}\)
      🔗
    • The zero matrix \(0_{m \times n}\) is the \(m \times n\) matrix all of whose entries are \(0\text{.}\)
      🔗
    🔗
    🔗

    Example 4.3. Reading Entries off a Matrix.

    Let
    \begin{equation*} A = \begin{bmatrix} 1 \amp 2 \amp 0 \\ 0 \amp 1 \amp -1 \\ 1 \amp 0 \amp 1 \end{bmatrix} = \begin{bmatrix} a_{ij} \end{bmatrix}. \end{equation*}
    Identify the size of \(A\text{,}\) the entry \(a_{23}\text{,}\) and the main diagonal of \(A\text{.}\)
    🔗
    Solution.
    \(A\) is a \(3 \times 3\) matrix. The entry \(a_{23}\) sits in row \(2\) and column \(3\text{,}\) so \(a_{23} = -1\text{.}\)
    🔗
    The main diagonal consists of the entries \(a_{11} = 1\text{,}\) \(a_{22} = 1\text{,}\) and \(a_{33} = 1\text{,}\) running from the upper-left corner to the lower-right corner of \(A\text{.}\)
    🔗
    🔗
    🔗

    Example 4.4. Zero and Identity Matrices.

    The \(2 \times 2\) zero matrix and the \(4 \times 4\) identity matrix are
    \begin{align*} 0_{2 \times 2} \amp = \begin{bmatrix} 0 \amp 0 \\ 0 \amp 0 \end{bmatrix},\\ I_4 = I_{4 \times 4} \amp = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}. \end{align*}
    🔗
    🔗
    🔗

    Subsection 4.1.2 Matrix Addition

    Definition 4.5. Matrix Addition.

    Let \(A = \begin{bmatrix} a_{ij} \end{bmatrix}\) and \(B = \begin{bmatrix} b_{ij} \end{bmatrix}\) be two \(m \times n\) matrices. Then \(A + B = C\text{,}\) where \(C\) is the \(m \times n\) matrix \(C = \begin{bmatrix} c_{ij} \end{bmatrix}\) defined by
    \begin{equation*} c_{ij} = a_{ij} + b_{ij}. \end{equation*}
    🔗
    🔗
    Notice that matrix addition is only defined when the two matrices have the same size, and that addition is performed entry by entry.
    🔗

    Example 4.6. Adding Two Matrices.

    Let \(A = \begin{bmatrix} 1 \amp 2 \\ 3 \amp 4 \end{bmatrix}\) and \(B = \begin{bmatrix} -1 \amp 2 \\ 4 \amp 3 \end{bmatrix}\text{.}\) Compute \(C = A + B\text{.}\)
    🔗
    Solution.
    \begin{equation*} C = A + B = \begin{bmatrix} 1 + (-1) \amp 2 + 2 \\ 3 + 4 \amp 4 + 3 \end{bmatrix} = \begin{bmatrix} 0 \amp 4 \\ 7 \amp 7 \end{bmatrix}. \end{equation*}
    🔗
    For instance, the \((1,2)\)-entry is \(c_{12} = a_{12} + b_{12} = 2 + 2 = 4\text{.}\)
    🔗
    🔗
    🔗

    Theorem 4.7. Properties of Matrix Addition.

    Let \(A\text{,}\) \(B\text{,}\) and \(C\) be \(m \times n\) matrices. Then the following properties hold.
    🔗
    1. \(A + B = B + A\) (matrix addition is commutative).
      🔗
      🔗
    2. \((A + B) + C = A + (B + C)\) (matrix addition is associative).
      🔗
      🔗
    3. There exists an \(m \times n\) zero matrix, \(0\text{,}\) such that \(A + 0 = A\) (existence of an additive identity).
      🔗
      🔗
    4. There exists an \(m \times n\) matrix \(-A\) such that \(A + (-A) = 0\) (existence of an additive inverse).
      🔗
      🔗
    🔗
    🔗

    Proof of (2).
    The \((i,j)\)-entry of \((A + B) + C\) is
    \begin{equation*} \left( a_{ij} + b_{ij} \right) + c_{ij}, \end{equation*}
    which is equal to the \((i,j)\)-entry of \(A + (B + C)\text{,}\) i.e.,
    \begin{equation*} a_{ij} + \left( b_{ij} + c_{ij} \right). \end{equation*}
    The two matrices therefore agree entry by entry, so they are equal.
    🔗
    🔗

    Remark 4.8.

    Each of these properties is inherited from the corresponding property of addition of real numbers, applied one entry at a time. The proof of (2) above is the model for the proofs of (1), (3), and (4).
    🔗
    🔗
    🔗

    Subsection 4.1.3 Scalar Multiplication

    Definition 4.9. Scalar Multiplication.

    Let \(A = \begin{bmatrix} a_{ij} \end{bmatrix}\) be an \(m \times n\) matrix and let \(k\) be a scalar. Then
    \begin{equation*} kA = \begin{bmatrix} k a_{ij} \end{bmatrix}. \end{equation*}
    🔗
    🔗

    Example 4.10. Multiplying by a Scalar.

    If \(A = \begin{bmatrix} 1 \amp 2 \\ 3 \amp 4 \end{bmatrix}\text{,}\) then
    \begin{equation*} 2A = \begin{bmatrix} 2 \amp 4 \\ 6 \amp 8 \end{bmatrix}. \end{equation*}
    🔗
    🔗

    Theorem 4.11. Properties of Scalar Multiplication.

    Let \(A\text{,}\) \(B\) be \(m \times n\) matrices and let \(k, p \in \R\) (scalars). Then the following properties hold.
    🔗
    1. \(k(A + B) = kA + kB\) (scalar multiplication distributes over matrix addition).
      🔗
      🔗
    2. \((k + p)A = kA + pA\) (addition distributes over scalar multiplication).
      🔗
      🔗
    3. \(k(pA) = (kp)A\) (scalar multiplication is associative).
      🔗
      🔗
    🔗
    🔗

    Example 4.12. Combining Scalar Multiples.

    Simplify
    \begin{equation*} 3 \begin{bmatrix} 1 \amp 0 \\ -1 \amp 1 \end{bmatrix} - \begin{bmatrix} 1 \amp 0 \\ -1 \amp 1 \end{bmatrix} - \begin{bmatrix} -3 \amp 0 \\ 3 \amp -3 \end{bmatrix}. \end{equation*}
    🔗
    Solution.
    Every matrix appearing here is a scalar multiple of \(M = \begin{bmatrix} 1 \amp 0 \\ -1 \amp 1 \end{bmatrix}\text{;}\) indeed, \(\begin{bmatrix} -3 \amp 0 \\ 3 \amp -3 \end{bmatrix} = -3M\text{.}\) So by Theorem 4.11 (2),
    \begin{align*} 3M - M - (-3M) \amp = (3 - 1 + 3)M\\ \amp = 5 \begin{bmatrix} 1 \amp 0 \\ -1 \amp 1 \end{bmatrix}\\ \amp = \begin{bmatrix} 5 \amp 0 \\ -5 \amp 5 \end{bmatrix}. \end{align*}
    🔗
