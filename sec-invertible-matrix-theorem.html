    Section 4.6 The Invertible Matrix Theorem

    We already discussed Theorem 4.43, and in what follows we will be building on it. The result below gathers together, in a single list, every characterization of invertibility we have met so far: in terms of row reduction, pivots, linear independence, spanning, solvability of \(A\vec{x} = \vec{b}\text{,}\) one-sided inverses, and the transpose.
    🔗
    Throughout this section, \(T_A\) denotes the linear transformation \(T_A(\vec{x}) = A\vec{x}\) associated with the matrix \(A\text{.}\)
    🔗

    Subsection 4.6.1 Statement of the Theorem

    Theorem 4.57. The Invertible Matrix Theorem.

    Let \(A\) be an \(n \times n\) matrix, and let \(\vec{X}\text{,}\) \(\vec{B}\) be \(n \times 1\) vectors. The following conditions are equivalent.
    🔗
    1. \(A\) is invertible.
      🔗
      🔗
    2. \(A\vec{X} = \vec{0}\) has only the trivial solution, \(\vec{X} = \vec{0}\text{.}\) (Equivalently, \(T_A(\vec{x}) = A\vec{x}\) is one-to-one.)
      🔗
      🔗
    3. \(A\) can be transformed to \(I_n\) by elementary row operations.
      🔗
      🔗
    4. \(A\) has \(n\) pivot positions.
      🔗
      🔗
    5. The columns of \(A\) are linearly independent.
      🔗
      🔗
    6. The columns of \(A\) span \(\R^n\text{.}\) (Equivalently, \(T_A(\vec{x}) = A\vec{x}\) is onto.)
      🔗
      🔗
    7. The system \(A\vec{X} = \vec{B}\) has a unique solution \(\vec{X}\) for any choice of \(\vec{B}\text{.}\)
      🔗
      🔗
    8. There exists an \(n \times n\) matrix \(C\) with the property that \(AC = I_n\text{.}\)
      🔗
      🔗
    9. There exists an \(n \times n\) matrix \(D\) with the property that \(DA = I_n\text{.}\)
      🔗
      🔗
    10. \(A^T\) is invertible.
      🔗
      🔗
    🔗
    🔗

    Remark 4.58.

    Conditions (8) and (9) are worth pausing over. They say that for square matrices, a one-sided inverse is automatically a two-sided inverse. This is what completes the argument left unfinished in the proof of Theorem 4.43.
    🔗
    🔗
    🔗

    Subsection 4.6.2 Proof of the Equivalences

    (1) \(\Longleftrightarrow\) (2). We already discussed that if (1) holds, then the reduced row-echelon matrix of \(A\) will be \(I_n\text{,}\) which means \(A\vec{x} = \vec{0}\) implies \(\vec{x} = \vec{0}\text{,}\) which is (2). Conversely, if (2) holds, then the system has no free variables, so after row reduction there is a leading one in every row. Since the matrix \(A\) is \(n \times n\text{,}\) its reduced row-echelon matrix is therefore \(I_n\text{,}\) and hence \(A\) is invertible.
    🔗
    (1) \(\Longleftrightarrow\) (3). We already discussed this equivalence.
    🔗
    (1) \(\Longleftrightarrow\) (4). We have also already discussed this equivalence. Note that the reduced row-echelon matrix being \(I_n\) is the same as having \(n\) pivot positions.
    🔗
    (2) \(\Longleftrightarrow\) (5). We proved a few sessions ago that the columns of \(A\) are linearly independent if and only if \(A\vec{x} = \vec{0}\) implies \(\vec{x} = \vec{0}\text{.}\)
    🔗
    (3) \(\Longleftrightarrow\) (6). If \(A\) can be transformed to \(I_n\text{,}\) then \(A\vec{x} = \vec{b}\) is a consistent system of linear equations for all \(\vec{b} \in \R^n\text{,}\) and hence the columns of \(A\) span \(\R^n\text{;}\) i.e., for all \(\vec{b}\) in \(\R^n\) we can find a linear combination
    \begin{equation*} x_1 \vec{A}_1 + x_2 \vec{A}_2 + \cdots + x_n \vec{A}_n = \vec{b}. \end{equation*}
    Conversely, if the columns of \(A\) span \(\R^n\text{,}\) then \(A\vec{x} = \vec{b}\) is a consistent system for all \(\vec{b} \in \R^n\text{,}\) and the last row of the row-echelon matrix cannot be all zeros. This means there are \(n\) leading ones, and hence the reduced row-echelon matrix is \(I_n\text{.}\)
    🔗
    (3) \(\Longleftrightarrow\) (7). If \(A\) can be reduced to \(I_n\text{,}\) then we know that the solution to \(A\vec{x} = \vec{b}\) exists uniquely for all \(\vec{b} \in \R^n\text{.}\) Conversely, if \(A\vec{x} = \vec{b}\) has a unique solution for any \(\vec{b} \in \R^n\text{,}\) then the reduced row-echelon matrix cannot have a row of zeros, which means \(I_n\) is the reduced row-echelon matrix.
    🔗
    (1) \(\Longleftrightarrow\) (8). If \(A\) is invertible, by definition we have \(AA^{-1} = I\text{,}\) so we may take \(C = A^{-1}\text{.}\)
    🔗
    Now let us assume there exists an \(n \times n\) matrix \(C\) with the property that \(AC = I_n\text{.}\) We can show that \(A\) is onto and hence invertible: for any \(\vec{b} \in \R^n\text{,}\) we can write
    \begin{equation*} \vec{b} = I \vec{b} = (AC)\vec{b} = A \left( C\vec{b} \right), \end{equation*}
    or \(T_A \left( C\vec{b} \right) = \vec{b}\text{.}\) This means that for any \(\vec{b} \in \R^n\) there exists \(\vec{x} = C\vec{b} \in \R^n\) such that \(T_A(\vec{x}) = \vec{b}\text{,}\) and hence \(T_A\) is onto and therefore \(A\) is invertible, by the equivalence of (1) and (6).
    🔗
    (1) \(\Longleftrightarrow\) (9). If \(A\) is invertible, by definition we have \(A^{-1}A = I\text{,}\) so we may take \(D = A^{-1}\text{.}\)
    🔗
    Now assume \(DA = I\text{.}\) We can show that \(T_A\) is one-to-one and hence \(A\) is invertible. If \(T_A(\vec{x}_1) = T_A(\vec{x}_2)\text{,}\) then \(A\vec{x}_1 = A\vec{x}_2\) and so \(DA\vec{x}_1 = DA\vec{x}_2\text{,}\) which gives \(\vec{x}_1 = \vec{x}_2\) since \(DA = I\text{.}\) Hence \(T_A\) is injective and \(A\) is invertible.
    🔗
    (1) \(\Longleftrightarrow\) (10). If \(A\) is invertible, then
    \begin{align*} \left( A A^{-1} \right)^T \amp = I^T \amp \amp \Longrightarrow \amp \left( A^{-1} \right)^T A^T \amp = I,\\ \left( A^{-1} A \right)^T \amp = I^T \amp \amp \Longrightarrow \amp A^T \left( A^{-1} \right)^T \amp = I, \end{align*}
    so \(A^T\) is invertible and \(\left( A^T \right)^{-1} = \left( A^{-1} \right)^T\text{.}\)
    🔗
    Conversely, if \(A^T\) is invertible, then transposing each of \(\left( A^T \right)^{-1} A^T = I\) and \(A^T \left( A^T \right)^{-1} = I\) gives
    \begin{align*} A \left( \left( A^T \right)^{-1} \right)^T \amp = I,\\ \left( \left( A^T \right)^{-1} \right)^T A \amp = I, \end{align*}
    so \(\left( \left( A^T \right)^{-1} \right)^T = A^{-1}\) and \(A\) is invertible.
    🔗
    🔗

    Subsection 4.6.3 Using the Theorem

    Example 4.60. Detecting Non-Invertibility from the Columns.

    Is the following matrix invertible?
    \begin{equation*} \begin{bmatrix} 1 \amp -1 \amp 1 \amp 2 \\ 0 \amp 1 \amp 5 \amp -1 \\ 1 \amp 0 \amp 7 \amp 1 \\ 0 \amp 2 \amp 10 \amp -2 \end{bmatrix} \end{equation*}
    🔗
    Solution.
    Label the columns \(\vec{u}_1, \vec{u}_2, \vec{u}_3, \vec{u}_4\text{.}\) Since
    \begin{equation*} \vec{u}_1 - \vec{u}_2 = \begin{bmatrix} 1 \\ 0 \\ 1 \\ 0 \end{bmatrix} - \begin{bmatrix} -1 \\ 1 \\ 0 \\ 2 \end{bmatrix} = \begin{bmatrix} 2 \\ -1 \\ 1 \\ -2 \end{bmatrix} = \vec{u}_4, \end{equation*}
    we know that the columns are not linearly independent, and hence the matrix is not invertible by condition (5) of Theorem 4.57.
    🔗
    🔗
    🔗

    Example 4.61. True or False?

    1. Invertible transformations map the zero vector to itself.
      🔗
      🔗
    2. Non-invertible matrices cannot be written as a product of elementary matrices.
      🔗
      🔗
    🔗
    Solution.
    (a) True. Condition (2) of Theorem 4.57 says that for invertible matrices we have \(A\vec{x} = \vec{0}\) implies \(\vec{x} = \vec{0}\text{.}\) This means \(T_A(\vec{0}) = \vec{0}\text{.}\)
    🔗
    (b) True. If we assume that a non-invertible matrix \(A\) can be written as a product of elementary matrices, \(A = E_1 E_2 \cdots E_n\text{,}\) we can easily see that the product is invertible since each elementary matrix is invertible:
    \begin{equation*} \left( E_1 E_2 \cdots E_n \right)^{-1} = E_n^{-1} E_{n-1}^{-1} \cdots E_2^{-1} E_1^{-1}, \end{equation*}
    which means we reach a contradiction. Hence non-invertible matrices cannot be written as a product of elementary matrices.
    🔗
    🔗
    🔗

    Example 4.62. An Inverse from a Polynomial Identity.

    Suppose \(P\) is a square matrix which satisfies the following:
    \begin{equation*} P^3 + 2P^2 + 2P - 3I = 0. \end{equation*}
    Find \(P^{-1}\text{,}\) if possible.
    🔗
    Solution.
    Divide the identity by \(3\) and isolate \(I\text{:}\)
    \begin{align*} \tfrac{1}{3}\left( P^3 + 2P^2 + 2P - 3I \right) \amp = 0\\ \tfrac{1}{3}\left( P^3 + 2P^2 + 2P \right) - I \amp = 0\\ \tfrac{1}{3}\left( P^3 + 2P^2 + 2P \right) \amp = I. \end{align*}
    🔗
    Factoring \(P\) out on the left gives
    \begin{equation*} P \left[ \tfrac{1}{3} \left( P^2 + 2P + 2I \right) \right] = I, \end{equation*}
    so by condition (8) of Theorem 4.57, \(P\) is invertible and
    \begin{equation*} P^{-1} = \tfrac{1}{3} \left( P^2 + 2P + 2I \right). \end{equation*}
