    1. ★ The Vector Space of Polynomials \(\mathbb{P}_1\).

    Let \(\mathbb{P}_1\) be the set of all polynomials of degree at most \(1\text{,}\) together with the zero polynomial, with the usual addition and scalar multiplication. Show that \(\mathbb{P}_1\) is a vector space.
    🔗
    Solution.
    Explicitly, \(\mathbb{P}_1 = \left\{ a_1 x + a_0 \; \middle| \; a_0, a_1 \in \R \right\}\text{.}\) Let \(f(x) = a_1 x + a_0\text{,}\) \(g(x) = b_1 x + b_0\text{,}\) and let \(c, d \in \R\text{.}\)
    🔗
    (I) Closure under addition.
    \begin{equation*} (f + g)(x) = (a_1 + b_1)x + (a_0 + b_0) \in \mathbb{P}_1, \end{equation*}
    again of degree at most \(1\text{.}\)
    🔗
    (II) Commutativity and (V) associativity hold because addition of the real coefficients is commutative and associative.
    🔗
    (III) Additive identity. The zero polynomial \(P_0(x) = 0\) is in \(\mathbb{P}_1\) and \(f + P_0 = f\text{.}\)
    🔗
    (IV) Additive inverse. Put \(-f(x) = -a_1 x - a_0\text{.}\) Then \(f + (-f) = P_0\text{.}\)
    🔗
    (VI) Closure under scalar multiplication.
    \begin{equation*} c f(x) = (c a_1)x + (c a_0) \in \mathbb{P}_1. \end{equation*}
    🔗
    (VII)–(X) follow one coefficient at a time; for instance \(c(d f(x)) = (cd a_1)x + (cd a_0) = (cd)f(x)\) and \(1f(x) = f(x)\text{.}\)
    🔗
    All ten axioms hold, so \(\mathbb{P}_1\) is a vector space. Note that the degree exactly one polynomials would not form a vector space: that set omits the zero polynomial, and \((x+1) + (-x)\) would leave it.
    🔗
    🔗
    🔗

    2. ★ The Vector Space of \(2 \times 3\) Matrices.

    Let \(\mathbb{M}_{23}\) be the set of all \(2 \times 3\) matrices. Is \(\mathbb{M}_{23}\) a vector space?
    🔗
    Solution.
    Yes. Let \(A, B, C \in \mathbb{M}_{23}\) and \(a, b \in \R\text{.}\)
    🔗
    • (I) \(A + B \in \mathbb{M}_{23}\text{,}\) since the sum of two \(2 \times 3\) matrices is again \(2 \times 3\text{.}\)
      🔗
      🔗
    • (II), (III), (IV), (V) follow from Theorem 4.7, taking the zero element to be \(0_{2 \times 3}\text{.}\)
      🔗
      🔗
    • (VI) \(aA \in \mathbb{M}_{23}\text{,}\) since scaling does not change the size.
      🔗
      🔗
    • (VII)–(X) follow from Theorem 4.11.
      🔗
      🔗
    🔗
    Nothing used the fact that the matrices were \(2 \times 3\) rather than \(m \times n\text{:}\) the same argument shows \(\mathbb{M}_{mn}\) is a vector space for any \(m\) and \(n\text{.}\)

    3. ★ A Subspace of \(\mathbb{M}_{22}\).

    Is the following subset of \(\mathbb{M}_{22}\) a subspace?
    \begin{equation*} \mathbb{M}_U = \left\{ \begin{bmatrix} x \amp y \\ 0 \amp z \end{bmatrix} \; \middle| \; x - y + z = 0 \right\}. \end{equation*}
    🔗
    Solution.
    Yes. Let \(A = \begin{bmatrix} a_1 \amp a_2 \\ 0 \amp a_3 \end{bmatrix}\) and \(B = \begin{bmatrix} b_1 \amp b_2 \\ 0 \amp b_3 \end{bmatrix}\) lie in \(\mathbb{M}_U\text{,}\) so \(a_1 - a_2 + a_3 = 0\) and \(b_1 - b_2 + b_3 = 0\text{.}\)
    🔗
    Closed under addition.
    \begin{equation*} A + B = \begin{bmatrix} a_1 + b_1 \amp a_2 + b_2 \\ 0 \amp a_3 + b_3 \end{bmatrix}, \end{equation*}
    whose lower-left entry is still \(0\text{,}\) and
    \begin{equation*} (a_1 + b_1) - (a_2 + b_2) + (a_3 + b_3) = 0 + 0 = 0, \end{equation*}
    so \(A + B \in \mathbb{M}_U\text{.}\)
    🔗
    Closed under scalar multiplication. For \(c \in \R\text{,}\) \(cA = \begin{bmatrix} ca_1 \amp ca_2 \\ 0 \amp ca_3 \end{bmatrix}\) and
    \begin{equation*} ca_1 - ca_2 + ca_3 = c(a_1 - a_2 + a_3) = 0, \end{equation*}
    so \(cA \in \mathbb{M}_U\text{.}\)
    🔗
    Contains the zero element. Taking \(c = 0\) above gives \(0_{2 \times 2} \in \mathbb{M}_U\text{.}\) The remaining axioms are inherited from \(\mathbb{M}_{22}\text{,}\) so \(\mathbb{M}_U\) is a subspace.
    🔗
    Both defining conditions are linear and homogeneous, which is exactly why closure works. A condition such as \(x - y + z = 1\) would fail, since the zero matrix would not satisfy it.
    🔗

    4. ★ A Standard Basis and a Subspace.

    1. Show that \(\{1, x\}\) is a basis for \(\mathbb{P}_1\text{.}\)
      🔗
      🔗
    2. Is \(\operatorname{Span}\{1 + x^2, \; 2x\}\) a subspace of \(\mathbb{P}_2\text{?}\) If so, is \(\{1 + x^2, \; 2x\}\) a basis for it?
      🔗
      🔗
    🔗
    Solution.
    (1) Every element of \(\mathbb{P}_1\) has the form \(a_1 x + a_0 = a_0(1) + a_1(x)\text{,}\) so \(\{1,x\}\) spans \(\mathbb{P}_1\text{.}\) It is also independent: if \(a_0(1) + a_1(x)\) is the zero polynomial, then it takes the value \(0\) for every \(x\text{,}\) and setting \(x = 0\) gives \(a_0 = 0\text{,}\) after which \(a_1 x = 0\) for all \(x\) forces \(a_1 = 0\text{.}\) So \(\{1,x\}\) is a basis and \(\dim \mathbb{P}_1 = 2\text{.}\)
    🔗
    (2) Yes. The set \(\{1 + x^2, \; 2x\}\) is a subset of \(\mathbb{P}_2\text{,}\) so its span is a subspace of \(\mathbb{P}_2\) by Theorem 7.8.
    🔗
    The two polynomials are independent: neither is a scalar multiple of the other, since only the first involves \(x^2\) and only the second involves a lone \(x\text{.}\) An independent spanning set is a basis, so \(\{1 + x^2, \; 2x\}\) is a basis for that subspace, which therefore has dimension \(2\) — one less than \(\dim \mathbb{P}_2 = 3\text{.}\)
    🔗

    5. ★ \(\mathbb{M}_{22}\) and \(\R^4\) Are Isomorphic.

    Show that \(\mathbb{M}_{22}\) and \(\R^4\) are isomorphic.
    🔗
    Solution.
    Define \(T : \mathbb{M}_{22} \to \R^4\) by reading the entries in order:
    \begin{equation*} T \left( \begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix} \right) = \begin{bmatrix} a \\ b \\ c \\ d \end{bmatrix}. \end{equation*}
    🔗
    \(T\) is linear, since matrix addition and scalar multiplication are computed entry by entry, and so is vector addition and scalar multiplication in \(\R^4\text{.}\)
    🔗
    \(T\) is one-to-one: if \(T(A) = \vec{0}\text{,}\) then every entry of \(A\) is \(0\text{,}\) so \(A = 0_{2 \times 2}\text{.}\)
    🔗
    \(T\) is onto: given \((a,b,c,d) \in \R^4\text{,}\) the matrix \(\begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix}\) maps to it.
    🔗
    A linear bijection is an isomorphism, so \(\mathbb{M}_{22} \cong \R^4\text{.}\) This is really the observation that \(T\) is the coordinate map for the standard basis \(\{M_{11}, M_{12}, M_{21}, M_{22}\}\text{:}\) an \(n\)-dimensional space is always isomorphic to \(\R^n\text{.}\)

    🔗

    6. ★ A Transformation from \(\mathbb{P}_2\) to \(\R^2\).

    Consider \(T : \mathbb{P}_2 \to \R^2\) defined by
    \begin{equation*} T(P(x)) = \begin{bmatrix} P(1) \\ P'(0) \end{bmatrix}. \end{equation*}
    1. Using the standard bases, find the matrix of \(T\text{.}\)
      🔗
      🔗
    2. Is \(T\) one-to-one?
      🔗
      🔗
    🔗
    Solution.
    (A) Write \(P(x) = ax^2 + bx + c\text{,}\) so \(P'(x) = 2ax + b\text{.}\) Then
    \begin{equation*} T(P(x)) = \begin{bmatrix} a + b + c \\ b \end{bmatrix}. \end{equation*}
    🔗
    Using the isomorphism that sends \(ax^2 + bx + c\) to \(\begin{bmatrix} c \\ b \\ a \end{bmatrix}\text{,}\) the basis polynomials \(1, x, x^2\) correspond to \(\vec{e}_1, \vec{e}_2, \vec{e}_3\text{,}\) with images
    \begin{equation*} T(1) = \begin{bmatrix} 1 \\ 0 \end{bmatrix}, \quad T(x) = \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \quad T(x^2) = \begin{bmatrix} 1 \\ 0 \end{bmatrix}, \end{equation*}
    so
    \begin{equation*} A = \begin{bmatrix} 1 \amp 1 \amp 1 \\ 0 \amp 1 \amp 0 \end{bmatrix}. \end{equation*}
    Checking, \(A(c,b,a)^T = (c + b + a,\ b)\text{.}\) \(\checkmark\)
    🔗
    (B) No. Solving \(A\vec{x} = \vec{0}\) gives \(b = 0\) from the second row and then \(c + a = 0\) from the first, so
    \begin{equation*} \begin{bmatrix} c \\ b \\ a \end{bmatrix} = t \begin{bmatrix} 1 \\ 0 \\ -1 \end{bmatrix}, \end{equation*}
    a nontrivial null space. Concretely, \(P(x) = 1 - x^2\) has \(P(1) = 0\) and \(P'(0) = 0\text{,}\) so
    \begin{equation*} T(1 - x^2) = \begin{bmatrix} 0 \\ 0 \end{bmatrix} = T(0), \end{equation*}
    two different polynomials with the same image.
    🔗
    There was no chance of injectivity: \(A\) is wide, and Remark 3.24 rules it out.
    🔗

    7. ★ The Same Vector in Two Coordinate Systems.

    Let \(\mathcal{B}_1 = \{\vec{e}_1, \vec{e}_2\}\) be the standard basis of \(\R^2\) and let \(\mathcal{B}_2 = \{\vec{b}_1, \vec{b}_2\}\) satisfy
    \begin{equation*} \vec{e}_1 = \tfrac{1}{3}\vec{b}_1, \qquad \vec{e}_2 = \tfrac{1}{3}\vec{b}_1 + \vec{b}_2. \end{equation*}
    If \([\vec{x}]_{\mathcal{B}_1} = \begin{bmatrix} 2 \\ 1 \end{bmatrix}\text{,}\) find \([\vec{x}]_{\mathcal{B}_2}\text{,}\) and find \(\vec{b}_1\) and \(\vec{b}_2\) explicitly.
    🔗
    Solution.
    The coordinates say \(\vec{x} = 2\vec{e}_1 + \vec{e}_2\text{.}\) Substituting the two relations,
    \begin{align*} \vec{x} \amp = 2\left( \tfrac{1}{3}\vec{b}_1 \right) + \left( \tfrac{1}{3}\vec{b}_1 + \vec{b}_2 \right)\\ \amp = \vec{b}_1 + \vec{b}_2, \end{align*}
    so \([\vec{x}]_{\mathcal{B}_2} = \begin{bmatrix} 1 \\ 1 \end{bmatrix}\text{.}\)
    🔗
    Solving the two relations for the new basis vectors,
    \begin{equation*} \vec{b}_1 = 3\vec{e}_1 = \begin{bmatrix} 3 \\ 0 \end{bmatrix}, \qquad \vec{b}_2 = \vec{e}_2 - \vec{e}_1 = \begin{bmatrix} -1 \\ 1 \end{bmatrix}. \end{equation*}
    Checking: \(\vec{b}_1 + \vec{b}_2 = (3,0) + (-1,1) = (2,1)\text{,}\) which is \(2\vec{e}_1 + \vec{e}_2\text{.}\) \(\checkmark\)
    🔗
    The vector has not moved. Only the grid against which we measure it has changed, from squares to parallelograms — compare Figure 7.20.

    8. ★ A Vector in Cartesian and Polar Coordinates.

    Let \(\vec{v} = \begin{bmatrix} \sqrt{3} \\ 1 \end{bmatrix} \in \R^2\text{.}\) Describe \(\vec{v}\) in Cartesian and in polar coordinates, and decide which description is a coordinate vector in the sense of Definition 7.18.
    🔗
    Solution.
    Cartesian. Relative to the standard basis \(\mathcal{E} = \{\vec{e}_1, \vec{e}_2\}\text{,}\)
    \begin{equation*} \vec{v} = \sqrt{3}\,\vec{e}_1 + 1\,\vec{e}_2, \qquad [\vec{v}]_{\mathcal{E}} = \begin{bmatrix} \sqrt{3} \\ 1 \end{bmatrix}. \end{equation*}
    These are coordinates relative to a basis.
    🔗
    Polar. The length and angle are
    \begin{equation*} r = \sqrt{3 + 1} = 2, \qquad \tan\theta = \frac{1}{\sqrt{3}} \implies \theta = \frac{\pi}{6}, \end{equation*}
    so that \(\vec{v} = \begin{bmatrix} 2\cos\frac{\pi}{6} \\ 2\sin\frac{\pi}{6} \end{bmatrix}\text{.}\)
    🔗
    Is \(\left( 2, \frac{\pi}{6} \right)\) a coordinate vector? No. Coordinate maps are linear, and \(\vec{v} \mapsto (r,\theta)\) is not. Doubling the vector gives \(2\vec{v} = (2\sqrt{3}, 2)\text{,}\) whose polar data is \(\left( 4, \frac{\pi}{6} \right)\) — but doubling the pair would give \(\left( 4, \frac{\pi}{3} \right)\text{.}\) The length doubles; the angle does not.
    🔗
    🔗
    🔗

    9. ★ The Same Matrix in Two Coordinate Systems.

    In \(\mathbb{M}_{22}\text{,}\) let \(M = \begin{bmatrix} 2 \amp -1 \\ 3 \amp 5 \end{bmatrix}\text{,}\) let \(\mathcal{B}_1 = \{M_{11}, M_{12}, M_{21}, M_{22}\}\) be the standard ordered basis, and let
    \begin{equation*} \mathcal{B}_2 = \left\{ \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}, \begin{bmatrix} 1 \amp 1 \\ 0 \amp 0 \end{bmatrix}, \begin{bmatrix} 0 \amp 0 \\ 1 \amp 1 \end{bmatrix}, \begin{bmatrix} 0 \amp 0 \\ 0 \amp 1 \end{bmatrix} \right\}. \end{equation*}
    Find \([M]_{\mathcal{B}_1}\) and \([M]_{\mathcal{B}_2}\text{.}\)
    🔗
    Solution.
    Relative to \(\mathcal{B}_1\text{.}\) The entries of \(M\text{,}\) read in order, are its coordinates:
    \begin{equation*} M = 2M_{11} - M_{12} + 3M_{21} + 5M_{22}, \qquad [M]_{\mathcal{B}_1} = \begin{bmatrix} 2 \\ -1 \\ 3 \\ 5 \end{bmatrix}. \end{equation*}
    🔗
    Relative to \(\mathcal{B}_2\text{.}\) Look for \(a, b, c, d\) with
    \begin{equation*} M = a\begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix} + b\begin{bmatrix} 1 \amp 1 \\ 0 \amp 0 \end{bmatrix} + c\begin{bmatrix} 0 \amp 0 \\ 1 \amp 1 \end{bmatrix} + d\begin{bmatrix} 0 \amp 0 \\ 0 \amp 1 \end{bmatrix}. \end{equation*}
    Comparing entries one at a time: the \((1,2)\)-entry gives \(b = -1\text{;}\) the \((1,1)\)-entry gives \(a + b = 2\text{,}\) so \(a = 3\text{;}\) the \((2,1)\)-entry gives \(c = 3\text{;}\) and the \((2,2)\)-entry gives \(c + d = 5\text{,}\) so \(d = 2\text{.}\) Hence
    \begin{equation*} [M]_{\mathcal{B}_2} = \begin{bmatrix} 3 \\ -1 \\ 3 \\ 2 \end{bmatrix}. \end{equation*}
    🔗
    The matrix \(M\) is one object; the two columns of numbers are two different descriptions of it.

    10. ★ Computing a Change of Basis Matrix.

    Continuing Exercise 10.7.7, find \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\) and verify it on \(\vec{x}\text{.}\)
    🔗
    Solution.
    The columns of \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\) are the \(\mathcal{B}_2\)-coordinates of the \(\mathcal{B}_1\) basis vectors. From the given relations,
    \begin{equation*} \vec{e}_1 = \tfrac{1}{3}\vec{b}_1 + 0\vec{b}_2 \implies [\vec{e}_1]_{\mathcal{B}_2} = \begin{bmatrix} \frac{1}{3} \\ 0 \end{bmatrix}, \end{equation*}
    \begin{equation*} \vec{e}_2 = \tfrac{1}{3}\vec{b}_1 + 1\vec{b}_2 \implies [\vec{e}_2]_{\mathcal{B}_2} = \begin{bmatrix} \frac{1}{3} \\ 1 \end{bmatrix}. \end{equation*}
    Therefore
    \begin{equation*} P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} = \begin{bmatrix} \frac{1}{3} \amp \frac{1}{3} \\[2pt] 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    Verifying on \(\vec{x}\text{,}\) whose \(\mathcal{B}_1\)-coordinates are \((2,1)\text{:}\)
    \begin{equation*} \begin{bmatrix} \frac{1}{3} \amp \frac{1}{3} \\[2pt] 0 \amp 1 \end{bmatrix} \begin{bmatrix} 2 \\ 1 \end{bmatrix} = \begin{bmatrix} \frac{2}{3} + \frac{1}{3} \\ 1 \end{bmatrix} = \begin{bmatrix} 1 \\ 1 \end{bmatrix} = [\vec{x}]_{\mathcal{B}_2}. \checkmark \end{equation*}

    11. ★ A Change of Basis Matrix in \(\mathbb{M}_{22}\).

    Continuing Exercise 10.7.9, find \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\) for those two bases of \(\mathbb{M}_{22}\text{,}\) and verify it on \(M\text{.}\)
    🔗
    Solution.
    Each column of \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\) holds the \(\mathcal{B}_2\)-coordinates of one standard basis matrix. Solving as before, entry by entry:
    \begin{equation*} [M_{11}]_{\mathcal{B}_2} = \begin{bmatrix} 1 \\ 0 \\ 0 \\ 0 \end{bmatrix}, \quad [M_{12}]_{\mathcal{B}_2} = \begin{bmatrix} -1 \\ 1 \\ 0 \\ 0 \end{bmatrix}, \end{equation*}
    \begin{equation*} [M_{21}]_{\mathcal{B}_2} = \begin{bmatrix} 0 \\ 0 \\ 1 \\ -1 \end{bmatrix}, \quad [M_{22}]_{\mathcal{B}_2} = \begin{bmatrix} 0 \\ 0 \\ 0 \\ 1 \end{bmatrix}. \end{equation*}
    🔗
    Assembling these as columns,
    \begin{equation*} P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} = \begin{bmatrix} 1 \amp -1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp -1 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    Verifying on \(M\text{,}\) whose \(\mathcal{B}_1\)-coordinates are \((2,-1,3,5)\text{:}\)
    \begin{equation*} P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} \begin{bmatrix} 2 \\ -1 \\ 3 \\ 5 \end{bmatrix} = \begin{bmatrix} 2 + 1 \\ -1 \\ 3 \\ -3 + 5 \end{bmatrix} = \begin{bmatrix} 3 \\ -1 \\ 3 \\ 2 \end{bmatrix} = [M]_{\mathcal{B}_2}. \checkmark \end{equation*}

    12. ★ A Change of Basis in \(\mathbb{P}_2\).

    Let \(\mathcal{B}_1 = \{1, x, x^2\}\) and \(\mathcal{B}_2 = \{1, \; 1 + x, \; 1 + x + x^2\}\) be ordered bases of \(\mathbb{P}_2\text{.}\) Find \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\) and use it to find \([p]_{\mathcal{B}_2}\) for \(p(x) = 2 + 3x - x^2\text{.}\)
    🔗
    Solution.
    Write each element of \(\mathcal{B}_1\) in terms of \(\mathcal{B}_2\text{:}\)
    \begin{align*} 1 \amp = 1 \cdot (1),\\ x \amp = -(1) + (1 + x),\\ x^2 \amp = -(1 + x) + (1 + x + x^2). \end{align*}
    So the coordinate columns are \((1,0,0)\text{,}\) \((-1,1,0)\text{,}\) \((0,-1,1)\text{,}\) and
    \begin{equation*} P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    For \(p(x) = 2 + 3x - x^2\) we have \([p]_{\mathcal{B}_1} = (2, 3, -1)\text{,}\) so
    \begin{equation*} [p]_{\mathcal{B}_2} = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix} \begin{bmatrix} 2 \\ 3 \\ -1 \end{bmatrix} = \begin{bmatrix} -1 \\ 4 \\ -1 \end{bmatrix}. \end{equation*}
    🔗
    Checking directly,
    \begin{equation*} -(1) + 4(1 + x) - (1 + x + x^2) = 2 + 3x - x^2. \checkmark \end{equation*}

    13. ★ The Same Transformation in Different Bases.

    Let \(T : \R^2 \to \R^2\) be given by \(T \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} 3x - 2y \\ x \end{bmatrix}\text{,}\) and let \(\mathcal{B} = \{\vec{e}_1, \vec{e}_2\}\) and \(\mathcal{B}' = \left\{ \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \begin{bmatrix} 2 \\ 1 \end{bmatrix} \right\}\text{.}\) Find the matrix of \(T\) using
    1. \(\mathcal{B}\) for both domain and codomain;
      🔗
      🔗
    2. \(\mathcal{B}'\) for both;
      🔗
      🔗
    3. \(\mathcal{B}\) for the domain and \(\mathcal{B}'\) for the codomain;
      🔗
      🔗
    4. \(\mathcal{B}'\) for the domain and \(\mathcal{B}\) for the codomain.
      🔗
      🔗
    🔗
    Solution.
    Throughout, a column of the matrix is the coordinate vector of the image of a domain basis vector, measured in the codomain basis.
    🔗
    (I) \(T(\vec{e}_1) = (3,1)\) and \(T(\vec{e}_2) = (-2,0)\text{,}\) and standard coordinates are the entries themselves, so
    \begin{equation*} A_1 = \begin{bmatrix} 3 \amp -2 \\ 1 \amp 0 \end{bmatrix}. \end{equation*}
    🔗
    (II) Compute the images of the \(\mathcal{B}'\) vectors:
    \begin{equation*} T \begin{bmatrix} 1 \\ 1 \end{bmatrix} = \begin{bmatrix} 1 \\ 1 \end{bmatrix}, \qquad T \begin{bmatrix} 2 \\ 1 \end{bmatrix} = \begin{bmatrix} 4 \\ 2 \end{bmatrix} = 2 \begin{bmatrix} 2 \\ 1 \end{bmatrix}. \end{equation*}
    Each basis vector is sent to a multiple of itself, so their coordinate columns are \((1,0)\) and \((0,2)\text{:}\)
    \begin{equation*} A_2 = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 2 \end{bmatrix}. \end{equation*}
    The basis \(\mathcal{B}'\) consists of eigenvectors, which is why the matrix comes out diagonal.
    🔗
    (III) Now express \(T(\vec{e}_1) = (3,1)\) and \(T(\vec{e}_2) = (-2,0)\) in \(\mathcal{B}'\text{.}\) Solving \(a(1,1) + b(2,1) = (3,1)\) gives \(a + b = 1\) and \(a + 2b = 3\text{,}\) so \(b = 2\text{,}\) \(a = -1\text{.}\) Solving \(a(1,1) + b(2,1) = (-2,0)\) gives \(b = -2\text{,}\) \(a = 2\text{.}\) Hence
    \begin{equation*} A_3 = \begin{bmatrix} -1 \amp 2 \\ 2 \amp -2 \end{bmatrix}. \end{equation*}
    🔗
    (IV) The images of the \(\mathcal{B}'\) vectors were computed in (II); now record them in standard coordinates:
    \begin{equation*} A_4 = \begin{bmatrix} 1 \amp 4 \\ 1 \amp 2 \end{bmatrix}. \end{equation*}
    🔗
    One transformation, four matrices. Only the pair of bases changed.
    🔗

    14. ★ The Same Game in \(\mathbb{P}_2\).

    Let \(T : \mathbb{P}_2 \to \mathbb{P}_2\) be \(T(p(x)) = p(x) - p'(x)\text{,}\) with ordered bases \(\mathcal{B}_1 = \{1, x, x^2\}\) and \(\mathcal{B}_2 = \{1, \; 1+x, \; 1+x+x^2\}\text{.}\) Find the matrix of \(T\) using (I) \(\mathcal{B}_1\) for both, (II) \(\mathcal{B}_2\) for both, (III) \(\mathcal{B}_1\) then \(\mathcal{B}_2\text{,}\) and (IV) \(\mathcal{B}_2\) then \(\mathcal{B}_1\text{.}\)
    🔗
    Solution.
    First compute the images of both bases:
    \begin{align*} T(1) \amp = 1, \qquad T(x) = x - 1, \qquad T(x^2) = x^2 - 2x,\\ T(1+x) \amp = x, \qquad T(1 + x + x^2) = x^2 - x. \end{align*}
    🔗
    (I) In \(\mathcal{B}_1\)-coordinates the images are \((1,0,0)\text{,}\) \((-1,1,0)\text{,}\) \((0,-2,1)\text{,}\) so
    \begin{equation*} A_1 = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    (II) Write each image of a \(\mathcal{B}_2\) vector in \(\mathcal{B}_2\text{:}\) \(T(1) = 1\) gives \((1,0,0)\text{;}\) \(T(1+x) = x = -(1) + (1+x)\) gives \((-1,1,0)\text{;}\) and \(T(1+x+x^2) = x^2 - x = (1) - 2(1+x) + (1+x+x^2)\) gives \((1,-2,1)\text{.}\) Hence
    \begin{equation*} A_2 = \begin{bmatrix} 1 \amp -1 \amp 1 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    (III) Take the \(\mathcal{B}_1\) images and record them in \(\mathcal{B}_2\text{.}\) Using \(x - 1 = -2(1) + (1+x)\) and \(x^2 - 2x = 2(1) - 3(1+x) + (1+x+x^2)\text{,}\)
    \begin{equation*} A_3 = \begin{bmatrix} 1 \amp -2 \amp 2 \\ 0 \amp 1 \amp -3 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    (IV) Take the \(\mathcal{B}_2\) images and record them in \(\mathcal{B}_1\text{:}\) \(1 \to (1,0,0)\text{,}\) \(x \to (0,1,0)\text{,}\) \(x^2 - x \to (0,-1,1)\text{,}\) so
    \begin{equation*} A_4 = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    All four are upper triangular with \(1\)s on the diagonal, because \(T\) lowers degree by differentiating and then subtracts: the leading term is never disturbed.
    🔗
    🔗

    15. ★ From \(\mathbb{P}_2\) to \(\mathbb{M}_{22}\).

    Define \(S : \mathbb{P}_2 \to \mathbb{M}_{22}\) by
    \begin{equation*} S \left( a_2 x^2 + a_1 x + a_0 \right) = \begin{bmatrix} a_0 + a_1 \amp a_0 - a_2 \\ a_1 + a_2 \amp a_0 \end{bmatrix}. \end{equation*}
    1. Describe the null space of \(S\text{.}\) Is \(S\) one-to-one?
      🔗
      🔗
    2. Express the range of \(S\) as a span. Is \(S\) onto?
      🔗
      🔗
    3. Is \(S\) an isomorphism?
      🔗
      🔗
    4. Find the matrix of \(S\) relative to \(\mathcal{B} = \{1, x, x^2\}\) and the standard basis of \(\mathbb{M}_{22}\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    (1) \(S(p) = 0_{2 \times 2}\) requires all four entries to vanish. The \((2,2)\)-entry gives \(a_0 = 0\text{;}\) then the \((1,1)\)-entry gives \(a_1 = 0\text{;}\) then the \((2,1)\)-entry gives \(a_2 = 0\text{.}\) So the null space is \(\{0\}\) and \(S\) is one-to-one.
    🔗
    (2) The range is spanned by the images of a basis:
    \begin{equation*} S(1) = \begin{bmatrix} 1 \amp 1 \\ 0 \amp 1 \end{bmatrix}, \quad S(x) = \begin{bmatrix} 1 \amp 0 \\ 1 \amp 0 \end{bmatrix}, \quad S(x^2) = \begin{bmatrix} 0 \amp -1 \\ 1 \amp 0 \end{bmatrix}. \end{equation*}
    These three are linearly independent, since \(S\) is one-to-one, so
    \begin{equation*} \operatorname{range}(S) = \operatorname{Span}\left\{ S(1), S(x), S(x^2) \right\}, \end{equation*}
    a three-dimensional subspace of the four-dimensional \(\mathbb{M}_{22}\text{.}\) Hence \(S\) is not onto.
    🔗
    (3) No. An isomorphism must be both one-to-one and onto, and \(S\) fails the second. Dimensions already rule it out: \(\dim \mathbb{P}_2 = 3 \neq 4 = \dim \mathbb{M}_{22}\text{.}\)
    🔗
    (4) Reading each image in the order \((M_{11}, M_{12}, M_{21}, M_{22})\) gives the columns \((1,1,0,1)\text{,}\) \((1,0,1,0)\text{,}\) \((0,-1,1,0)\text{,}\) so
    \begin{equation*} A = \begin{bmatrix} 1 \amp 1 \amp 0 \\ 1 \amp 0 \amp -1 \\ 0 \amp 1 \amp 1 \\ 1 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    The matrix is \(4 \times 3\text{:}\) tall, and by Remark 3.33 therefore never onto, confirming (2).
    🔗
    🔗

    16. ★ Another Transformation \(\mathbb{M}_{22} \to \R\).

    Define \(S : \mathbb{M}_{22} \to \R\) by \(S(A) = a_{12} + a_{21}\text{.}\) Show that \(S\) is linear, find its matrix relative to the standard bases, and describe its null space and range.
    🔗
    Solution.
    Linearity. For \(A, B \in \mathbb{M}_{22}\) and \(c \in \R\text{,}\) the entries of \(A + B\) and \(cA\) are computed entry by entry, so
    \begin{align*} S(A + B) \amp = (a_{12} + b_{12}) + (a_{21} + b_{21})\\ \amp = S(A) + S(B), \end{align*}
    and \(S(cA) = ca_{12} + ca_{21} = cS(A)\text{.}\)
    🔗
    The matrix. Evaluating on the standard basis,
    \begin{equation*} S(M_{11}) = 0, \quad S(M_{12}) = 1, \quad S(M_{21}) = 1, \quad S(M_{22}) = 0, \end{equation*}
    so the matrix is the \(1 \times 4\) row
    \begin{equation*} A = \begin{bmatrix} 0 \amp 1 \amp 1 \amp 0 \end{bmatrix}. \end{equation*}
    🔗
    Range. \(A\) has one pivot, in a single row, so \(S\) is onto: \(\operatorname{range}(S) = \R\text{.}\) Indeed \(S\left( \begin{bmatrix} 0 \amp t \\ 0 \amp 0 \end{bmatrix} \right) = t\) for any \(t\text{.}\)
    🔗
    Null space. The condition is \(a_{12} + a_{21} = 0\text{,}\) one equation on four unknowns, so
    \begin{equation*} \operatorname{Nul}(S) = \left\{ \begin{bmatrix} p \amp q \\ -q \amp r \end{bmatrix} \; \middle| \; p, q, r \in \R \right\}, \end{equation*}
    which has dimension \(3\text{.}\) Consistently with Theorem 5.26, \(1 + 3 = 4 = \dim \mathbb{M}_{22}\text{.}\)
    🔗
    🔗

    17. ★ Reading a Matrix off a Change of Basis.

    Let \(T : \mathbb{P}_2 \to \mathbb{P}_2\) be \(T(p(x)) = p(x) - p'(x)\) as in Exercise 10.7.14. Verify that
    \begin{equation*} A_3 = P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} \, A_1, \end{equation*}
    where \(A_1\) and \(A_3\) are the matrices found there and \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\) is the change of basis matrix of Exercise 10.7.12.
    🔗
    Solution.
    The three matrices are
    \begin{equation*} A_1 = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \end{bmatrix}, \quad P = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
    🔗
    Multiplying,
    \begin{equation*} PA_1 = \begin{bmatrix} 1 \amp -2 \amp 2 \\ 0 \amp 1 \amp -3 \\ 0 \amp 0 \amp 1 \end{bmatrix} = A_3. \checkmark \end{equation*}
    🔗
    This is exactly what one should expect. Applying \(A_1\) takes \(\mathcal{B}_1\)-coordinates of \(p\) to \(\mathcal{B}_1\)-coordinates of \(T(p)\text{;}\) applying \(P\) then re-expresses that answer in \(\mathcal{B}_2\text{.}\) Doing the transformation and then the change of basis is the same as using \(\mathcal{B}_1\) for the domain and \(\mathcal{B}_2\) for the codomain from the start.
