Example 4.62. An Inverse from a Polynomial Identity.

Suppose \(P\) is a square matrix which satisfies the following:
\begin{equation*} P^3 + 2P^2 + 2P - 3I = 0. \end{equation*}
Find \(P^{-1}\text{,}\) if possible.
🔗
Solution.
Divide the identity by \(3\) and isolate \(I\text{:}\)
\begin{align*} \tfrac{1}{3}\left( P^3 + 2P^2 + 2P - 3I \right) \amp = 0\\ \tfrac{1}{3}\left( P^3 + 2P^2 + 2P \right) - I \amp = 0\\ \tfrac{1}{3}\left( P^3 + 2P^2 + 2P \right) \amp = I. \end{align*}
🔗
Factoring \(P\) out on the left gives
\begin{equation*} P \left[ \tfrac{1}{3} \left( P^2 + 2P + 2I \right) \right] = I, \end{equation*}
so by condition (8) of Theorem 4.57, \(P\) is invertible and
\begin{equation*} P^{-1} = \tfrac{1}{3} \left( P^2 + 2P + 2I \right). \end{equation*}
