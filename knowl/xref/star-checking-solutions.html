Exercise 3. ★ Checking Candidate Solutions.

For the system of Exercise 10.1.2, decide which of the following are solutions:
\begin{align*} \text{(a) } \amp x_1 = 1, \; x_2 = 1, \; x_3 = 0,\\ \text{(b) } \amp x_1 = 3, \; x_2 = 8, \; x_3 = 3,\\ \text{(c) } \amp x_1 = 2, \; x_2 = 0, \; x_3 = 0. \end{align*}
🔗
Solution.
(a) is a solution. Substituting,
\begin{align*} 1 + 1 - 3(0) \amp = 2, \checkmark\\ 2(1) - 1 + 0 \amp = 1. \checkmark \end{align*}
🔗
(b) is also a solution. Substituting,
\begin{align*} 3 + 8 - 3(3) \amp = 11 - 9 = 2, \checkmark\\ 2(3) - 8 + 3 \amp = 6 - 8 + 3 = 1. \checkmark \end{align*}
🔗
(c) is not a solution. It satisfies the first equation, since \(2 + 0 - 0 = 2\text{,}\) but the second gives \(2(2) - 0 + 0 = 4 \neq 1\text{.}\) A solution must satisfy every equation of the system, so passing one test is not enough.
