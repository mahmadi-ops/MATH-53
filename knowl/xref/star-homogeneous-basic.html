Exercise 10. ★ Solving a Homogeneous System.

Solve
\begin{align*} x_1 + 2x_2 - x_3 + x_4 \amp = 0\\ 2x_1 + 5x_2 + x_3 - x_4 \amp = 0\\ x_1 + 3x_2 + 2x_3 - 2x_4 \amp = 0 \end{align*}
🔗
Solution.
\begin{align*} \left[ \begin{array}{cccc|c} 1 \amp 2 \amp -1 \amp 1 \amp 0 \\ 2 \amp 5 \amp 1 \amp -1 \amp 0 \\ 1 \amp 3 \amp 2 \amp -2 \amp 0 \end{array} \right] \amp \xrightarrow[-r_1 + r_3]{-2r_1 + r_2} \left[ \begin{array}{cccc|c} 1 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 3 \amp -3 \amp 0 \\ 0 \amp 1 \amp 3 \amp -3 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-r_2 + r_3} \left[ \begin{array}{cccc|c} 1 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 3 \amp -3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-2r_2 + r_1} \left[ \begin{array}{cccc|c} 1 \amp 0 \amp -7 \amp 7 \amp 0 \\ 0 \amp 1 \amp 3 \amp -3 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{align*}
🔗
Here \(x_3\) and \(x_4\) are free. Setting \(x_3 = s\) and \(x_4 = t\text{,}\) the two nonzero rows give
\begin{align*} x_1 \amp = 7s - 7t\\ x_2 \amp = -3s + 3t\\ x_3 \amp = s\\ x_4 \amp = t, \qquad \text{where } s, t \in \R. \end{align*}
The trivial solution is the case \(s = t = 0\text{;}\) every other choice gives a nontrivial solution.
