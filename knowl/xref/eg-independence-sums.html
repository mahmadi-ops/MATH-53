Example 2.45. Independence of the Pairwise Sums.

Let \(\vec{u}\text{,}\) \(\vec{v}\text{,}\) \(\vec{w}\) be vectors in \(\R^n\text{.}\) Show that
\begin{align*} \{ \vec{u}, \vec{v}, \vec{w} \} \amp \text{ is linearly independent}\\ \Longleftrightarrow \quad \{ \vec{u} + \vec{v}, \; \vec{v} + \vec{w}, \; \vec{w} + \vec{u} \} \amp \text{ is linearly independent}. \end{align*}
🔗
Solution.
Both directions rest on one computation. For scalars \(a, b, c\text{,}\) regrouping gives
\begin{align*} a(\vec{u} + \vec{v}) + b(\vec{v} + \vec{w}) + c(\vec{w} + \vec{u})\\ \amp = (a + c)\vec{u} + (a + b)\vec{v} + (b + c)\vec{w}. \end{align*}
🔗
(\(\Rightarrow\)) Suppose \(\{\vec{u}, \vec{v}, \vec{w}\}\) is linearly independent, and suppose the left-hand side above is \(\vec{0}\text{.}\) Then all three coefficients on the right must vanish:
\begin{equation*} a + c = 0, \qquad a + b = 0, \qquad b + c = 0. \end{equation*}
The first two give \(c = -a\) and \(b = -a\text{;}\) substituting into the third gives \(-2a = 0\text{,}\) so \(a = 0\) and then \(b = c = 0\text{.}\) Only the trivial combination gives \(\vec{0}\text{,}\) so the pairwise sums are linearly independent by Theorem 2.37.
🔗
(\(\Leftarrow\)) We prove the contrapositive. Suppose \(\{\vec{u}, \vec{v}, \vec{w}\}\) is linearly dependent, so there are scalars \(x, y, z\text{,}\) not all zero, with \(x\vec{u} + y\vec{v} + z\vec{w} = \vec{0}\text{.}\) We want \(a, b, c\text{,}\) not all zero, with \(a + c = x\text{,}\) \(a + b = y\text{,}\) \(b + c = z\text{.}\) That is the system
\begin{equation*} \begin{bmatrix} 1 \amp 0 \amp 1 \\ 1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 1 \end{bmatrix} \begin{bmatrix} a \\ b \\ c \end{bmatrix} = \begin{bmatrix} x \\ y \\ z \end{bmatrix}, \end{equation*}
and the coefficient matrix has determinant \(1(1) - 0 + 1(1) = 2 \neq 0\text{.}\) By Theorem 4.57 it is invertible, so the system has a unique solution \((a,b,c)\text{;}\) and since \((x,y,z) \neq \vec{0}\text{,}\) that solution is not \(\vec{0}\) either.
🔗
For this choice of \(a, b, c\) the displayed identity gives
\begin{equation*} a(\vec{u} + \vec{v}) + b(\vec{v} + \vec{w}) + c(\vec{w} + \vec{u}) = x\vec{u} + y\vec{v} + z\vec{w} = \vec{0}, \end{equation*}
a nontrivial dependence among the pairwise sums. So dependence of \(\{\vec{u}, \vec{v}, \vec{w}\}\) forces dependence of the sums, which is the contrapositive of the direction we wanted.
🔗
A warning. The \(2\) in that determinant is doing real work. The same argument with four vectors and the cyclic sums \(\vec{u}_1 + \vec{u}_2, \; \vec{u}_2 + \vec{u}_3, \; \vec{u}_3 + \vec{u}_4, \; \vec{u}_4 + \vec{u}_1\) fails: those four sums always satisfy
\begin{equation*} (\vec{u}_1 + \vec{u}_2) - (\vec{u}_2 + \vec{u}_3) + (\vec{u}_3 + \vec{u}_4) - (\vec{u}_4 + \vec{u}_1) = \vec{0}, \end{equation*}
so they are dependent no matter how independent the \(\vec{u}_i\) are.
