Definition 7.1. Vector Space.

A vector space \(V\) is a set of vectors with two operations defined, addition and scalar multiplication, which satisfy the following axioms for all \(\vec{u}\text{,}\) \(\vec{v}\text{,}\) and \(\vec{w} \in V\) and for all \(a, b \in \R\text{.}\)
🔗
  1. \(\vec{u} + \vec{v} \in V\text{.}\)
    🔗
    🔗
  2. \(\vec{u} + \vec{v} = \vec{v} + \vec{u}\text{.}\)
    🔗
    🔗
  3. There exists \(\vec{0} \in V\) such that \(\vec{0} + \vec{u} = \vec{u}\text{.}\)
    🔗
    🔗
  4. There exists \(-\vec{u} \in V\) such that \(\vec{u} + (-\vec{u}) = \vec{0}\text{.}\)
    🔗
    🔗
  5. \((\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})\text{.}\)
    🔗
    🔗
  6. \(a\vec{u} \in V\text{.}\)
    🔗
    🔗
  7. \(a(\vec{u} + \vec{v}) = a\vec{u} + a\vec{v}\text{.}\)
    🔗
    🔗
  8. \((a + b)\vec{u} = a\vec{u} + b\vec{u}\text{.}\)
    🔗
    🔗
  9. \(a(b\vec{u}) = (ab)\vec{u}\text{.}\)
    🔗
    🔗
  10. \(1\vec{u} = \vec{u}\text{.}\)
    🔗
