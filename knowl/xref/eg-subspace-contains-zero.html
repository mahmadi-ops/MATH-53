Example 5.5. True or False?

Any subspace \(H\) of \(\R^n\) contains the zero vector.
🔗
Solution.
This is true. Note that since a subspace is nonempty, it has at least one element \(\vec{u}\text{.}\) But then \(0\vec{u} = \vec{0}\) is in \(H\) since \(H\) is closed under scalar multiplication.
