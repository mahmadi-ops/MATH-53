Exercise 2. A Second \(3 \times 3\) Matrix.

Find the eigenvalues and eigenvectors of \(A = \begin{bmatrix} 3 \amp -2 \amp -1 \\ 0 \amp 5 \amp 1 \\ 0 \amp 2 \amp 4 \end{bmatrix}\text{.}\)
🔗
Solution.
Expanding down the first column, which has a single nonzero entry,
\begin{align*} \det(A - \lambda I) \amp = (3-\lambda)\begin{vmatrix} 5-\lambda \amp 1 \\ 2 \amp 4-\lambda \end{vmatrix}\\ \amp = (3-\lambda)\bigl[(5-\lambda)(4-\lambda) - 2\bigr]\\ \amp = (3-\lambda)(\lambda^2 - 9\lambda + 18)\\ \amp = (3-\lambda)(\lambda - 3)(\lambda - 6). \end{align*}
The eigenvalues are \(\lambda = 3\text{,}\) of multiplicity \(2\text{,}\) and \(\lambda = 6\text{.}\)
🔗
\(\lambda = 3\text{.}\)
\begin{equation*} A - 3I = \begin{bmatrix} 0 \amp -2 \amp -1 \\ 0 \amp 2 \amp 1 \\ 0 \amp 2 \amp 1 \end{bmatrix} \longrightarrow \begin{bmatrix} 0 \amp 2 \amp 1 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
The one equation is \(2x_2 + x_3 = 0\text{,}\) so \(x_1\) and \(x_2\) are free:
\begin{equation*} \vec{v}_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}, \qquad \vec{v}_2 = \begin{bmatrix} 0 \\ 1 \\ -2 \end{bmatrix}. \end{equation*}
🔗
\(\lambda = 6\text{.}\)
\begin{equation*} A - 6I = \begin{bmatrix} -3 \amp -2 \amp -1 \\ 0 \amp -1 \amp 1 \\ 0 \amp 2 \amp -2 \end{bmatrix}. \end{equation*}
Row \(2\) gives \(x_3 = x_2\text{,}\) and row \(1\) then gives \(-3x_1 - 3x_2 = 0\text{,}\) so \(x_1 = -x_2\text{:}\) \(\vec{v}_3 = \begin{bmatrix} -1 \\ 1 \\ 1 \end{bmatrix}\text{.}\)
🔗
Checking the last one, \(A\vec{v}_3 = (-3 - 2 - 1,\ 0 + 5 + 1,\ 0 + 2 + 4) = (-6, 6, 6) = 6\vec{v}_3\text{.}\) \(\checkmark\)
