Exercise 14. ★ The Same Game in \(\mathbb{P}_2\).

Let \(T : \mathbb{P}_2 \to \mathbb{P}_2\) be \(T(p(x)) = p(x) - p'(x)\text{,}\) with ordered bases \(\mathcal{B}_1 = \{1, x, x^2\}\) and \(\mathcal{B}_2 = \{1, \; 1+x, \; 1+x+x^2\}\text{.}\) Find the matrix of \(T\) using (I) \(\mathcal{B}_1\) for both, (II) \(\mathcal{B}_2\) for both, (III) \(\mathcal{B}_1\) then \(\mathcal{B}_2\text{,}\) and (IV) \(\mathcal{B}_2\) then \(\mathcal{B}_1\text{.}\)
🔗
Solution.
First compute the images of both bases:
\begin{align*} T(1) \amp = 1, \qquad T(x) = x - 1, \qquad T(x^2) = x^2 - 2x,\\ T(1+x) \amp = x, \qquad T(1 + x + x^2) = x^2 - x. \end{align*}
🔗
(I) In \(\mathcal{B}_1\)-coordinates the images are \((1,0,0)\text{,}\) \((-1,1,0)\text{,}\) \((0,-2,1)\text{,}\) so
\begin{equation*} A_1 = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
(II) Write each image of a \(\mathcal{B}_2\) vector in \(\mathcal{B}_2\text{:}\) \(T(1) = 1\) gives \((1,0,0)\text{;}\) \(T(1+x) = x = -(1) + (1+x)\) gives \((-1,1,0)\text{;}\) and \(T(1+x+x^2) = x^2 - x = (1) - 2(1+x) + (1+x+x^2)\) gives \((1,-2,1)\text{.}\) Hence
\begin{equation*} A_2 = \begin{bmatrix} 1 \amp -1 \amp 1 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
(III) Take the \(\mathcal{B}_1\) images and record them in \(\mathcal{B}_2\text{.}\) Using \(x - 1 = -2(1) + (1+x)\) and \(x^2 - 2x = 2(1) - 3(1+x) + (1+x+x^2)\text{,}\)
\begin{equation*} A_3 = \begin{bmatrix} 1 \amp -2 \amp 2 \\ 0 \amp 1 \amp -3 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
(IV) Take the \(\mathcal{B}_2\) images and record them in \(\mathcal{B}_1\text{:}\) \(1 \to (1,0,0)\text{,}\) \(x \to (0,1,0)\text{,}\) \(x^2 - x \to (0,-1,1)\text{,}\) so
\begin{equation*} A_4 = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
All four are upper triangular with \(1\)s on the diagonal, because \(T\) lowers degree by differentiating and then subtracts: the leading term is never disturbed.
