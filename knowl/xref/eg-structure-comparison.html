Example 2.25 Comparing a Homogeneous System with Its Non-Homogeneous Partner.

Solve the following systems and explain the relation between their solution sets.
🔗
\begin{align*} x + y + z \amp = 0\\ x + y - z \amp = 0\\ x + y \phantom{{}- z} \amp = 0 \end{align*}
\begin{align*} x + y + z \amp = -1\\ x + y - z \amp = 1\\ x + y \phantom{{}- z} \amp = 0 \end{align*}
🔗
Solution.
The homogeneous system.
\begin{equation*} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 1 \amp 0 \\ 1 \amp 1 \amp -1 \amp 0 \\ 1 \amp 1 \amp 0 \amp 0 \end{array} \right] \longrightarrow \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 1 \amp 0 \\ 0 \amp 0 \amp -2 \amp 0 \\ 0 \amp 0 \amp -1 \amp 0 \end{array} \right] \longrightarrow \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{equation*}
So \(z = 0\) and \(x = -y\text{.}\) With \(y = s\text{,}\)
\begin{equation*} x = -s, \quad y = s, \quad z = 0, \qquad \text{i.e.} \qquad \vec{v}_h = s \begin{bmatrix} -1 \\ 1 \\ 0 \end{bmatrix} = s\vec{v}_1, \quad s \in \R, \end{equation*}
where \(\vec{v}_1 = \begin{bmatrix} -1 \\ 1 \\ 0 \end{bmatrix}\) is the basic solution.
🔗
The non-homogeneous system.
\begin{equation*} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 1 \amp -1 \\ 1 \amp 1 \amp -1 \amp 1 \\ 1 \amp 1 \amp 0 \amp 0 \end{array} \right] \longrightarrow \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 1 \amp -1 \\ 0 \amp 0 \amp -2 \amp 2 \\ 0 \amp 0 \amp -1 \amp 1 \end{array} \right] \longrightarrow \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{equation*}
So \(z = -1\) and \(x = -y\text{.}\) With \(y = s\text{,}\)
\begin{equation*} \vec{w} = s \begin{bmatrix} -1 \\ 1 \\ 0 \end{bmatrix} + \begin{bmatrix} 0 \\ 0 \\ -1 \end{bmatrix} = s\vec{v}_1 + \vec{p}. \end{equation*}
🔗
Note that \(\vec{p} = \begin{bmatrix} 0 \\ 0 \\ -1 \end{bmatrix}\) is a solution of the non-homogeneous system, whereas \(s\vec{v}_1 = \vec{v}_h\) is the solution of the homogeneous system.
🔗
Geometrically, \(\vec{p}\) is a vector in \(\R^3\text{,}\) whereas \(s\vec{v}_1\) corresponds to a line in \(\R^3\text{.}\) The solution set of the non-homogeneous system is that line translated by \(\vec{p}\text{.}\)
🔗
Figure 2.27 draws this picture for the two systems of this example, in \(\R^3\text{.}\) Two operations relate the two solution sets. Scaling the basic solution \(\vec{v}_1\) by \(s\) gives the homogeneous solution \(\vec{v}_h = s\vec{v}_1\) and moves along the gray line through the origin. Adding \(\vec{p}\) then carries the point \(s\vec{v}_1\) to \(\vec{w} = \vec{p} + s\vec{v}_1\) on the olive line.
