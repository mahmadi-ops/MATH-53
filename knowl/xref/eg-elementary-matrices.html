Example 4.51. Three Elementary Matrices.

Each of the following is obtained from \(I_4\) by a single elementary row operation:
\begin{equation*} E = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \end{bmatrix}, \quad F = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp -2 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}, \quad G = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ -3 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
Specifically,
\begin{align*} I_4 \amp \xrightarrow{\;R_2 \leftrightarrow R_4\;} E,\\ I_4 \amp \xrightarrow{\;-2R_3\;} F,\\ I_4 \amp \xrightarrow{\;-3R_1 + R_3\;} G. \end{align*}
