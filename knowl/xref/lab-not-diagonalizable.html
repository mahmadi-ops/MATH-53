Exercise 17. A Matrix That Is Not Diagonalizable.

Let \(A = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 3 \amp -2 \\ 0 \amp 2 \amp -1 \end{bmatrix}\text{.}\)
  1. Find the characteristic polynomial of \(A\text{.}\)
    🔗
    🔗
  2. Find the eigenvalues and their multiplicities.
    🔗
    🔗
  3. Is \(A\) diagonalizable? Give the simplest reason you can.
    🔗
    🔗
🔗
Solution.
(a) Expanding \(\det(\lambda I - A)\) along the first row,
\begin{align*} c_A(\lambda) \amp = (\lambda - 1)\begin{vmatrix} \lambda - 3 \amp 2 \\ -2 \amp \lambda + 1 \end{vmatrix}\\ \amp = (\lambda - 1)\bigl[(\lambda-3)(\lambda+1) + 4\bigr]\\ \amp = (\lambda - 1)(\lambda^2 - 2\lambda + 1)\\ \amp = (\lambda - 1)^3. \end{align*}
🔗
(b) The only eigenvalue is \(\lambda = 1\text{,}\) of multiplicity \(3\text{.}\)
🔗
(c) No. Solve \((A - I)\vec{x} = \vec{0}\text{:}\)
\begin{equation*} A - I = \begin{bmatrix} 0 \amp 0 \amp 0 \\ 0 \amp 2 \amp -2 \\ 0 \amp 2 \amp -2 \end{bmatrix} \longrightarrow \begin{bmatrix} 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
There is one equation and three unknowns, so the general solution has \(2\) parameters and the eigenspace is two-dimensional.
🔗
A \(3 \times 3\) matrix is diagonalizable only if it has \(3\) independent eigenvectors, but here we can find only \(2\text{.}\) In the language of Theorem 8.17: the multiplicity of \(\lambda = 1\) is \(3\) while the number of basic eigenvectors for it is \(2\text{,}\) and \(3 \neq 2\text{.}\)
