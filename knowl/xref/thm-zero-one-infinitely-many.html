Theorem 1.12 Zero, One, or Infinitely Many Solutions.

A system of linear equations has either no solution, exactly one solution, or infinitely many solutions.
🔗
🔗

Proof.
We show that a system with two different solutions must have infinitely many. Suppose \((u_1, \ldots, u_n)\) and \((v_1, \ldots, v_n)\) are two different solutions of a system in the variables \(x_1, \ldots, x_n\text{.}\) For any real number \(t\text{,}\) consider the assignment
\begin{equation*} x_1 = u_1 + t(v_1 - u_1), \quad x_2 = u_2 + t(v_2 - u_2), \quad \ldots, \quad x_n = u_n + t(v_n - u_n). \end{equation*}
Take any equation \(a_1 x_1 + \cdots + a_n x_n = b\) of the system. Both given solutions satisfy it, so \(a_1 u_1 + \cdots + a_n u_n = b\) and \(a_1 v_1 + \cdots + a_n v_n = b\text{.}\) Substituting the new assignment,
\begin{align*} \sum_{i=1}^{n} a_i \bigl(u_i + t(v_i - u_i)\bigr) \amp = \sum_{i=1}^{n} a_i u_i + t\Bigl(\sum_{i=1}^{n} a_i v_i - \sum_{i=1}^{n} a_i u_i\Bigr)\\ \amp = b + t(b - b) = b. \end{align*}
So the new assignment satisfies every equation of the system, for every real \(t\text{.}\) Finally, different values of \(t\) give different assignments: the two given solutions differ in some coordinate, say \(u_k \neq v_k\text{,}\) and then \(u_k + t(v_k - u_k)\) takes a different value for each \(t\text{.}\) Hence there are infinitely many solutions.
