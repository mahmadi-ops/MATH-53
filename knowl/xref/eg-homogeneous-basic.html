Example 2.18. Solving a Homogeneous System.

Solve the system
\begin{align*} x_1 + x_2 - x_3 + 3x_4 \amp = 0\\ -x_1 + 4x_2 + 5x_3 - 2x_4 \amp = 0\\ x_1 + 6x_2 + 3x_3 + 4x_4 \amp = 0 \end{align*}
🔗
Solution.
\begin{align*} \left[ \begin{array}{cccc|c} 1 \amp 1 \amp -1 \amp 3 \amp 0 \\ -1 \amp 4 \amp 5 \amp -2 \amp 0 \\ 1 \amp 6 \amp 3 \amp 4 \amp 0 \end{array} \right] \amp \xrightarrow[-r_1 + r_3]{r_1 + r_2} \left[ \begin{array}{cccc|c} 1 \amp 1 \amp -1 \amp 3 \amp 0 \\ 0 \amp 5 \amp 4 \amp 1 \amp 0 \\ 0 \amp 5 \amp 4 \amp 1 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-r_2 + r_3} \left[ \begin{array}{cccc|c} 1 \amp 1 \amp -1 \amp 3 \amp 0 \\ 0 \amp 5 \amp 4 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{array} \right] \xrightarrow{\frac{1}{5} r_2} \left[ \begin{array}{cccc|c} 1 \amp 1 \amp -1 \amp 3 \amp 0 \\ 0 \amp 1 \amp \frac{4}{5} \amp \frac{1}{5} \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-r_2 + r_1} \left[ \begin{array}{cccc|c} 1 \amp 0 \amp -\frac{9}{5} \amp \frac{14}{5} \amp 0 \\ 0 \amp 1 \amp \frac{4}{5} \amp \frac{1}{5} \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{array} \right]. \end{align*}
🔗
Here \(x_3\) and \(x_4\) are free variables. The two nonzero rows read
\begin{align*} x_1 - \tfrac{9}{5}x_3 + \tfrac{14}{5}x_4 \amp = 0\\ x_2 + \tfrac{4}{5}x_3 + \tfrac{1}{5}x_4 \amp = 0 \end{align*}
so setting \(x_3 = s\) and \(x_4 = t\text{,}\)
\begin{align*} x_1 \amp = \tfrac{9}{5}s - \tfrac{14}{5}t\\ x_2 \amp = -\tfrac{4}{5}s - \tfrac{1}{5}t\\ x_3 \amp = s\\ x_4 \amp = t, \qquad \text{where } s, t \in \R. \end{align*}
