Remark 4.14. Question: What is the size of \(AB\text{?}\)

Each column \(B_j\) of \(B\) is an \(n \times 1\) vector, so each product \(AB_j\) is an \(m \times 1\) vector. There are \(p\) such columns, so \(AB\) is an \(m \times p\) matrix.
🔗
In particular, the product \(AB\) is defined only when the number of columns of \(A\) equals the number of rows of \(B\text{:}\)
\begin{equation*} \underset{m \times n}{A} \; \underset{n \times p}{B} = \underset{m \times p}{AB}. \end{equation*}
The two inner dimensions must match, and the outer dimensions give the size of the product.
🔗
