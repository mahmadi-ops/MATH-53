Definition 1.20. Row-Echelon Matrix.

A matrix is a row-echelon matrix (REM) if
  1. All rows consisting entirely of zeros are at the bottom.
    🔗
    🔗
  2. The first nonzero entry in each nonzero row is called a leading entry.
    🔗
    🔗
  3. Each leading entry is to the right of all leading entries in rows above it.
