Example 3.55 Projection into the \(x\)-Axis.

Projection into the \(x\)-axis sends \(\vec{x} = \begin{bmatrix} x \\ y \end{bmatrix}\) to \(T(\vec{x}) = \begin{bmatrix} x \\ 0 \end{bmatrix}\text{,}\) flattening the whole plane onto the \(x\)-axis. Since \(T(\vec{e}_1) = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\) and \(T(\vec{e}_2) = \begin{bmatrix} 0 \\ 0 \end{bmatrix}\text{,}\)
\begin{equation*} A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}. \end{equation*}
🔗
Note the contrast with Example 3.50: a reflection is one-to-one, while this projection is not, since every vector \(\begin{bmatrix} x \\ y \end{bmatrix}\) has the same image regardless of \(y\text{.}\)
