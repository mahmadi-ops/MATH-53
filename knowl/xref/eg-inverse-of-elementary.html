Example 4.54. Inverting an Elementary Matrix by Inspection.

Without using the matrix inversion algorithm, find the inverse of the elementary matrix
\begin{equation*} G = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ -3 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
Hint. What row operation can be applied to \(G\) to transform it to \(I_4\text{?}\)
🔗
Solution.
\(G\) was obtained from \(I_4\) by the row operation \(-3R_1 + R_3\text{.}\) The row operation that undoes it is \(+3R_1 + R_3\text{,}\) so applying that inverse row operation to \(I_4\) gives \(G^{-1}\text{:}\)
\begin{equation*} I_4 \xrightarrow[\text{row operation}]{\;-3R_1 + R_3\;} G \xrightarrow[\text{inverse row operation}]{\;+3R_1 + R_3\;} G^{-1} = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 3 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
