Definition 1.1 Linear Equation.

A linear equation in the variables \(x_1,\ldots,x_n\) can be written as
\begin{equation*} a_1x_1+\cdots+a_nx_n=b, \end{equation*}
where the coefficients \(a_1,\ldots,a_n\) and the constant \(b\) are known real numbers. We seek real values of the variables. A system is a collection of equations to be satisfied simultaneously.
