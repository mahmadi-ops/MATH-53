Remark 3.42. Square Matrices: One-to-One Equals Onto.

For an \(n \times n\) matrix \(A\text{,}\) having a pivot in every column is the same as having \(n\) pivots, which is the same as having a pivot in every row. So for a square matrix, the transformation \(T(\vec{x}) = A\vec{x}\) is one-to-one if and only if it is onto. For non-square matrices the two properties are independent — except that, by Remark 3.24 and Remark 3.33, a wide matrix is never one-to-one and a tall matrix is never onto.
