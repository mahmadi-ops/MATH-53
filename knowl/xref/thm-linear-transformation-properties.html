Theorem 3.10. Properties of Linear Transformations.

Let \(T : \R^n \to \R^m\) be a linear transformation, and let \(\vec{x} \in \R^n\text{.}\)
🔗
  1. \(T(0\vec{x}) = 0T(\vec{x})\text{,}\) implying \(T(\vec{0}) = \vec{0}\text{,}\) so \(T\) preserves the zero vector.
    🔗
    🔗
  2. \(T((-1)\vec{x}) = (-1)T(\vec{x})\text{,}\) implying \(T(-\vec{x}) = -T(\vec{x})\text{,}\) so \(T\) preserves the negative of a vector.
    🔗
    🔗
  3. Suppose \(\vec{x}_1, \vec{x}_2, \ldots, \vec{x}_k\) are vectors in \(\R^n\) and \(\vec{y} = a_1\vec{x}_1 + a_2\vec{x}_2 + \cdots + a_k\vec{x}_k\) for some \(a_1, a_2, \ldots, a_k \in \R\text{.}\) Then
    \begin{align*} T(\vec{y}) \amp = T(a_1\vec{x}_1 + a_2\vec{x}_2 + \cdots + a_k\vec{x}_k)\\ \amp = a_1 T(\vec{x}_1) + a_2 T(\vec{x}_2) + \cdots + a_k T(\vec{x}_k), \end{align*}
    i.e., \(T\) preserves linear combinations.
    🔗
    🔗
