Theorem 3.12 Properties of Linear Transformations.

Let \(T : \R^n \to \R^m\) be a linear transformation, and let \(\vec{x} \in \R^n\text{.}\)
🔗
  1. \(T(0\vec{x}) = 0T(\vec{x})\text{,}\) implying \(T(\vec{0}) = \vec{0}\text{,}\) so \(T\) preserves the zero vector.
    🔗
    🔗
  2. \(T((-1)\vec{x}) = (-1)T(\vec{x})\text{,}\) implying \(T(-\vec{x}) = -T(\vec{x})\text{,}\) so \(T\) preserves the negative of a vector.
    🔗
    🔗
  3. Suppose \(\vec{x}_1, \vec{x}_2, \ldots, \vec{x}_k\) are vectors in \(\R^n\) and \(\vec{y} = a_1\vec{x}_1 + a_2\vec{x}_2 + \cdots + a_k\vec{x}_k\) for some \(a_1, a_2, \ldots, a_k \in \R\text{.}\) Then
    \begin{align*} T(\vec{y}) \amp = T(a_1\vec{x}_1 + a_2\vec{x}_2 + \cdots + a_k\vec{x}_k)\\ \amp = a_1 T(\vec{x}_1) + a_2 T(\vec{x}_2) + \cdots + a_k T(\vec{x}_k), \end{align*}
    i.e., \(T\) preserves linear combinations.
    🔗
    🔗
🔗
🔗

Proof.
Each part uses only the two properties in Definition 3.10.
🔗
  1. Preservation of scalar multiplication with the scalar \(0\) gives \(T(0\vec{x}) = 0T(\vec{x})\text{.}\) On the left, \(0\vec{x}\) is the zero vector of \(\R^n\text{.}\) On the right, \(0\) times any vector of \(\R^m\) is the zero vector of \(\R^m\text{.}\) Hence \(T(\vec{0}) = \vec{0}\text{.}\)
    🔗
    🔗
  2. Preservation of scalar multiplication with the scalar \(-1\) gives \(T((-1)\vec{x}) = (-1)T(\vec{x})\text{.}\) Since \((-1)\vec{x} = -\vec{x}\) and \((-1)T(\vec{x}) = -T(\vec{x})\text{,}\) this says \(T(-\vec{x}) = -T(\vec{x})\text{.}\)
    🔗
    🔗
  3. For two vectors, use preservation of addition and then preservation of scalar multiplication:
    \begin{equation*} T(a_1\vec{x}_1 + a_2\vec{x}_2) = T(a_1\vec{x}_1) + T(a_2\vec{x}_2) = a_1 T(\vec{x}_1) + a_2 T(\vec{x}_2). \end{equation*}
    For \(k\) vectors, split off the last term in the same way,
    \begin{equation*} T\bigl( (a_1\vec{x}_1 + \cdots + a_{k-1}\vec{x}_{k-1}) + a_k\vec{x}_k \bigr) = T(a_1\vec{x}_1 + \cdots + a_{k-1}\vec{x}_{k-1}) + a_k T(\vec{x}_k), \end{equation*}
    and repeat the step on the shorter sum that remains. After \(k - 1\) steps every term has been split off, which gives
    \begin{equation*} T(a_1\vec{x}_1 + a_2\vec{x}_2 + \cdots + a_k\vec{x}_k) = a_1 T(\vec{x}_1) + a_2 T(\vec{x}_2) + \cdots + a_k T(\vec{x}_k). \end{equation*}
    🔗
    🔗
