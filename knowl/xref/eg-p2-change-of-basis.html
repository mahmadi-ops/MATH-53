Example 7.32. A Change of Basis in \(\mathbb{P}_2\).

Consider the standard ordered basis \(\mathcal{B}_1 = \{ 1, x, x^2 \}\) of \(\mathbb{P}_2\) and the set
\begin{equation*} \mathcal{B}_2 = \{ 1, \; 1 + x, \; 1 + x + x^2 \}. \end{equation*}
🔗
  1. Show that \(\mathcal{B}_2\) is a basis of \(\mathbb{P}_2\text{.}\)
    🔗
    🔗
  2. Find the change-of-basis matrix \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\text{,}\) which converts \(\mathcal{B}_1\)-coordinates into \(\mathcal{B}_2\)-coordinates.
    🔗
    🔗
  3. Find the coordinates of \(q(x) = 3 + 2x + 4x^2\) relative to the basis \(\mathcal{B}_2\text{.}\)
    🔗
    🔗
🔗
Solution.
(1) Since \(\dim \mathbb{P}_2 = 3\text{,}\) it is enough to show that the three polynomials are linearly independent. Suppose
\begin{equation*} a(1) + b(1 + x) + c(1 + x + x^2) = 0, \end{equation*}
that is,
\begin{equation*} (a + b + c) + (b + c)x + c x^2 = 0. \end{equation*}
Comparing coefficients gives \(c = 0\text{,}\) then \(b + c = 0\) forces \(b = 0\text{,}\) and then \(a + b + c = 0\) forces \(a = 0\text{.}\) Only the trivial combination produces the zero polynomial, so \(\mathcal{B}_2\) is linearly independent and hence a basis of \(\mathbb{P}_2\text{.}\)
🔗
(2) The easy direction is the other one: each element of \(\mathcal{B}_2\) is already written in terms of \(\{1, x, x^2\}\text{,}\) so reading off coordinates columnwise,
\begin{equation*} P_{\mathcal{B}_1 \leftarrow \mathcal{B}_2} = \begin{bmatrix} 1 \amp 1 \amp 1 \\ 0 \amp 1 \amp 1 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
The matrix we want is its inverse, \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} = \left( P_{\mathcal{B}_1 \leftarrow \mathcal{B}_2} \right)^{-1}\text{,}\) which we can also compute directly by expressing each element of \(\mathcal{B}_1\) in the basis \(\mathcal{B}_2\text{:}\)
\begin{equation*} 1 = (1), \qquad x = (1 + x) - (1), \qquad x^2 = (1 + x + x^2) - (1 + x), \end{equation*}
so that
\begin{equation*} P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
In the language of this section, \(P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1}\) is the matrix of the identity transformation \(\operatorname{id} : \mathbb{P}_2 \to \mathbb{P}_2\) with respect to the basis \(\mathcal{B}_1\) of the domain and the basis \(\mathcal{B}_2\) of the codomain: the transformation does nothing, and the matrix only translates between the two coordinate systems.
🔗
(3) Relative to \(\mathcal{B}_1\) the coordinates of \(q\) are read off directly, and the matrix converts them:
\begin{equation*} [q(x)]_{\mathcal{B}_1} = \begin{bmatrix} 3 \\ 2 \\ 4 \end{bmatrix}, \qquad [q(x)]_{\mathcal{B}_2} = P_{\mathcal{B}_2 \leftarrow \mathcal{B}_1} [q(x)]_{\mathcal{B}_1} = \begin{bmatrix} 1 \amp -1 \amp 0 \\ 0 \amp 1 \amp -1 \\ 0 \amp 0 \amp 1 \end{bmatrix} \begin{bmatrix} 3 \\ 2 \\ 4 \end{bmatrix} = \begin{bmatrix} 1 \\ -2 \\ 4 \end{bmatrix}. \end{equation*}
As a check,
\begin{equation*} 1(1) - 2(1 + x) + 4(1 + x + x^2) = (1 - 2 + 4) + (-2 + 4)x + 4x^2 = 3 + 2x + 4x^2 = q(x). \end{equation*}
