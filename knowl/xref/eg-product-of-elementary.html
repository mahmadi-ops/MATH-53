Example 4.63 Factoring a Matrix into Elementary Matrices.

Express \(A = \begin{bmatrix} 1 \amp 2 \amp -4 \\ -3 \amp -6 \amp 13 \\ 0 \amp -1 \amp 2 \end{bmatrix}\) as a product of elementary matrices and, if possible, find \(A^{-1}\text{.}\)
🔗
Solution.
We need to keep track of the elementary row operations performed in the matrix inversion algorithm. Each step below records the elementary matrix \(E_i\) obtained by applying that step’s row operation to \(I_3\text{.}\)
🔗
\begin{align*} \left[ \begin{array}{ccc|ccc} 1 \amp 2 \amp -4 \amp 1 \amp 0 \amp 0 \\ -3 \amp -6 \amp 13 \amp 0 \amp 1 \amp 0 \\ 0 \amp -1 \amp 2 \amp 0 \amp 0 \amp 1 \end{array} \right] \amp \xrightarrow{R_2 + 3R_1} \left[ \begin{array}{ccc|ccc} 1 \amp 2 \amp -4 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 3 \amp 1 \amp 0 \\ 0 \amp -1 \amp 2 \amp 0 \amp 0 \amp 1 \end{array} \right]\\ \amp \xrightarrow{R_3 \leftrightarrow R_2} \left[ \begin{array}{ccc|ccc} 1 \amp 2 \amp -4 \amp 1 \amp 0 \amp 0 \\ 0 \amp -1 \amp 2 \amp 0 \amp 0 \amp 1 \\ 0 \amp 0 \amp 1 \amp 3 \amp 1 \amp 0 \end{array} \right]\\ \amp \xrightarrow{-R_2} \left[ \begin{array}{ccc|ccc} 1 \amp 2 \amp -4 \amp 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -2 \amp 0 \amp 0 \amp -1 \\ 0 \amp 0 \amp 1 \amp 3 \amp 1 \amp 0 \end{array} \right]\\ \amp \xrightarrow{R_1 - 2R_2} \left[ \begin{array}{ccc|ccc} 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp -2 \amp 0 \amp 0 \amp -1 \\ 0 \amp 0 \amp 1 \amp 3 \amp 1 \amp 0 \end{array} \right]\\ \amp \xrightarrow{R_2 + 2R_3} \left[ \begin{array}{ccc|ccc} 1 \amp 0 \amp 0 \amp 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp 0 \amp 6 \amp 2 \amp -1 \\ 0 \amp 0 \amp 1 \amp 3 \amp 1 \amp 0 \end{array} \right] = \left[ \, I_3 \mid A^{-1} \, \right]. \end{align*}
🔗
The corresponding elementary matrices are
\begin{equation*} E_1 = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 3 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix}, \quad E_2 = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \end{bmatrix}, \quad E_3 = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix}, \end{equation*}
\begin{equation*} E_4 = \begin{bmatrix} 1 \amp -2 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix}, \quad E_5 = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 2 \\ 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
By Observation 4.60, applying these five row operations in order is the same as multiplying on the left by \(E_1\text{,}\) then \(E_2\text{,}\) and so on. Since the reduction carried \(A\) to \(I\text{,}\)
\begin{equation*} \left( E_5 E_4 E_3 E_2 E_1 \right) A = I. \end{equation*}
Multiplying both sides on the right by \(A^{-1}\) gives
\begin{equation*} \left( E_5 E_4 E_3 E_2 E_1 \right) \underbrace{A A^{-1}}_{I} = I A^{-1}, \end{equation*}
so
\begin{equation*} A^{-1} = E_5 E_4 E_3 E_2 E_1 = \begin{bmatrix} 1 \amp 0 \amp 2 \\ 6 \amp 2 \amp -1 \\ 3 \amp 1 \amp 0 \end{bmatrix}, \end{equation*}
agreeing with the right half of the reduced augmented matrix above.
🔗
Finally, taking inverses of both sides and using Theorem 4.47 (3),
\begin{equation*} A = \left( E_5 E_4 E_3 E_2 E_1 \right)^{-1} = E_1^{-1} E_2^{-1} E_3^{-1} E_4^{-1} E_5^{-1}, \end{equation*}
that is,
\begin{equation*} A = \begin{bmatrix} 1 \amp 0 \amp 0 \\ -3 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix} \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \\ 0 \amp 1 \amp 0 \end{bmatrix} \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp -1 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix} \begin{bmatrix} 1 \amp 2 \amp 0 \\ 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix} \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp -2 \\ 0 \amp 0 \amp 1 \end{bmatrix}, \end{equation*}
where each factor was obtained from the corresponding \(E_i\) by Observation 4.62.
