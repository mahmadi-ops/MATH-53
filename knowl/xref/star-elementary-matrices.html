Exercise 42. ★ Three Elementary Matrices.

Write down the elementary matrices obtained from \(I_4\) by each of the row operations \(r_1 \leftrightarrow r_3\text{,}\) \(4r_2\text{,}\) and \(2r_4 + r_1\text{.}\)
🔗
Solution.
Apply each operation to \(I_4\) exactly once:
\begin{equation*} E = \begin{bmatrix} 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 1 \amp 0 \amp 0 \\ 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}, \quad F = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 0 \\ 0 \amp 4 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}, \end{equation*}
\begin{equation*} G = \begin{bmatrix} 1 \amp 0 \amp 0 \amp 2 \\ 0 \amp 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \amp 0 \\ 0 \amp 0 \amp 0 \amp 1 \end{bmatrix}. \end{equation*}
🔗
In symbols,
\begin{align*} I_4 \amp \xrightarrow{\;r_1 \leftrightarrow r_3\;} E,\\ I_4 \amp \xrightarrow{\;4r_2\;} F,\\ I_4 \amp \xrightarrow{\;2r_4 + r_1\;} G. \end{align*}
For \(G\text{,}\) note that adding \(2\) times row \(4\) to row \(1\) puts the \(2\) in position \((1,4)\text{,}\) not \((4,1)\text{.}\)
