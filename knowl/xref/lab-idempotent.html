Exercise 11. Matrices with \(A^2 = A\).

Let \(A\) be an \(n \times n\) matrix and \(I\) the \(n \times n\) identity. Which of the following statements is always true?
  1. If \(A^2 = A\text{,}\) then \(A = 0\) or \(A = I\text{.}\)
    🔗
    🔗
  2. If \(A^2 = A\) and \(A \neq 0\text{,}\) then \(A\) is invertible.
    🔗
    🔗
  3. If \(A^2 = A\text{,}\) then \(\det A = 0\) or \(\det A = 1\text{.}\)
    🔗
    🔗
  4. If \(\det A = 0\) or \(\det A = 1\text{,}\) then \(A^2 = A\text{.}\)
    🔗
    🔗
🔗
Solution.
A single example settles (a) and (b). Take \(A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}\text{.}\) Then \(A^2 = A\text{,}\) yet \(A\) is neither \(0\) nor \(I\text{,}\) and \(\det A = 0\) so \(A\) is not invertible. Both (a) and (b) are false.
🔗
(c) is true. Taking determinants in \(A^2 = A\) and using Theorem 6.19,
\begin{equation*} (\det A)^2 = \det A, \qquad\text{so}\qquad \det A (\det A - 1) = 0, \end{equation*}
which forces \(\det A = 0\) or \(\det A = 1\text{.}\)
🔗
(d) is false — it is the converse of (c), and converses of true statements need not hold. For instance \(A = \begin{bmatrix} 1 \amp 1 \\ 0 \amp 1 \end{bmatrix}\) has \(\det A = 1\text{,}\) but \(A^2 = \begin{bmatrix} 1 \amp 2 \\ 0 \amp 1 \end{bmatrix} \neq A\text{.}\)
