Exercise 8. ★ The Steady State for Bob’s Coffee.

Does \(T = \begin{bmatrix} \frac{1}{3} \amp 1 \\[2pt] \frac{2}{3} \amp 0 \end{bmatrix}\) have a unique steady state vector? If so, find it.
🔗
Solution.
(I) \(T\) is stochastic, since each column sums to \(1\text{.}\)
🔗
(II) \(T\) is regular, by Exercise 10.9.3.
🔗
From (I) and (II) and Theorem 9.12, \(T\) has a unique steady state vector.
🔗
To find it, solve \((T - I)\vec{S} = \vec{0}\text{:}\)
\begin{equation*} \left[ \begin{array}{cc|c} -\frac{2}{3} \amp 1 \amp 0 \\[2pt] \frac{2}{3} \amp -1 \amp 0 \end{array} \right] \longrightarrow \left[ \begin{array}{cc|c} 2 \amp -3 \amp 0 \\ 0 \amp 0 \amp 0 \end{array} \right], \end{equation*}
so \(2a = 3b\) and \(\vec{S} = t\begin{bmatrix} 3 \\ 2 \end{bmatrix}\text{.}\)
🔗
The entries are probabilities, so they must sum to \(1\text{:}\) \(5t = 1\) gives \(t = \tfrac{1}{5}\) and
\begin{equation*} \vec{S} = \begin{bmatrix} \frac{3}{5} \\[2pt] \frac{2}{5} \end{bmatrix} = \begin{bmatrix} 0.6 \\ 0.4 \end{bmatrix}, \end{equation*}
confirming the numerical limit observed in Exercise 10.9.2. Checking, \(T(0.6, 0.4) = (0.2 + 0.4,\ 0.4) = (0.6, 0.4)\text{.}\) \(\checkmark\)
