Example 7.22. The Same Matrix in Two Coordinate Systems.

Coordinates work in any vector space, not just in \(\R^n\text{.}\) In \(\mathbb{M}_{22}\text{,}\) consider the matrix \(M = \begin{bmatrix} 3 \amp 1 \\ -2 \amp 4 \end{bmatrix}\text{,}\) the standard ordered basis
\begin{equation*} \mathcal{B}_1 = \{ M_{11}, M_{12}, M_{21}, M_{22} \} = \left\{ \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}, \begin{bmatrix} 0 \amp 1 \\ 0 \amp 0 \end{bmatrix}, \begin{bmatrix} 0 \amp 0 \\ 1 \amp 0 \end{bmatrix}, \begin{bmatrix} 0 \amp 0 \\ 0 \amp 1 \end{bmatrix} \right\}, \end{equation*}
and the ordered basis
\begin{equation*} \mathcal{B}_2 = \left\{ \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}, \begin{bmatrix} 1 \amp 1 \\ 0 \amp 0 \end{bmatrix}, \begin{bmatrix} 0 \amp 0 \\ 1 \amp 1 \end{bmatrix}, \begin{bmatrix} 0 \amp 0 \\ 0 \amp 1 \end{bmatrix} \right\}. \end{equation*}
Find the two representations \([M]_{\mathcal{B}_1}\) and \([M]_{\mathcal{B}_2}\text{.}\)
🔗
Solution.
Relative to \(\mathcal{B}_1\text{.}\) The entries of \(M\) are its coordinates:
\begin{equation*} M = 3M_{11} + 1M_{12} - 2M_{21} + 4M_{22}, \qquad [M]_{\mathcal{B}_1} = \begin{bmatrix} 3 \\ 1 \\ -2 \\ 4 \end{bmatrix}. \end{equation*}
🔗
Relative to \(\mathcal{B}_2\text{.}\) First, \(\mathcal{B}_2\) is indeed a basis: setting a combination of its four matrices equal to the zero matrix and comparing the \((1,2)\text{,}\) \((1,1)\text{,}\) \((2,1)\text{,}\) and \((2,2)\) entries in that order forces every coefficient to vanish, so the set is linearly independent, and four independent vectors in the four-dimensional space \(\mathbb{M}_{22}\) form a basis. Now write
\begin{equation*} M = a \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix} + b \begin{bmatrix} 1 \amp 1 \\ 0 \amp 0 \end{bmatrix} + c \begin{bmatrix} 0 \amp 0 \\ 1 \amp 1 \end{bmatrix} + d \begin{bmatrix} 0 \amp 0 \\ 0 \amp 1 \end{bmatrix}. \end{equation*}
Comparing entries: the \((1,2)\) entry gives \(b = 1\text{,}\) then the \((1,1)\) entry gives \(a + b = 3\text{,}\) so \(a = 2\text{;}\) the \((2,1)\) entry gives \(c = -2\text{,}\) then the \((2,2)\) entry gives \(c + d = 4\text{,}\) so \(d = 6\text{.}\) Hence
\begin{equation*} [M]_{\mathcal{B}_2} = \begin{bmatrix} 2 \\ 1 \\ -2 \\ 6 \end{bmatrix}. \end{equation*}
The same matrix, two coordinate vectors — one for each choice of basis.
