Example 1.13 Describing Infinitely Many Solutions.

The system of linear equations in three variables that we saw earlier,
\begin{align*} x_1 - 2x_2 - 7x_3 \amp = -1\\ -x_1 + 3x_2 + 6x_3 \amp = 0, \end{align*}
has solutions \(x_1 = -3 + 9s\text{,}\) \(x_2 = -1 + s\text{,}\) \(x_3 = s\text{,}\) where \(s\) is any real number (\(s \in \R\)).
🔗
Solution.
To obtain all the solutions, add the two original equations to get \(x_2-x_3=-1\text{.}\) Thus \(x_2=-1+x_3\text{.}\) Substitution in the first equation gives
\begin{equation*} x_1=-1+2(-1+x_3)+7x_3=-3+9x_3. \end{equation*}
Every solution must therefore have the stated form with \(s=x_3\text{.}\) Conversely, substituting these expressions in the original equations gives
\begin{align*} (-3+9s)-2(-1+s)-7s \amp =-1,\\ -(-3+9s)+3(-1+s)+6s \amp =0 \end{align*}
for every real \(s\text{.}\) Hence every parameter value works, and the formulas describe exactly all the solutions.
🔗
The number \(s\) is called a parameter, and
\begin{equation*} x_1 = -3 + 9s, \quad x_2 = -1 + s, \quad x_3 = s, \quad \text{where } s \in \R \end{equation*}
is called the solution set in parametric form.
🔗
Notice that the two solutions we found in Example 1.5 are recovered by taking \(s = 0\) and \(s = 1\text{:}\)
\begin{align*} s = 0 \amp \;\longrightarrow\; (x_1, x_2, x_3) = (-3, -1, 0),\\ s = 1 \amp \;\longrightarrow\; (x_1, x_2, x_3) = (6, 0, 1). \end{align*}
