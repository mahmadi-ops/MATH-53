Exercise 12. When Cancellation Fails.

  1. Find \(2 \times 2\) matrices \(A\text{,}\) \(C\text{,}\) \(D\) with \(A \neq 0\) and \(C \neq D\text{,}\) but \(AC = AD\text{.}\)
    🔗
    🔗
  2. Can this be done with \(AC \neq 0\text{?}\)
    🔗
    🔗
  3. Give an example of matrices \(A\text{,}\) \(B\text{,}\) neither of them zero, with \(AB = 0\text{.}\)
    🔗
    🔗
🔗
Solution.
(a) The condition \(AC = AD\) is the same as \(A(C - D) = 0\text{,}\) so we need a nonzero \(A\) that kills some nonzero matrix. Any \(A\) whose columns are linearly dependent will do. Take
\begin{equation*} A = \begin{bmatrix} 1 \amp -1 \\ -1 \amp 1 \end{bmatrix}, \quad C = \begin{bmatrix} 1 \amp 1 \\ 1 \amp 1 \end{bmatrix}, \quad D = \begin{bmatrix} 2 \amp 2 \\ 2 \amp 2 \end{bmatrix}. \end{equation*}
Every column of \(C\) and of \(D\) has equal entries, and \(A\) annihilates such a column, so
\begin{equation*} AC = \begin{bmatrix} 0 \amp 0 \\ 0 \amp 0 \end{bmatrix} = AD, \end{equation*}
while \(C \neq D\) and \(A \neq 0\text{.}\)
🔗
(b) Yes. We only need \(A(C-D) = 0\text{;}\) nothing forces \(AC\) itself to vanish. Take
\begin{equation*} A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}, \quad C = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}, \quad D = \begin{bmatrix} 1 \amp 0 \\ 1 \amp 0 \end{bmatrix}. \end{equation*}
Then
\begin{equation*} AC = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix} = AD \neq 0, \end{equation*}
and still \(C \neq D\text{.}\)
🔗
(c) This is the case \(D = 0\) of part (a): we need a nonzero \(B\) whose columns all solve \(A\vec{x} = \vec{0}\text{.}\) Such a nonzero \(\vec{x}\) exists exactly when \(A\) is not invertible. With the same \(A\) as in (a),
\begin{equation*} \begin{bmatrix} 1 \amp -1 \\ -1 \amp 1 \end{bmatrix} \begin{bmatrix} 1 \amp 1 \\ 1 \amp 1 \end{bmatrix} = \begin{bmatrix} 0 \amp 0 \\ 0 \amp 0 \end{bmatrix}. \end{equation*}
Note that \(B\) may have any number of columns; a single column \([1\ 1]^T\) works just as well.
🔗
