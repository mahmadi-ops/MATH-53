Example 2.38. Expressing a Vector as a Linear Combination.

Let
\begin{equation*} A = \begin{bmatrix} 1 \amp 0 \amp 2 \amp -1 \\ 2 \amp -1 \amp 0 \amp 1 \\ 3 \amp 1 \amp 3 \amp 1 \end{bmatrix} \qquad \text{and} \qquad B = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}. \end{equation*}
Express \(B\) as a linear combination of the columns \(A_1, A_2, A_3, A_4\) of \(A\text{,}\) or show that this is impossible.
🔗
Solution.
Consider \(C = \begin{bmatrix} A \amp \vec{B} \end{bmatrix}\text{.}\) As stated in Theorem 2.37, if \(C\vec{X} = \vec{0}\) has only the trivial solution, then \(\{ \vec{A}_1, \vec{A}_2, \vec{A}_3, \vec{A}_4, \vec{B} \}\) is a linearly independent set. If this is the case, we will not be able to write \(\vec{B}\) as a linear combination of the columns of \(A\text{.}\)
🔗
Also, if \(C\vec{X} = \vec{0}\) has a nontrivial solution, then we have
\begin{equation*} a_1 \vec{A}_1 + a_2 \vec{A}_2 + a_3 \vec{A}_3 + a_4 \vec{A}_4 + a_5 \vec{B} = \vec{0}, \end{equation*}
and if \(a_5 \neq 0\text{,}\) then
\begin{equation*} \vec{B} = -\frac{1}{a_5} \left( a_1 \vec{A}_1 + a_2 \vec{A}_2 + a_3 \vec{A}_3 + a_4 \vec{A}_4 \right). \end{equation*}
🔗
Row reducing,
\begin{align*} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 2 \amp -1 \amp 0 \amp 1 \amp 1 \amp 0 \\ 3 \amp 1 \amp 3 \amp 1 \amp 1 \amp 0 \end{array} \right] \amp \xrightarrow[-3r_1 + r_3]{-2r_1 + r_2} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp -1 \amp -4 \amp 3 \amp -1 \amp 0 \\ 0 \amp 1 \amp -3 \amp 4 \amp -2 \amp 0 \end{array} \right]\\ \amp \xrightarrow{r_2 + r_3} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp -1 \amp -4 \amp 3 \amp -1 \amp 0 \\ 0 \amp 0 \amp -7 \amp 7 \amp -3 \amp 0 \end{array} \right]\\ \amp \xrightarrow[-\frac{1}{7} r_3]{-r_2} \left[ \begin{array}{ccccc|c} 1 \amp 0 \amp 2 \amp -1 \amp 1 \amp 0 \\ 0 \amp 1 \amp 4 \amp -3 \amp 1 \amp 0 \\ 0 \amp 0 \amp 1 \amp -1 \amp \frac{3}{7} \amp 0 \end{array} \right]. \end{align*}
🔗
With \(x_4 = s\) and \(x_5 = t\) free, back-substitution gives
\begin{align*} x_1 \amp = -s - \tfrac{1}{7}t\\ x_2 \amp = -s + \tfrac{5}{7}t\\ x_3 \amp = s - \tfrac{3}{7}t\\ x_4 \amp = s\\ x_5 \amp = t, \qquad \text{where } s, t \in \R. \end{align*}
🔗
For \(s = 1\) and \(t = -1\) we get \(x_1 = -\frac{6}{7}\text{,}\) \(x_2 = -\frac{12}{7}\text{,}\) \(x_3 = \frac{10}{7}\text{,}\) \(x_4 = 1\text{,}\) \(x_5 = -1\text{,}\) so
\begin{equation*} -\tfrac{6}{7}\vec{A}_1 - \tfrac{12}{7}\vec{A}_2 + \tfrac{10}{7}\vec{A}_3 + \vec{A}_4 - \vec{B} = \vec{0}. \end{equation*}
Since \(a_5 = -1 \neq 0\text{,}\) we may solve for \(\vec{B}\text{.}\) As an example, \(\vec{B}\) can be written as the following linear combination of the columns of \(A\text{:}\)
\begin{equation*} \vec{B} = -\tfrac{6}{7}\vec{A}_1 - \tfrac{12}{7}\vec{A}_2 + \tfrac{10}{7}\vec{A}_3 + \vec{A}_4. \end{equation*}
