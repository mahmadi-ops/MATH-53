Theorem 4.20. Properties of Matrix Multiplication.

Let \(A\text{,}\) \(B\text{,}\) and \(C\) be matrices of the appropriate sizes, and let \(r \in \R\) be a scalar. Then the following properties hold.
🔗
  1. \(A(B + C) = AB + AC\) (matrix multiplication distributes over matrix addition).
    🔗
    🔗
  2. \((B + C)A = BA + CA\) (matrix multiplication distributes over matrix addition).
    🔗
    🔗
  3. \(A(BC) = (AB)C\) (matrix multiplication is associative).
    🔗
    🔗
  4. \(r(AB) = (rA)B = A(rB)\text{.}\)
