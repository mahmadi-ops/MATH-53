Example 3.5 Which Outputs Occur, and from Which Input?

Let \(T = T_A\) be the transformation of Example 3.4, and let \(\vec{b} = \begin{bmatrix} b_1 \\ b_2 \\ b_3 \\ b_4 \end{bmatrix}\) be a proposed output.
🔗
  1. Determine exactly when \(T(\vec{x}) = \vec{b}\) has a solution, and find every input \(\vec{x}\) when it does.
    🔗
    🔗
  2. Show that your condition is sufficient as well as necessary.
    🔗
    🔗
  3. The output has four entries. Do they record four independent pieces of information about the input?
    🔗
    🔗
🔗
Solution.
(a) The equation \(T(\vec{x}) = \vec{b}\) is the linear system \(A\vec{x} = \vec{b}\text{.}\) Row reduce its augmented matrix:
\begin{align*} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 0 \amp b_1 \\ 0 \amp 1 \amp 0 \amp b_2 \\ 0 \amp 1 \amp -1 \amp b_3 \\ 0 \amp -1 \amp 1 \amp b_4 \end{array} \right] \amp \xrightarrow[r_2 + r_4]{-r_2 + r_3} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 0 \amp b_1 \\ 0 \amp 1 \amp 0 \amp b_2 \\ 0 \amp 0 \amp -1 \amp b_3 - b_2 \\ 0 \amp 0 \amp 1 \amp b_2 + b_4 \end{array} \right]\\ \amp \xrightarrow{r_3 + r_4} \left[ \begin{array}{ccc|c} 1 \amp 1 \amp 0 \amp b_1 \\ 0 \amp 1 \amp 0 \amp b_2 \\ 0 \amp 0 \amp -1 \amp b_3 - b_2 \\ 0 \amp 0 \amp 0 \amp b_3 + b_4 \end{array} \right]\\ \amp \xrightarrow[-r_2 + r_1]{-r_3} \left[ \begin{array}{ccc|c} 1 \amp 0 \amp 0 \amp b_1 - b_2 \\ 0 \amp 1 \amp 0 \amp b_2 \\ 0 \amp 0 \amp 1 \amp b_2 - b_3 \\ 0 \amp 0 \amp 0 \amp b_3 + b_4 \end{array} \right]. \end{align*}
The last row reads \(0 = b_3 + b_4\text{,}\) so the system is consistent exactly when \(b_4 = -b_3\text{.}\) In that case every column of \(A\) has a pivot, there is no free variable, and there is exactly one input:
\begin{equation*} \vec{x} = \begin{bmatrix} b_1 - b_2 \\ b_2 \\ b_2 - b_3 \end{bmatrix}. \end{equation*}
🔗
(b) The condition is necessary because of the last row. It is sufficient because, when \(b_4 = -b_3\text{,}\) the input found in (a) really does produce \(\vec{b}\text{:}\)
\begin{equation*} T \begin{bmatrix} b_1 - b_2 \\ b_2 \\ b_2 - b_3 \end{bmatrix} = \begin{bmatrix} (b_1 - b_2) + b_2 \\ b_2 \\ b_2 - (b_2 - b_3) \\ -b_2 + (b_2 - b_3) \end{bmatrix} = \begin{bmatrix} b_1 \\ b_2 \\ b_3 \\ -b_3 \end{bmatrix} = \vec{b}. \end{equation*}
🔗
(c) No. The fourth entry of every output is the negative of the third, since \(-y + z = -(y - z)\text{,}\) so it repeats what the third entry already says. The range of \(T\) is the set of vectors of \(\R^4\) with \(b_3 + b_4 = 0\text{,}\) not all of \(\R^4\text{.}\) For example, \(\begin{bmatrix} 1 \\ 0 \\ -2 \\ 2 \end{bmatrix}\) is an output, and the formula in (a) returns its input \(\begin{bmatrix} 1 \\ 0 \\ 2 \end{bmatrix}\text{,}\) whereas \(\begin{bmatrix} 1 \\ 0 \\ 0 \\ 1 \end{bmatrix}\) is not an output of any input.
🔗
Two separate facts appeared here: every output that occurs comes from only one input, and not every vector of the codomain occurs. Section 3.2 gives each of them a name.
