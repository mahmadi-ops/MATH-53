Theorem 3.12. Every Matrix Transformation Is a Linear Transformation.

Every matrix transformation is a linear transformation.
🔗
🔗

Proof.
Consider the matrix transformation \(T_A(\vec{x}) = A\vec{x}\text{.}\) We will show that such a transformation is in fact linear, i.e., it preserves addition and scalar multiplication.
🔗
(1) Preservation of addition. Let \(A\) be \(m \times n\) with columns \(\vec{A}_1, \ldots, \vec{A}_n\text{,}\) and let \(\vec{x}, \vec{y} \in \R^n\text{.}\) Then
\begin{align*} T_A(\vec{x} + \vec{y}) \amp = A(\vec{x} + \vec{y})\\ \amp = (x_1 + y_1)\vec{A}_1 + (x_2 + y_2)\vec{A}_2 + \cdots + (x_n + y_n)\vec{A}_n\\ \amp = \left( x_1\vec{A}_1 + \cdots + x_n\vec{A}_n \right) + \left( y_1\vec{A}_1 + \cdots + y_n\vec{A}_n \right)\\ \amp = A\vec{x} + A\vec{y} = T_A(\vec{x}) + T_A(\vec{y}). \end{align*}
🔗
(2) Preservation of scalar multiplication. Let \(c \in \R\) and \(\vec{x} \in \R^n\text{.}\) Then
\begin{align*} T_A(c\vec{x}) \amp = A(c\vec{x})\\ \amp = (cx_1)\vec{A}_1 + (cx_2)\vec{A}_2 + \cdots + (cx_n)\vec{A}_n\\ \amp = c \left( x_1\vec{A}_1 + x_2\vec{A}_2 + \cdots + x_n\vec{A}_n \right)\\ \amp = c \left( A\vec{x} \right) = c \, T_A(\vec{x}). \end{align*}
