Exercise 19. What Guarantees Diagonalizability?

Let \(A\) be an \(n \times n\) matrix. Which of the following is always true?
  1. \(A\) is always diagonalizable.
    🔗
    🔗
  2. If for some \(\lambda\) the system \((\lambda I - A)\vec{x} = \vec{0}\) has infinitely many solutions, then \(A\) is diagonalizable.
    🔗
    🔗
  3. If the characteristic polynomial of \(A\) has a single root of multiplicity \(n\text{,}\) then \(A\) is diagonalizable.
    🔗
    🔗
  4. If the characteristic polynomial of \(A\) has \(n\) distinct roots, then \(A\) is diagonalizable.
    🔗
    🔗
🔗
Solution.
(a) False. Exercise 10.8.17 gives a \(3 \times 3\) counterexample, and \(\begin{bmatrix} 1 \amp 1 \\ 0 \amp 1 \end{bmatrix}\) gives a \(2 \times 2\) one.
🔗
(b) False. That \((\lambda I - A)\vec{x} = \vec{0}\) has a nontrivial solution says only that \(\lambda\) is an eigenvalue — true of every eigenvalue of every matrix, diagonalizable or not. Again \(\begin{bmatrix} 1 \amp 1 \\ 0 \amp 1 \end{bmatrix}\) with \(\lambda = 1\) is a counterexample.
🔗
(c) False. This is precisely the situation of Exercise 10.8.17: a single root of multiplicity \(n\) whose eigenspace is too small. (It can happen that such a matrix is diagonalizable — when \(A = \lambda I\) — but it is not guaranteed.)
🔗
(d) True. Eigenvectors belonging to distinct eigenvalues are linearly independent, so \(n\) distinct roots produce \(n\) independent eigenvectors, which is exactly the criterion of Theorem 8.15. See also Example 8.14.
