Definition 2.19. Linear Combination.

If \(X_1, X_2, \ldots, X_p \in \R^n\) are columns with \(n\) entries, and if \(a_1, a_2, \ldots, a_p \in \R\) are scalars, then
\begin{equation*} a_1 X_1 + a_2 X_2 + \cdots + a_p X_p \end{equation*}
is a linear combination of columns \(X_1, X_2, \ldots, X_p\text{.}\)
