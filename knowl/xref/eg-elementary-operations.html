Example 1.17. The Three Operations in Action.

Consider the system of linear equations
\begin{align*} 3x_1 - 2x_2 - 7x_3 \amp = -1\\ -x_1 + 3x_2 + 6x_3 \amp = 1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
Apply each of the three elementary operations to it.
🔗
Solution.
Interchange the first two equations.
\begin{align*} -x_1 + 3x_2 + 6x_3 \amp = 1\\ 3x_1 - 2x_2 - 7x_3 \amp = -1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
🔗
Multiply the first equation by \(-2\text{.}\)
\begin{align*} -6x_1 + 4x_2 + 14x_3 \amp = 2\\ -x_1 + 3x_2 + 6x_3 \amp = 1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
🔗
Add \(3\) times the second equation to the first equation.
\begin{align*} \phantom{-6x_1 +{}} 7x_2 + 11x_3 \amp = 2\\ -x_1 + 3x_2 + 6x_3 \amp = 1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
Here the first equation became \((3x_1 - 2x_2 - 7x_3) + 3(-x_1 + 3x_2 + 6x_3) = -1 + 3(1)\text{,}\) i.e., \(0x_1 + 7x_2 + 11x_3 = 2\text{.}\) Notice that \(x_1\) has been eliminated from that equation — this is exactly the effect we will exploit systematically.
🔗
Each of the three displays above is obtained from the original system by a single operation; they are not applied one after another.
