Example 1.23 The Three Operations in Action.

Consider the system of linear equations
\begin{align*} 3x_1 - 2x_2 - 7x_3 \amp = -1\\ -x_1 + 3x_2 + 6x_3 \amp = 1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
Use the three elementary operations, one after another, to eliminate \(x_1\) from the second equation.
🔗
Solution.
The operations are applied in sequence: each one acts on the system produced by the one before, not on the original system. This is how they are always used in practice.
🔗
Interchange the first two equations, \(E_1 \leftrightarrow E_2\text{,}\) to bring the equation with the simplest \(x_1\)-term to the top:
\begin{align*} -x_1 + 3x_2 + 6x_3 \amp = 1\\ 3x_1 - 2x_2 - 7x_3 \amp = -1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
🔗
Multiply the first equation by \(-1\text{,}\) \(-E_1\text{,}\) so that it begins with \(x_1\text{:}\)
\begin{align*} x_1 - 3x_2 - 6x_3 \amp = -1\\ 3x_1 - 2x_2 - 7x_3 \amp = -1\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
🔗
Add \(-3\) times the first equation to the second equation, \(-3E_1 + E_2\text{:}\)
\begin{align*} x_1 - 3x_2 - 6x_3 \amp = -1\\ \phantom{x_1 +{}} 7x_2 + 11x_3 \amp = 2\\ 2x_1 \phantom{{}- 2x_2} - x_3 \amp = 3 \end{align*}
Here the second equation became \((3x_1 - 2x_2 - 7x_3) - 3(x_1 - 3x_2 - 6x_3) = -1 - 3(-1)\text{,}\) i.e., \(0x_1 + 7x_2 + 11x_3 = 2\text{.}\) Notice that \(x_1\) has been eliminated from that equation — this is exactly the effect we will exploit systematically. By Theorem 1.22, every system along the way is equivalent to the one we started with.
