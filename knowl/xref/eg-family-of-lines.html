Example 1.12 One Family, All Three Cases.

For all real numbers \(a\) and \(b\text{,}\) classify the solution set of
\begin{align*} x + y \amp = 1\\ ax + y \amp = b. \end{align*}
Give exact conditions on \(a\) and \(b\) for one solution, no solutions, and infinitely many solutions; find all solutions in every consistent case; and interpret each case as intersecting, parallel, or coincident lines. Why would dividing by \(a - 1\) before separating cases lose answers?
🔗
Solution.
Subtracting the first equation from the second gives
\begin{equation*} (a - 1)x = b - 1. \end{equation*}
Every solution of the system satisfies this equation. Conversely, if \(x + y = 1\) and \((a-1)x = b-1\) both hold, adding them gives back \(ax + y = b\text{.}\) So the system has exactly the same solutions as the pair \(x + y = 1\text{,}\) \((a-1)x = b-1\text{,}\) and everything depends on whether \(a - 1\) is zero.
🔗
Case \(a \neq 1\text{.}\) Then \(x = \dfrac{b-1}{a-1}\) and \(y = 1 - x = \dfrac{a-b}{a-1}\text{:}\) exactly one solution, for every \(b\text{.}\) The lines have slopes \(-1\) and \(-a\text{,}\) which differ, so they intersect in one point.
🔗
Case \(a = 1\) and \(b = 1\text{.}\) Both equations are \(x + y = 1\text{,}\) and the derived equation reads \(0 = 0\text{.}\) The lines coincide, and every point \((x, y) = (t, 1 - t)\) with \(t \in \R\) is a solution. The same thing happens whenever one equation is a nonzero multiple of the other: in \(x - y = 0\text{,}\) \(2x - 2y = 0\text{,}\) both equations describe the line \(y = x\text{.}\)
🔗
Case \(a = 1\) and \(b \neq 1\text{.}\) The derived equation reads \(0 = b - 1\) with \(b - 1 \neq 0\text{,}\) which is impossible: no solutions. The lines \(x + y = 1\) and \(x + y = b\) are parallel and distinct.
🔗
The formula \(x = (b-1)/(a-1)\) has no meaning when \(a = 1\text{,}\) and dividing by \(a - 1\) at the start would silently assume \(a \neq 1\text{.}\) Both the coincident case and the parallel case live exactly at \(a = 1\text{,}\) so the division would discard every system except those with a unique solution.
