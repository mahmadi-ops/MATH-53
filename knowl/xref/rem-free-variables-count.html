Theorem 1.41 Existence and Uniqueness of Solutions.

Let a system of linear equations have augmented matrix \(A\text{,}\) and let \(R\) be a row-echelon form of \(A\text{.}\)
  1. Existence. The system is consistent if and only if \(R\) has no row of the form \(\left[ \begin{array}{cccc|c} 0 \amp 0 \amp \cdots \amp 0 \amp d \end{array} \right]\) with \(d \neq 0\text{;}\) equivalently, if and only if the augmented column is not a pivot column.
    🔗
    🔗
  2. Uniqueness. If the system is consistent, then it has a unique solution when there are no free variables, and infinitely many solutions when there is at least one free variable — one parameter for each free variable.
    🔗
    🔗
🔗
🔗

Proof.
A row \([\,0 \; \cdots \; 0 \mid d\,]\) with \(d \neq 0\) stands for the equation \(0 = d\text{,}\) which no values of the variables can satisfy, so a system whose echelon form contains such a row is inconsistent. Conversely, suppose there is no such row. Then every nonzero row of \(R\) has its leading entry in a variable column, and the backward phase of the algorithm carries \(R\) to a reduced row-echelon matrix in which each basic variable appears, with coefficient \(1\text{,}\) in exactly one equation, and in no other. Assign arbitrary values to the free variables; each equation then determines the value of its basic variable. This produces a solution, so the system is consistent. That proves existence.
🔗
For uniqueness, the same description shows that the solutions are in one-to-one correspondence with the choices of values for the free variables. If there are no free variables there is exactly one choice, hence one solution. If there is at least one free variable, it can take infinitely many values, each giving a different solution.
