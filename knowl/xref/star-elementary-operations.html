Exercise 9. ★ The Three Operations in Action.

Apply each of the three elementary operations to the system
\begin{align*} 2x_1 + x_2 - 3x_3 \amp = 4\\ x_1 - x_2 + 2x_3 \amp = -1\\ -x_1 \phantom{{}- x_2} + 4x_3 \amp = 5 \end{align*}
🔗
Solution.
Interchange the first two equations.
\begin{align*} x_1 - x_2 + 2x_3 \amp = -1\\ 2x_1 + x_2 - 3x_3 \amp = 4\\ -x_1 \phantom{{}- x_2} + 4x_3 \amp = 5 \end{align*}
🔗
Multiply the second equation by \(-3\text{.}\)
\begin{align*} 2x_1 + x_2 - 3x_3 \amp = 4\\ -3x_1 + 3x_2 - 6x_3 \amp = 3\\ -x_1 \phantom{{}- x_2} + 4x_3 \amp = 5 \end{align*}
🔗
Add \(-2\) times the second equation to the first.
\begin{align*} \phantom{2x_1 +{}} 3x_2 - 7x_3 \amp = 6\\ x_1 - x_2 + 2x_3 \amp = -1\\ -x_1 \phantom{{}- x_2} + 4x_3 \amp = 5 \end{align*}
The first equation became \((2x_1 + x_2 - 3x_3) - 2(x_1 - x_2 + 2x_3) = 4 - 2(-1)\text{,}\) that is \(0x_1 + 3x_2 - 7x_3 = 6\text{:}\) the variable \(x_1\) has been eliminated.
🔗
As in Example 1.17, each display comes from the original system by one operation; they are not applied in sequence.
