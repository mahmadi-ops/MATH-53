Theorem 1.19 Elementary Operations Preserve Solutions.

If one system of linear equations is obtained from another by an elementary operation, then the two systems are equivalent.
🔗
🔗

Proof.
Suppose the new system is obtained from the old one by an elementary operation. Every solution of the old system is a solution of the new one, because each equation of the new system is built from equations of the old system by arithmetic: interchanging equations changes nothing; if numbers satisfy an equation then they satisfy any nonzero multiple of it; and if numbers satisfy two equations, then they satisfy the sum of one with any multiple of the other.
🔗
For the reverse direction, observe that each elementary operation can be undone by an elementary operation of the same type: interchange the same two equations again, multiply by the reciprocal of the scaling factor, or subtract the same multiple that was added. So the old system is obtained from the new one by an elementary operation, and by the first paragraph every solution of the new system is a solution of the old one. The two systems therefore have exactly the same solutions.
