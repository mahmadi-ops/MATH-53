Definition 6.4. Cofactor Expansion Along Row \(i\) or Column \(j\).

If \(A = \begin{bmatrix} a_{ij} \end{bmatrix}\) is an \(n \times n\) matrix, then
\begin{equation*} \det A = a_{i1}C_{i1} + a_{i2}C_{i2} + a_{i3}C_{i3} + \cdots + a_{in}C_{in} \end{equation*}
(cofactor expansion along row \(i\)), and
\begin{equation*} \det A = a_{1j}C_{1j} + a_{2j}C_{2j} + a_{3j}C_{3j} + \cdots + a_{nj}C_{nj} \end{equation*}
(cofactor expansion along column \(j\)).
