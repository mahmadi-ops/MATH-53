    Section 7.1 Vector Spaces

    Everything we proved about \(\R^n\) used only a short list of properties of addition and scalar multiplication. Taking that list as the definition frees us from columns of numbers: polynomials and matrices satisfy the same axioms, and so everything we know applies to them too.
    🔗

    Definition 7.1. Vector Space.

    A vector space \(V\) is a set of vectors with two operations defined, addition and scalar multiplication, which satisfy the following axioms for all \(\vec{u}\text{,}\) \(\vec{v}\text{,}\) and \(\vec{w} \in V\) and for all \(a, b \in \R\text{.}\)
    🔗
    1. \(\vec{u} + \vec{v} \in V\text{.}\)
      🔗
      🔗
    2. \(\vec{u} + \vec{v} = \vec{v} + \vec{u}\text{.}\)
      🔗
      🔗
    3. There exists \(\vec{0} \in V\) such that \(\vec{0} + \vec{u} = \vec{u}\text{.}\)
      🔗
      🔗
    4. There exists \(-\vec{u} \in V\) such that \(\vec{u} + (-\vec{u}) = \vec{0}\text{.}\)
      🔗
      🔗
    5. \((\vec{u} + \vec{v}) + \vec{w} = \vec{u} + (\vec{v} + \vec{w})\text{.}\)
      🔗
      🔗
    6. \(a\vec{u} \in V\text{.}\)
      🔗
      🔗
    7. \(a(\vec{u} + \vec{v}) = a\vec{u} + a\vec{v}\text{.}\)
      🔗
      🔗
    8. \((a + b)\vec{u} = a\vec{u} + b\vec{u}\text{.}\)
      🔗
      🔗
    9. \(a(b\vec{u}) = (ab)\vec{u}\text{.}\)
      🔗
      🔗
    10. \(1\vec{u} = \vec{u}\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 7.2. The Vector Space of Polynomials \(\mathbb{P}_2\).

    Let \(\mathbb{P}_2\) be the set of all polynomials of at most degree \(2\) as well as the zero polynomial. Define addition to be the standard addition of polynomials, and scalar multiplication the usual multiplication of a polynomial by a number. Show that \(\mathbb{P}_2\) is a vector space.
    🔗
    Solution.
    We can write \(\mathbb{P}_2\) explicitly as
    \begin{equation*} \mathbb{P}_2 = \left\{ a_2 x^2 + a_1 x + a_0 \; \middle| \; a_i \in \R \text{ for all } i \right\}. \end{equation*}
    Let \(f(x) = a_2 x^2 + a_1 x + a_0\) and \(g(x) = b_2 x^2 + b_1 x + b_0\) be two polynomials of at most degree \(2\text{,}\) and let \(c, d \in \R\text{.}\)
    🔗
    (I) Closure under addition.
    \begin{equation*} (f + g)(x) = f(x) + g(x) = (a_2 + b_2)x^2 + (a_1 + b_1)x + (a_0 + b_0) \in \mathbb{P}_2, \end{equation*}
    since the sum is again a polynomial of degree at most \(2\text{.}\)
    🔗
    (II) Commutativity. \(f(x) + g(x) = g(x) + f(x)\text{,}\) since addition of the coefficients is commutative.
    🔗
    (III) Additive identity. The zero polynomial \(P_0(x) = 0\) for all \(x \in \R\) is in \(\mathbb{P}_2\text{,}\) and
    \begin{equation*} (f + P_0)(x) = f(x) + P_0(x) = f(x) + 0 = f(x). \end{equation*}
    🔗
    (IV) Additive inverse. Let \(-f(x) = -a_2 x^2 - a_1 x - a_0\text{.}\) Then
    \begin{equation*} f(x) + (-f(x)) = (a_2 - a_2)x^2 + (a_1 - a_1)x + (a_0 - a_0) = P_0(x). \end{equation*}
    🔗
    (V) Associativity follows in the same way, one coefficient at a time.
    🔗
    (VI) Closure under scalar multiplication.
    \begin{equation*} c \, f(x) = c \left( a_2 x^2 + a_1 x + a_0 \right) = c a_2 x^2 + c a_1 x + c a_0 \in \mathbb{P}_2. \end{equation*}
    🔗
    (VII)–(X) are verified the same way. For instance,
    \begin{equation*} c \left( d \, f(x) \right) = c \left( d a_2 x^2 + d a_1 x + d a_0 \right) = (cd) a_2 x^2 + (cd) a_1 x + (cd) a_0 = (cd) f(x), \end{equation*}
    and \(1 f(x) = f(x)\text{.}\)
    🔗
    Since the above axioms hold, we know that \(\mathbb{P}_2\) as described above is a vector space.
    🔗
    🔗
    🔗

    Example 7.3. The Vector Space of \(2 \times 2\) Matrices.

    Let \(\mathbb{M}_{22}\) be the set of all \(2 \times 2\) matrices. Is \(\mathbb{M}_{22}\) a vector space?
    🔗
    Solution.
    Yes. Let \(A, B, C \in \mathbb{M}_{22}\text{,}\) and let \(a\) and \(b \in \R\text{.}\)
    🔗
    • (I) \(A + B \in \mathbb{M}_{22}\text{,}\) since the sum of two \(2 \times 2\) matrices is again \(2 \times 2\text{.}\)
      🔗
      🔗
    • (II), (III), (IV), and (V) follow from Theorem 4.7, the properties of matrix addition.
      🔗
      🔗
    • (VI) \(aA \in \mathbb{M}_{22}\text{.}\)
      🔗
      🔗
    • (VII), (VIII), (IX), and (X) follow from Theorem 4.11, the properties of scalar multiplication for matrices.
      🔗
      🔗
    🔗
    🔗
    🔗

    Remark 7.4.

    Notice how little work the second example took. Once the axioms are isolated, a familiar theorem about matrices is the verification. This is the payoff of abstraction: results proved from the axioms alone hold in every vector space at once.
