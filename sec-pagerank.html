    Section 9.4 The PageRank Algorithm: The 25 Billion Dollar Eigenvector

    The PageRank algorithm is one of many algorithms that Google uses to determine the relative importance of a webpage. In 1998, Brin and Page posed the original formulation and subsequent solution of the PageRank problem in the Markov chain realm. Google owes its success partly to its PageRank algorithm, which enables ranking the pages and thereby presenting to the user the most relevant and helpful pages first. Here, we will study a simplified version of this algorithm.
    🔗
    The PageRank algorithm models the internet with a directed graph. Each webpage is a node, and there is an edge from node \(i\) to node \(j\) if page \(i\) links to page \(j\text{.}\) Let \(\operatorname{In}(i)\) be the websites linking to page \(i\) and let \(\operatorname{Out}(i)\) be the websites that page \(i\) links to.
    🔗
    The PageRank algorithm ranks pages by how many other pages link to them. A link from a more important page counts more than one from a less important page. For example, in Figure 9.19 we would expect node \(0\) to have a very high rank because every other node links to it. Consequently, we would expect node \(7\) to have a fairly high rank because node \(0\) links to it, even though node \(0\) is the only node to do so.
    🔗

    Remark 9.20.

    For example, in Figure 9.19,
    \begin{equation*} \operatorname{Out}(2) = \{ \, \}, \quad \operatorname{Out}(4) = \{ 0, 5, 6 \}, \quad \operatorname{In}(2) = \{ 3 \}, \quad \operatorname{In}(4) = \{ \, \}. \end{equation*}
    Also, we will use the notation \(|\operatorname{Out}(i)|\) to represent the number of webpages that page \(i\) links to. For example, \(|\operatorname{Out}(4)| = 3\text{.}\)
    🔗
    🔗

    Subsection 9.4.1 The Random Surfer

    The PageRank algorithm assumes that a surfer chooses a starting webpage randomly. Then, if the surfer is at page \(i\text{,}\) they randomly select a page from \(\operatorname{Out}(i)\) to visit next. This means that the surfer’s chance of being on page \(i\) at time \(t\) is determined by where they were at time \(t - 1\text{.}\)
    🔗

    Example 9.21. Question 1.

    A surfer starts by choosing a webpage randomly. Suppose the internet has \(N\) webpages, and let \(p_i(t)\) be the likelihood that the surfer is on page \(i\) at time \(t\text{.}\) What are the probabilities \(p_i(0)\) and \(p_i(t+1)\text{?}\)
    🔗
    Solution.
    \begin{equation*} p_i(0) = \frac{1}{N}, \qquad p_i(t+1) = \sum_{j \in \operatorname{In}(i)} \frac{p_j(t)}{|\operatorname{Out}(j)|}. \end{equation*}
    The sum runs over the in-linking pages, and the denominator is the number of out-links of the linking page \(j\text{.}\)
    🔗
    Key ideas.
    1. A page is highly ranked if it is cited often by other pages. The importance of page \(i\) increases if it is linked to from page \(j\text{.}\)
      🔗
      🔗
    2. Also, the increment in the importance of page \(i\) should depend on the importance of the linking page \(p_j\text{;}\) the increment in the importance of page \(i\) should be inversely proportional to the number of out-links from page \(j\text{,}\) which is denoted by \(|\operatorname{Out}(j)|\text{.}\)
      🔗
      🔗
    🔗
    🔗
    🔗

    Example 9.22. Question 2.

    Find \(p_6(t+1)\text{.}\)
    🔗
    Solution.
    Since \(|\operatorname{Out}(3)| = 3\text{,}\) \(|\operatorname{Out}(4)| = 3\text{,}\) and \(|\operatorname{Out}(5)| = 2\text{,}\) and pages \(3\text{,}\) \(4\text{,}\) \(5\) are the ones linking to page \(6\text{,}\)
    \begin{equation*} p_6(t+1) = \frac{p_3(t)}{3} + \frac{p_4(t)}{3} + \frac{p_5(t)}{2}. \end{equation*}
    🔗
    🔗
    🔗

    Example 9.23. Question 3.

    For the graph in Figure 9.19, find a matrix which will represent the evolution of probabilities from time \(t\) to time \(t+1\text{.}\)
    🔗
    Solution.
    Reading each column \(j\) as the out-links of page \(j\text{,}\)
    \begin{equation*} H_0 = \begin{bmatrix} 0 \amp 1 \amp 0 \amp \frac{1}{3} \amp \frac{1}{3} \amp \frac{1}{2} \amp 1 \amp 1 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp \frac{1}{3} \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp 0 \amp \frac{1}{3} \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \amp \frac{1}{3} \amp \frac{1}{3} \amp \frac{1}{2} \amp 0 \amp 0 \\ 1 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}, \qquad H_0 \vec{p}(t) = \vec{p}(t+1). \end{equation*}
    For example, row \(6\) reproduces \(p_6(t+1) = \frac{p_3(t)}{3} + \frac{p_4(t)}{3} + \frac{p_5(t)}{2}\text{.}\)
    🔗
    🔗
    🔗

The cells on this page share their variables, so run them in order. The cell below enters \(H_0\text{,}\) computes one step \(\vec{p}(1) = H_0\,\vec{p}(0)\) from the uniform start \(p_i(0) = \frac{1}{8}\text{,}\) and then computes the sum of each column of \(H_0\text{.}\)
    🔗
    Notice that every column of \(H_0\) sums to one except column \(2\text{,}\) which sums to zero: \(H_0\) is not a stochastic matrix, because page \(2\) is a dangling page. This is exactly the problem addressed next.
    🔗
    🔗

    Subsection 9.4.2 Pages with No Outbound Links

    On the Internet many pages are dangling or sink links, without any outbound links. What happens to the random surfer who visits such a page? The simplest thing is to imagine that the surfer chooses the next page entirely at random.
    🔗

    Example 9.24. Question 4.

    Modify the directed graph of Figure 9.19 and the probabilities \(p_i(t+1)\) assuming that surfers visiting a page with no outbound link will choose another page at random.
    🔗
    Solution.
    Page \(2\) is the dangling node, so we replace its column of zeros by a column of \(\frac{1}{8}\)s:
    \begin{equation*} H = \begin{bmatrix} 0 \amp 1 \amp \frac{1}{8} \amp \frac{1}{3} \amp \frac{1}{3} \amp \frac{1}{2} \amp 1 \amp 1 \\ 0 \amp 0 \amp \frac{1}{8} \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp \frac{1}{8} \amp \frac{1}{3} \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp \frac{1}{8} \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp \frac{1}{8} \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp \frac{1}{8} \amp 0 \amp \frac{1}{3} \amp 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp \frac{1}{8} \amp \frac{1}{3} \amp \frac{1}{3} \amp \frac{1}{2} \amp 0 \amp 0 \\ 1 \amp 0 \amp \frac{1}{8} \amp 0 \amp 0 \amp 0 \amp 0 \amp 0 \end{bmatrix}. \end{equation*}
    The probability for page \(6\) gains an additional term:
    \begin{equation*} p_6(t+1) = \frac{p_3(t)}{3} + \frac{p_4(t)}{3} + \frac{p_5(t)}{2} + \underbrace{\frac{p_2(t)}{8}}_{\text{additional term}}. \end{equation*}
    Now \(H\) is column stochastic and will preserve probabilities.
    🔗
    🔗
    🔗
    Check it in Sage. The cell below builds \(H\) from \(H_0\) by replacing column \(2\) with a column of \(\frac{1}{8}\)s, and then verifies that every column of \(H\) now sums to one, i.e. that \(H\) is stochastic. (It uses H0 from the previous cell, so evaluate that one first.)

    Subsection 9.4.3 Making the Model More Realistic (Adding Boredom)

    Previously we assumed that the current page must link to the next page. However, the model is more realistic if we assume that the surfer sometimes gets bored and randomly picks a new starting page.
    🔗

    Example 9.25. Question 5.

    Denote the probability that a surfer stays interested at time step \(t\) by a constant \(\alpha\text{,}\) called the damping factor. How would the probabilities \(p_i(t+1)\) be modified?
    🔗
    Solution.
    \begin{equation*} p_i(t+1) = \alpha \left( \sum_{j \in \operatorname{In}(i)} \frac{p_j(t)}{|\operatorname{Out}(j)|} \right) + (1 - \alpha)\frac{1}{N}, \end{equation*}
    since with probability \((1 - \alpha)\) the surfer loses interest and will choose another page at random.
    🔗
    🔗
    🔗

    Example 9.26. Question 6.

    Express the result of the previous question as a matrix equation and show that it represents a Markov chain whose transition matrix is regular and stochastic.
    🔗
    Solution.
    \begin{align*} \vec{p}(t+1) \amp = \alpha H \vec{p}(t) + (1-\alpha) \begin{bmatrix} \frac{1}{N} \\ \vdots \\ \frac{1}{N} \end{bmatrix}\\ \amp = \alpha H \vec{p}(t) + \frac{(1-\alpha)}{N} \begin{bmatrix} 1 \amp 1 \amp \cdots \amp 1 \\ \vdots \amp \vdots \amp \amp \vdots \\ 1 \amp 1 \amp \cdots \amp 1 \end{bmatrix}_{N \times N} \vec{p}(t)\\ \amp = \left( \alpha H + \frac{(1-\alpha)}{N} \begin{bmatrix} 1 \amp \cdots \amp 1 \\ \vdots \amp \amp \vdots \\ 1 \amp \cdots \amp 1 \end{bmatrix}_{N \times N} \right) \vec{p}(t), \end{align*}
    where the second step uses that the entries of \(\vec{p}(t)\) sum to one.
    🔗
    Note that \(H\) is a stochastic matrix and \(B = \frac{1}{N} \begin{bmatrix} 1 \amp \cdots \amp 1 \\ \vdots \amp \amp \vdots \\ 1 \amp \cdots \amp 1 \end{bmatrix}_{N \times N}\) is also a stochastic matrix. Therefore \(\alpha H + (1-\alpha)B\) is also a stochastic matrix:
    \begin{equation*} \sum_{i=1}^{N} \left( \alpha H_{ij} + (1-\alpha)B_{ij} \right) = \alpha \sum_{i=1}^{N} H_{ij} + (1-\alpha) \sum_{i=1}^{N} B_{ij} = \alpha(1) + (1-\alpha)(1) = 1. \end{equation*}
    Also, it is obvious that \(\alpha H + (1-\alpha)B\) is a regular matrix, since every entry is strictly positive.
    🔗
    🔗
    🔗

    Example 9.27. Question 7.

    Choose \(\alpha = 0.85\) and find the steady state of the Markov chain derived in the previous question for the example shown in Figure 9.19.
    🔗
    Solution.
    With
    \begin{equation*} T = \alpha H + \frac{(1-\alpha)}{N} \begin{bmatrix} 1 \amp \cdots \amp 1 \\ \vdots \amp \amp \vdots \\ 1 \amp \cdots \amp 1 \end{bmatrix}_{N \times N}, \end{equation*}
    we calculate the eigenvector corresponding to eigenvalue one, normalized to be a probability vector:
    \begin{equation*} \vec{p}_* = \begin{bmatrix} 0.4387 \\ 0.0217 \\ 0.0279 \\ 0.0217 \\ 0.0217 \\ 0.0279 \\ 0.0459 \\ 0.3946 \end{bmatrix}. \end{equation*}
    🔗
    As expected, page \(0\) has the highest rank. Page \(7\) has a higher rank than page \(6\text{,}\) because it has been linked to by the highest ranked page (page \(0\)). The above probability vector provides a comparison between the importance of the webpages.
    🔗
    🔗
    🔗
    Check it in Sage. The cell below builds \(T = \alpha H + \frac{(1-\alpha)}{N} B\) with \(\alpha = 0.85\text{,}\) where ones_matrix(QQ, N, N) is the \(N \times N\) matrix of ones. Since \(T\) is a regular stochastic matrix, Theorem 9.12 guarantees a unique steady state, and by Example 9.15 we can reach it by iterating from any starting probability vector. The cell computes \(T^{100}\,\vec{p}(0)\) from the uniform start; compare the output with \(\vec{p}_*\) above. (It uses H from the previous cell, so evaluate that one first.)
    🔗
    Alternatively, following Theorem 9.13, we can find the steady state directly by solving \((T - I)\vec{p}_* = \vec{0}\text{:}\) the command (T - 1).right_kernel() computes the null space of \(T - I\text{,}\) and dividing its basis vector by the sum of its entries normalizes it into a probability vector.
    🔗
    Both computations agree with the ranking found above: page \(0\) first, page \(7\) second. As an experiment, try changing the damping factor to \(\alpha = 0.5\) or \(\alpha = 0.99\) in the first cell and re-running both cells. Does the ranking of the pages change?
